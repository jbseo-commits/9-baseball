# 코퍼 시로코 V2 수정 계약

사용자 피드백: 와인드업에서 손이 바뀌어 보이며 매력이 부족함. 아이보리 에이스·로즈 페인트처럼 글래머한 캐릭터를 원함.

실제 두 기준 PNG를 확인했다. 성인 29세 설정을 유지하며 얼굴·체형·의상을 다시 그린다. 풍만한 상체, 잘록한 허리, 매끄러운 체형, 긴 다리, 부드러운 애니메이션풍 얼굴을 기준으로 한다. V1은 사용자 반려 기록으로 보존한다.

## 구현 전 영향도 분석

## 모션 계약

- 실제 머리 위 와인드업을 포함한다. 몸은 포수 시점에 가까운 정면을 유지한다.
- 공은 해부학적 오른손(화면 왼쪽), 글러브는 왼손(화면 오른쪽). 오른손 구릿빛 밴드·왼손 흰 밴드를 연속 유지한다.
- 축발은 착지 전 오른발, 착지 후에는 왼쪽 앞발을 같은 캔버스 접지 좌표에 맞춘다. 각 그림의 외곽선 중앙으로 자동 재정렬하지 않는다.
- 새 중간포즈는 직접 그린다. 실제 고유 그림 수와 120셀 파일 규격을 구분한다. 단순 이동·회전·교차 페이드로 부드러운 관절 애니메이션이라고 주장하지 않는다.
- 원화 및 미검증/반려 출력은 보존한다. 새 영상 검색·재생 상태와 검수 결과를 사실대로 기록한다.

## 진행 상태

원화·24포즈 재제작과 독립 시각/코드 검수 완료. 오른손/왼글러브·왼무릎 상승·머리 위 와인드업 확인. 공유 발 앵커와 디딤 전환 거리16.76px 확인. 포즈별 체형/크기 변화와 회복→준비 점프는 후보 한계로 보존한다. 7개 계약·PNG 회귀 검사는 포장/메타데이터 검증이며 인체 연속성은 별도 시각 검수다. 세부 검수는 `v2/review.json`, 실제 파일 검사는 `v2/validation.json`. 기존 게임 연결·main 병합 없음.
