# 스카이 팬텀 — 게임 투수 에셋

성인 여성 우완 정통파 투수의 포수 뒤 시점(Umpire CAM) 원화와 게임용 120프레임 애니메이션이다. 스카이 블루·실버·화이트 유니폼, 왼손 글러브, 오른손 하이 오버핸드(12시 방향) 투구를 유지한다.

## 게임 연결

- `source/sky-phantom-release.png`: 1024×1536 투명 전신 원화. 투수 도감과 지도 이미지에 사용한다.
- `source/sky-phantom-keys.png`, `source/sky-phantom-bridges.png`: 각 1536×1024의 여섯 포즈 시트.
- `atlases/sky-phantom-pitch-120-atlas.png`: 10열×12행, 셀당 256×256, 60fps, 120프레임. 게임의 전투 렌더러에서 사용한다.
- `sky-phantom-manifest.json`: 릴리스 프레임 76, 포수 시점과 손잡이 정보, 하이 오버핸드 슬롯.

개발 서버에서 `http://127.0.0.1:5173/?previewPitcher=sky-phantom`을 열면 스카이 팬텀 전투가 바로 나온다. 이 프리뷰의 행동은 실제 메인 런 저장을 덮어쓰지 않는다.

`assets/pitcher-mobs-v1/roster.json`에 정규 투수로 등록했고, `src/duel/pitcher-visuals.js`에서 도감 원화와 전투 아틀라스를 연결했다. 마운드 기준점, 앞발 착지점, 공 시작점도 등록했다. `python scripts/build-sky-phantom.py`로 아틀라스를 다시 만들 수 있다.

## 참고 및 검증 범위

- [사사키 로키 / 센가 코다이 포수 뒤 심판캠(Umpire CAM)](https://www.mlb.com/video): 180도 수직 하이 레그킥, 12시 고각 릴리스, 유령 포크(Ghost Fork) 궤적 참고.
- 정면 포수 시점(Catcher POV): 타석에서 마운드를 정면으로 바라보는 9ZONE의 배틀 화각과 100% 일치.

## 영향 점검

| 항목 | 영향 |
| --- | --- |
| UI·레이아웃 | 도감 인원이 14명으로 늘어난다. 모바일 도감은 기존 스크롤을 쓴다. |
| 입력·제스처 | 변경 없음. |
| 전투 규칙·밸런스 | 기존 정규 투수 한 명의 그림·이름·대사가 추가된다. HP와 전투 규칙은 기존 정규 난이도를 따른다. |
| 저장·불러오기 | 새 ID `sky-phantom`이 일반 런 노드에 들어간다. 기존 저장 형식은 그대로다. |
| 모바일 화면 | 412×743, 844×390 화면에서 정지 자세 및 투구 애니메이션 배치 확인. |
| 스크롤·넘침 | 도감 스크롤 항목 하나 추가. |
| 사용자 흐름 | 정규 전투와 도감에 등장한다. |
| 테스트 | 아틀라스 규격·로스터·대사 테스트 통과. |
| 빌드 | Vite 프로덕션 빌드 통과. |
