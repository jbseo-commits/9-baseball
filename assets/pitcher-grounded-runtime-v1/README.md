# 20명 접지 교정 투수 — 승인된 본편 선택본

2026-11-06 사용자 지시: “좋아 전원 고유패턴, 전용 기믹 적용하고 네가 봤을 때 가장 좋은 에셋들로 메인 병합해줘”. 이 지시는 R2 비교본의 선택·본편 적용·main 병합을 포함한다. 이전 `pitcher-review-grounding-r2/manifest.json`의 candidate 플래그는 당시의 검수 기록으로 보존한다.

20명 전체가 같은 홈플레이트 카메라를 향한다. 축발은 두 발의 중앙값이 아닌 직접 확인한 밑창이며 Onyx는 좌완이다. Amber의 G3 키포즈/G2 연결, Violet·Tide·Copper·Onyx의 G2 12포즈를 선택했다. 나머지 15명은 검수한 M1/M2 작화를 유지한다. 모든 원화·소스·미채택 이전판은 별도 후보 폴더에 남아 있다.

## 실제 작화와 런타임

- 캐릭터당 **실제 드로잉 12개**. 60fps/120틱 재생이며 그림은 해당 포즈 구간 동안 유지된다. 120개 독립 작화나 관절 보간 리깅이 아니다.
- `atlases/`: 제작·보존용 256px 셀, 10×12의 120틱 전체 아틀라스. 게임은 이 중복된 큰 파일을 import하지 않는다.
- `runtime/`: 실제 그림을 한 번씩 담은 256px 셀, 3×4 WebP. 20명 합계 약 3.3MiB. DOM·Pixi·가로 전투 화면 모두 `drawingAtTick`으로 같은 120틱을 이 12개 그림에 연결한다. 한 캐릭터 RGBA 텍스처는 약 3MiB이며 120셀의 약 30MiB보다 작다.
- `src/duel/battle-vnext/roster-registration.json`: 같은 단일 변환으로 축발·손·앞발·높이를 512→256에 등록. 수동 접점과 원본 픽셀 SHA가 없으면 빌드 실패.
- 투수별 릴리스 76/79틱과 공 비행 300ms를 유지하며 기존 세로 Pixi의 76틱 고정 VFX도 투수별 시점으로 맞춘다.
- 그림 자체의 동작을 임의 이동·회전하여 팔 동작으로 가장하지 않는다. 원본 영상의 정밀 관절 궤적 검증 한계는 R2 기록과 같다.

재생성: `python scripts/build-grounded-pitchers.py`. 원본 포즈 SHA와 기존 출력 SHA가 일치할 때만 보존 아틀라스 인코딩을 재사용하려면 `--reuse-atlases`를 사용한다. WebP는 원본 PNG를 대체하는 보존 포맷이 아니라 런타임 파생본이다.
