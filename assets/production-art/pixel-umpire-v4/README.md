# Pixel Umpire V4 — 복귀 원화와 구장 광원

기존 카드 일러스트와 카드/9존 조작을 유지한 전투 장면 후보다. V3 타자의 원본36셀은 RGBA가 동일하며, 복귀용 새 원화12개를 뒤에 추가했다. 56개 atlas 슬롯 중48개가 실제 원화이고8개는 빈 패딩이다. 실제 helper 재생 검사에서는37개의 서로 다른 원화가 사용된다. 이 수치는 화질이나 부드러움의 합격 기준이 아니다.

복귀는 `19→36→52→48→37→38→39→40→41→44→45→42→43→0`이며 마지막2070ms에 원래 READY 그림0으로 돌아간다. 새 원화는 몸통 감속, 몸 앞의 배트 내림, 하체 정리와 재준비를 연결한다. 52의 손잡이는 몸통 뒤로 가려져 추정 위치만 기록했다. 가려진 손의 연속성을 불투명 픽셀 검사로 입증했다고 주장하지 않는다. 44→45의 지지 기준 변경에서 발견한 전신 이동을 없애기 위해 앞발 기준을 READY까지 유지한다. 뒷발은 복귀 과정에서 한 번 정리되며 READY 이후 고정된 그림으로 쉰다.

구장은 우상단의 따뜻한 조명과 좌측의 차가운 환경광으로 다시 생성했다. 배우의 기존 밝은 면은 따뜻한 색, 그늘은 차가운 색으로 정리하고 현재 자세의 실루엣 그림자를 같은 방향으로 바닥에 투사한다. 기존 투수의 모든 원화를 광원 방향에 맞춰 다시 그린 것은 아니다. 기존 투수의 정체성/원화 순서는 보존한다. 파생 색상/그림자는 배우별16프레임 캐시를 사용하며 캔버스 읽기가 불가능하면 원본 배우를 표시한다.

`runtime/manifest.json`은 게임용 좌표/시간표 wrapper다. `provenance/final-run/manifest.json`은 공식 compose 결과이고 서로 역할이 다르다. 원화의 `sourceFile`은 제작 당시 export label이며 실제 반입 파일은 `provenance/native-exports/`와 `manual-measurements/atlas-input-map.json`으로 추적한다. 기존36셀 원본은 V3 provenance에 있다.

생성은 내장 image_gen으로 수행했다. 원본 고해상도 AI raster를 공식 component 추출→V3 공유96색 palette→pixel-unfake→상태별 동일 배율의 가역 curation→공식 compose로 처리했다. 128logical/256storage,2px 격자, hard alpha이며 손으로 처음부터 그린 native pixel art나 무손실 변환이 아니다. 모든 최종 프롬프트9개와 선택/탈락 원본은 `provenance/`에 보관한다.

실제 플레이 영상·좌표 검증·남는 한계는 [V4 검증 기록](../../../docs/design/pixel-umpire-v4/README.md)에 있다. 딤래스·홀스틴과 동급의 아트 또는 완성 애니메이션으로 승인된 결과는 아니다.
