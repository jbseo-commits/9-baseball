# 가로 전투 pilot 동작

2026-10-28 사용자 요청의 5단계 연출 구현용. 선정 catcher-camera 원화를 identity/camera 참조로 image_gen에서 새 동작을 그렸다. 타자 14개 그림(준비·로드·스트라이드·회전·접촉·팔로스루·복귀), 샘플 투수 5개 그림(세트·기존 코일·릴리스·팔로스루·피로)이다. 120개 독립 그림이나 전체 로스터 완료로 표기하지 않는다.

`source/`는 원본 생성 시트, `*-atlas.png`는 등록된 lossless 시트, `*-atlas.webp`는 런타임 파생본. `motion.json`에 원본 해시·image_gen 실행 ID·각 포즈의 crop/발 접점/등록 배율·배트 접촉/오른손 릴리스 기준점을 보존한다. 생성 시트의 일부 배트가 가상 격자를 넘으므로 일정 셀로 무작정 자르지 않는다.

빌드: `python3 scripts/build-landscape-cinema-atlas.py`. 이 스크립트는 그림을 crop·발 등록·크기 정규화·packing·WebP 인코딩한다. 사지를 변형하거나 원화를 회전해서 중간 동작을 만들지 않는다. 투명 픽셀의 보이지 않는 RGB는 런타임에서 최적화하되 원본/PNG를 보존한다.

명시적 메모리 검수/샘플 배우에서 사용한다. 기존 actor-coverage의 실제 상대 승인 목록은 변경하지 않는다. 그립·타석 방향·발·배트·공은 실제 플레이 영상으로 검수하며, 제한된 포즈 수와 프레임 사이 세부 형태 변화는 실기기/아트 추가 검수 대상이다.
