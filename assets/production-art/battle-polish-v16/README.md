# Battle polish V16 — anatomy correction candidates

`docs/art/benchmark/target/battle-portrait.png`와 기존 `battle-portrait-v15`를 기준으로 제작한 **비파괴 후보**다. 기존 런타임 에셋, `QUEUE.md`, 보상 화면 코드는 수정하지 않았다. 세부 배치와 전환은 제미나이가 맡을 수 있도록 개별 투명 PNG와 시간표를 제공한다.

## 파일과 선택 기준

| 파일 | 역할 | 시각 검수 |
| --- | --- | --- |
| `red-rush-coil-break.png` | 와인드업에서 양손이 갈라지는 순간 | 앞무릎 들림·축발 접지·공 1개 |
| `red-rush-late-cocking.png` | 공을 쥔 손과 어깨→팔꿈치→손목 연결이 보이는 릴리스 직전 | 1개 공, 양팔 연결, 얼굴/유니폼 유지 |
| `red-rush-arm-whip.png` | 팔꿈치가 선행하고 공 쥔 손이 앞으로 오는 중간 | 손·글러브·어깨 연결 유지 |
| `red-rush-release-no-ball.png` | 공을 독립 레이어로 내보낸 릴리스 순간 | 투구 손과 글러브 분리, 공 중복 없음 |
| `red-rush-follow-through.png` | 던진 팔과 뒤쪽 다리의 관성 | 양팔/양다리 판독, 균형 유지 |
| `impact-slash.png` | 타격 순간 청색 속도선+금빛 접점 VFX 대안 | 투명 이펙트, 배우/문자 없음 |

모든 PNG는 내장 `image_gen`으로 생성·수정했다. 투수 키포즈 5장은 1024×1536, VFX는 1254×1254이며 네 모서리의 알파값은 0이다. 기존 V15의 와인드업·스트라이드와 이어지는 권장 순서는 `manifest.json`에 있다. `preview.html`은 **키포즈 타이밍 미리보기**이며 완성된 고프레임 애니메이션 판정이 아니다.

`red-rush-keypose-animatic.webp`는 기존 2포즈와 새 5포즈를 256×384 프레임으로 무손실 묶은 7프레임 재생 파일이다. 원본 PNG는 변경하지 않았다. HTML 미리보기와 WebP 모두 움직임을 확인하기 위한 후보이며, 최종 프레임 등록과 추가 인비트윈은 아직 남았다.

## 제작 지시 요약

- 기존 Red Rush의 붉은 포니테일, 금빛 눈, 검정/빨강 유니폼, 긴 야구 바지와 갈색 왼손 글러브를 고정했다.
- `coil-break`: 들어 올린 무릎과 축발을 유지하며 손이 분리되는 초반 체중 이동을 그렸다.
- `late-cocking`: 오른손이 야구공을 자연스럽게 감싸고, 오른쪽 어깨부터 손목까지 이어지는 오버핸드 코일을 그렸다.
- `arm-whip`: 공을 쥔 손과 글러브가 서로 반대로 움직이는 릴리스 직전 중간 키포즈를 만들었다.
- `release`: 앞으로 회전한 몸통과 던진 손, 가슴 쪽으로 접힌 글러브를 분리했다. 생성본에 함께 있던 공은 이미지 편집으로 제거했다.
- `follow-through`: 오른팔이 몸 앞을 지나 내려오고 뒷다리가 들어올려지는 관성을 표현했다.
- `impact-slash`: 목업의 청색 타구 속도선과 금빛 접점을 투명 단독 VFX로 제작했다.

## 인수 시 확인할 점

- 이 후보는 기존 V15 키포즈와 **화풍·얼굴·발 기준선이 완전히 잠겼다는 보증이 없다**. `preview.html`의 전환과 실제 412×743 화면에서 얼굴, 어깨·손목, 발 접지 및 프레임 점프를 확인해야 한다.
- 릴리스 PNG에는 야구공이 없으므로 공은 게임 엔진에서 별도 생성하고 릴리스 시점에 맞춰야 한다.
- 기존 `battle-portrait-v15`의 타자 7포즈가 신규 타자 시안보다 더 완성도가 높아, 이번 패키지는 타자 스프라이트 교체를 제안하지 않는다.
- 런타임 연결, 8축 블라인드 비교, 완성 애니메이션 검증은 아직 수행하지 않았다.
