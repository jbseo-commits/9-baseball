# At-bat mechanic illustrations

image_gen authored one3×3 illustration sheet, 2026-10-29. Source is preserved at source/illustrations.png. The exact observed frame bounds are recorded in manifest.json and extracted by scripts/build-atbat-card-art.py. All cards use their real kind mapping; no text, range grid or cost is painted into the art. UI is live model data.

Runtime200px WebP quality70, about46KB for nine illustrations. Cards show the whole image using contain. Original high resolution sheet remains available for later delivery-budget improvements.

Mapping: place(contact), rally(advance), strike(opposite field), laser(line drive), scout(pitch release), wall(coverage), watch(patience), slug(long ball), defend(cut). Other card kinds retain their existing artwork, not an invented mechanic mapping.
