# 20명 투수 접지·투구폼 수정 R2

2026-11-06 사용자 요청에 따라 전원 12포즈와 신발 접점을 직접 확인한 수정 후보입니다. 기존 양발 하단 알파 중앙값을 축발 밑창 접점으로 바꿨습니다. 19명 우완은 오른발, Onyx 좌완은 왼발이 기준입니다.

**비교 페이지:** [이전/수정 후보 전환](https://jbseo-commits.github.io/9-baseball/previews/codex-pitcher-grounding-low-slot-r2/art-review/pitcher-grounding-r2/). 투수·배속·포즈를 선택하고 `기준: 기존 / 수정 후보`, `접지 가이드`를 바꾸면 실제 필드의 같은 투수판에서 비교할 수 있습니다. 이 페이지는 에셋 검수용이며 본편 로스터·저장·규칙을 실행하거나 교체하지 않습니다.

## 수정

- **전원 접지:** 실제 게임 배경 사진의 투수판 영역을 별도로 표시하고, 신발만 분리한 접점 후보를 사람이 20명 모두 확인했습니다. SET·체중 이동·다리 들기에서 확인한 축발을 사용합니다. 한 캐릭터의 좌표와 배율은 모든 포즈에서 고정하며, 디딤발을 투수판으로 끌어당기지 않습니다.
- **Amber / Violet / Tide:** 낮은 three-quarter·sidearm 동작을 전신 키/연결 포즈로 다시 그렸습니다. 골반·몸통 회전과 팔꿈치/손목 진행, 팔로스루를 구분합니다. 기존 폼 분류를 유지하며 임의의 새 언더핸드 폼으로 바꾸지 않았습니다.
- **Copper / Onyx:** 다리 들기에서 축발이 옆으로 크게 이동하던 자세를 재작화했습니다. Copper의 머리 위 모으기, Onyx의 좌완·오른쪽 글러브·오른발 디딤을 유지했습니다.
- **효과 위치:** 공 출발점은 수정 그림의 빈 손끝에서, 착지 먼지는 실제 앞발 위치에서 시작합니다. 준비 동작의 접지 기준과 디딤 위치를 분리했습니다. 기존 릴리스 프레임 76/79, 별도 공 300ms와 공개 기믹 정보는 유지합니다.

총 **20명×12드로잉=240개 PNG**입니다. 5명×12=60개를 재작화했고 나머지 15명의 드로잉은 이전 미리보기와 동일합니다. 캐릭터 원화 20개의 SHA도 보존했습니다. 120개의 독립 작화·새 리깅·보간 애니메이션을 만들었다고 주장하지 않습니다.

## 파일과 재현

- `manifest.json`: 캐릭터별 현재/이전 등록점, 손끝, 디딤점, 원화 SHA, 선택 소스와 타이밍.
- `grounding-annotations.json`: 20명의 **수동 확인된** 신발 접점. `annotate-grounding.py`는 별도 `grounding-annotation-proposals.json`만 생성해 확정 등록점을 덮어쓰지 않습니다.
- `source/`, `prompts/`: 생성 원본·프롬프트 보존. 채택 소스는 manifest의 `source_sheets`로 결정하며, 과거/미채택 시트를 함께 보존합니다. `reports/source-preservation.json`이 현재/이전/미채택 역할과 SHA를 구분합니다.
- `poses/`: 선택된 240개 투명 512px PNG. `identity/`에는 승인 원화가 있습니다.
- `previews/frames`, `previews/before`: 수정/이전 lossless WebP 240장씩. `previews/*12poses.*`와 신발·손끝·투수판 사진 가이드도 포함합니다.
- `effects/`, `skills/`: PixelFX 효과 전용 시트/메타데이터·MIT 고지와 기존 공개 기믹 스냅샷. 별도 라이선스 폰트는 포함하지 않습니다.
- `references/`, `reports/`: 실제 PC·휴대폰 캡처, 비교 화면, 구조/접지/브라우저 검사 기록.

`process-motion.py`는 sprite-gen의 알파 잔상 정리와 2dimg2motion GIF 유틸리티를 사용합니다. Python Pillow·NumPy·sprite-gen 및 설치된 `asset-tool`이 필요합니다. PNG 원본은 수정하지 않으며 새 5명은 **12장 전체에 동일하게 480/512 배율+16px 패딩**을 적용합니다. 이는 셀 여백 확보용 공통 패킹입니다. 포즈별 크기 보정이나 사지 합성이 아니며 새 모션으로 세지 않습니다. Amber의 실제 잘린 신발은 패딩으로 숨기지 않고 G3에서 전신을 다시 그렸습니다.

```sh
python process-motion.py
python validate-grounding.py
python build-gallery.py
node qa-gallery.cjs
node qa-projection.cjs
node qa-boot-dom.cjs
```

네이티브 원본 해시와 공개 전 검증한 bytes는 `reports/native-selected-integrity.json`에 있습니다. `process-motion.py`는 확정된 축발 override를 재사용합니다. 원본 생성에는 image_gen을 썼으며, 재현 명령은 새 그림을 생성하거나 외부 API를 호출하지 않습니다. QA의 Playwright/Chromium 위치는 실행 환경에 맞게 준비해야 합니다.

## 검증 근거와 한계

- 브라우저 제어·전후 비교·접지 가이드·효과 pivot/30fps·배속 연속성·정지·공 수명 등 **23개 항목 통과**.
- 실제 DOM의 20명×12포즈×2구도 **480개 배우 배치 검사 통과**.
- 실제 신발 접점의 20명×3준비 단계×2구도 **120개 검사**에서 이전판은 92개가 투수판 영역 밖, 수정판은 0개였습니다. 실제 배경에서 독립 표시한 영역과 사람이 확인한 신발 픽셀을 사용했으며 허용 오차는 캡처 기준 0.6px입니다.
- 원본 20명과 수정 5명의 전체 접점표를 직접 확인했고, 별도 reviewer가 수정 소스 10시트·60포즈를 검사했습니다. 명백한 손/글러브 반전·추가 사지·릴리스 후 잔존 공은 발견하지 못했습니다.

이 수치는 정렬·소스·제어 계약의 검증입니다. 상업 품질이나 실제 관절 역학의 입증은 아닙니다. 제한된 공개 검색에서 사용할 수 있는 새 낮은 폼 영상을 찾지 못했으며, 새 영상을 관찰한 것처럼 기록하지 않습니다. `manifest.json`에 검색 범위와 `reference_unverified` 한계를 남겼습니다. 기존 부분 검증 캐시는 정확한 관절 궤적이나 전체 와인드업을 입증하지 않습니다.

본편의 256×256·10×12 아틀라스와 런타임 로스터는 이 후보와 별도입니다. 이번 요청의 GitHub 게시 승인은 수정 후보 브랜치에 적용하며 main에는 병합하지 않습니다.

## 최종 회귀·재빌드 확인

전체227개 테스트 파일/1528개 테스트가 `pnpm exec vitest run --maxWorkers=2 --testTimeout=15000`으로 통과했습니다. 기존 대량 시드 이벤트 검사가 공유 CPU에서 기본5초를 초과해 로컬 실행 제한을15초로 늘렸으며 테스트 단언문은 변경하지 않았습니다. 새 접지 회귀6개도 별도 통과했습니다. Vite 브랜치 경로 빌드가 통과했습니다.

확정 접점20명이나 원본 픽셀 SHA 바인딩이 없거나 바뀌면 프로세서는 결과 이미지를 쓰기 전에 중단합니다. 임의 중앙값으로 돌아가지 않습니다. 누락 접점/변조된 바인딩 두 부정 사례에서 출력 PNG0개인 것도 확인했습니다.
