# 실행·이슈·회차 기록 템플릿

총괄이 에이전트 편집과 겹치지 않는 시간에 기록한다. 실행 ID·이슈 ID는 에이전트가 생성한다. 비밀키·인증 코드·대화 전체·reasoning은 기록하지 않는다. 재현 가능한 입력과 실제 결과만 남긴다. 큰 PNG·영상·원시 출력은 `work/` 등의 로컬 산출물이며 원격에서 보이지 않으면 그 사실을 적는다.

## 실행 파일: `loop/autodev/runs/<실행-id>.md`

```markdown
# 실행 <id>
- 시작/기한(KST):
- 목표·허용 범주 / 제외 범주:
- 실제 사용자 지시·승인 근거:
- 원격 대상·허용 브랜치 / PR / 공개 권한:
- 기준 main SHA / 현재 HEAD / 작업 브랜치:
- 기존 변경·다른 실행·열린 PR 확인 / 미확인:
- 실제 도구·역할·모델 / 사용할 수 없는 역할:
- 최대 회차 / 사용한 회차 / 남은 회차:
- 회차 상태·이슈 / 이슈별 누적 수정 횟수:
- 실제 검증과 산출물 위치 / 미실행·실패:
- 로컬 / 원격 / 프리뷰 / 공개 배포 상태와 실제 링크:
- 미반영 의존성 / 보류·결정 필요 / 사람 검증 대기:
- 종료·재개 근거 / 다음 한 행동:
```

## 이슈 파일: `loop/autodev/issues/<이슈-id>.md`

```markdown
# <ID> <플레이어가 겪는 문제>
- 우선순위 / 상태 / 소유 실행·작업자:
- 발견 근거 / 현행 재현 SHA / 관련 PR·기존 큐:
- 시드·덱·등급·행동·뷰포트·기기:
- 재현 순서 / 기대 결과 / 실제 결과:
- 증거 파일·줄 / 실제 PNG·영상·출력:
- 원인 가설 / 수정 전 통과 조건:
- 허용 파일·권한 / 선행 조건 / 회귀 위험:
- 9축 영향도와 PR 체크 / 누적 수정 횟수:
- 독립 검수 결함 ID·판정 / 해결 근거:
- 실제 기술·플레이 검증 / 미검증:
- 로컬 커밋 / PR / 프리뷰 / 공개 상태:
- 다음 행동 / 재처리 조건:
```

## 회차 파일: `loop/autodev/rounds/<실행-id>-<번호>.md`

```markdown
# 회차 <번호> — <이슈-id>
- 기준 SHA → 후보 SHA / 현재 브랜치:
- 문제 / Before 조건·증거:
- 변경과 플레이어에게 생기는 차이:
- 영향도 / 실제 수정 파일 / 예상 사이드이펙트:
- 명령별 종료 코드·실제 결과 / 실패·미실행:
- 확인한 사용자 흐름·뷰포트·장면 / 확인 못 한 범위:
- 독립 코드 검수 / 플레이·UX 검수 / 변경 후 재검수:
- 상태 / 누적 수정 횟수 / 채택·보류·기각 근거:
- 로컬·원격·프리뷰·공개 상태 / 실제 링크:
- 결정 필요·사람 검증 / 다음 독립 항목:
```
