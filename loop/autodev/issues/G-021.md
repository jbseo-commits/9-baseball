## 적용 묶음

- 외곽선이 실제 셀들의 topology를 보존한 닫힌 도형으로 이어진다. 분리된 영역/내부 구멍은 보존한다.
- 도착 ghost는 얇고 고정, 운반 중 실루엣은 읽히는 한 물체, 착지는 한 번의 주변부 빛, 직후 몸체를 걷어 존 글자/역할 토큰을 읽힌다. 타일별 방사 효과는 추가하지 않는다.
- 동시 카드 placement 보이스의 gain 목표를 정규화하고, 이동 시작→목적지 pan은 실제 화면 위치로 제안한다. 여러 칸을 여러 번의 성공음으로 세지 않는다. 청감 검증을 자동 테스트로 대체하지 않는다.
- 투구/타격/G020 결과 타이밍과 G013 결과 레이아웃의 추가 변경은 이번 원화 독립 검수 없이 확정하지 않는다. 기존 후보의 PixelFX/Pixelbolt·배속·실제 결과 경계는 보존한다.
- 연구15공식트레일러 디코딩+실제표시프레임,100공식페이지/스크린샷: 정지화면/샘플프레임/연속관찰/설계추론 분리. 원본 클립 속도·소리·ms를 보지 않고 실측이라고 하지 않는다.
