## 수정 전 통과 조건·분담

- 모달 열린 동안 실제 Tab/Shift+Tab/Enter로 배경 보상 확정·건너뛰기 불가. 선택과 저장은 그대로.
- 현재 선택 가능한 모달 내부 버튼을 모두 키보드로 접근 가능하며 초점이 경계에서만 순환.
- 카드 상세가 위에 열리면 해당 시트가 초점을 소유. Escape/닫기→원래 카드→일반 모달 닫기→원래 덱 버튼 복귀.
- 설정→주크박스 등 일반 모달 내부 전환에서도 외부 opener 보존. Escape는 모달만 닫으며 배경 plan/selection에 영향 없음.
- `.duel-app` 자체 inert/aria-hidden 금지(모달도 그 안에 있음). 필요 없는 전역 이벤트/공용스타일 추가 금지.
- 허용 파일: App.jsx, 필요 시 작은 일반 모달 전용 컴포넌트/헬퍼, 관련 regression tests. 작업 중 한 명만 편집. 투수 도감 Tab 결함은 별도 이슈.
- 독립 reviewer 사전 검토: 실제 입력 결함 우선 처리 적절. CSS/문구/배치 변경 없는 초점 의미 수정은 실제 키보드 계약으로 검수; 정적 미학 향상 주장/게이트 포괄 면제 없음. 최종 diff가 시각 변경을 포함하면 별도 블라인드 게이트 적용.
- 현재 테스트/후보/원격 상태: 구현 전. 다음: worker RED 검사 후 좁은 수정, reviewer와 실제 UX 재검증.
