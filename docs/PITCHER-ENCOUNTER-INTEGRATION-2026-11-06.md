## 에셋 선택

R2 검수에서 직접 확인한 고정 카메라 20명 드로잉을 선택한다. Amber G3 키포즈·G2 연결, Violet/Tide/Copper/Onyx G2를 사용하고 나머지 15명은 검수한 기존 M1/M2 드로잉을 유지한다. 캐릭터당 실제 작화는 12개이며 120개 독립 작화·새 사지 리깅으로 부르지 않는다. 기존 원화와 이전 아틀라스는 저장소에 보존한다.

수동 확정한 512px 원본 접점·릴리스·착지점과 SHA를 빌드 입력으로 묶는다. 256px로 같은 비율 변환하며 포즈별 재정렬·중앙값 fallback을 금지한다. 원본 영상의 정밀 관절 검증 한계는 기존 검수 기록에 남아 있다. 이번 승인은 해당 후보의 본편 통합·main 게시를 명시적으로 포함한다.

## 완료 근거

실행 후 전체 테스트·관련 실제 브라우저 점검·용량·최종 배포 결과를 기록한다. 수치를 재미나 상업 품질의 입증으로 사용하지 않는다.

## 실행한 검증

- 실제 App에서20명×PC/휴대폰×SET·gather·lift =120개 밑창 접점을 사진의 독립 투수판 영역과 대조. 이탈0, JavaScript오류0. 0.5배속 재생으로 실제 그림 번호0·1·2를 확인하고 각40건의 실제 지켜보기 판정까지 확인했다. 측정 시계는 정지시켜 검수 명령 사이의 CPU 지연을 투구 시간으로 세지 않았다.
- 전체20명 실제 노드에 직접 진입하는 진단 시나리오이며 일반 맵 경로를 차례로 완주한40경기라는 뜻은 아니다. 원본/새 소스의 손·축발 검수 기록은R2 자료를 재사용한다.
- 타이틀→설정→첫 타격 연습의 실제 진입에서compact3×4를 확인.
- Vite production 번들에서 신규 namespace의 실제카드·존선택→판정→리로드시 같은 투구수 재개, 이미지768×1024, HTTP오류0/JS오류0 확인.
