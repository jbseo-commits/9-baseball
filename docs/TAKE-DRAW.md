# 지켜보기 추가 드로우

사용자는 지켜보기 에너지 보상에 카드 드로우도 요청했다. 에너지 예약과 같은 생존 조건·다음 실제 투구 전이를 사용해 추가 1장을 지급한다.

## 구현 계약

- V10에서 지켜본 볼과 삼진 전 루킹 스트라이크는 다음 공 에너지 +1에 추가 드로우 1장을 더한다. 기본 다음 공 드로우 1장 또는 다음 타자의 4장 보충을 먼저 처리한 뒤 보너스 1장을 뽑는다. 볼넷은 다음 타자에게 전달한다.
- 기본 손패 한도 5장을 유지하고, 지켜보기의 추가 드로우만 6장까지 허용한다. 이미 6장이면 더 뽑지 않는다. 덱과 버림더미가 모두 비었을 때도 카드가 생기지 않는다. 기존 카드를 임의로 버리거나 교체하지 않는다.
- 추가 드로우 대기열은 만들지 않는다. 기존 예약 0/1을 재사용하고 실제 다음 공/타자 전이에서 한 번 소비한다. 결과 화면·이어하기·카드 선택은 즉시 드로우하지 않는다. 삼진·HP 0·새 전투에는 예약이 없다.
- 실제 추가 드로우 가능 여부와 지급된 장수를 화면에서 구분해, 손패 한도나 뽑을 카드가 없을 때 +1장을 받았다고 안내하지 않는다. 이전 버전의 에너지 예약 저장도 다음 전이에서 새 보상 규칙을 적용한다.
- 일반·준비·공격 효과의 드로우는 한도 5를 유지한다. V9 규칙, 에너지·스택 한도, 투구 확률·피해 공식은 유지한다. 6장 손패의 스크롤·선택과 저장 복원을 검증한다.
- 카드 재섞기의 `seed`와 투구의 `pitchSeed`를 구분한다. 현재 확정 공을 재추첨하지 않으며 같은 다음 전이의 투구 난수도 드로우 때문에 바뀌지 않는지 검사한다. 재섞기가 필요한 추가 드로우는 카드 난수 스트림을 소비할 수 있다.
- `fullHand`·`allIn`처럼 손패 수를 쓰는 기존 카드 효과는 6장 손패를 계산에 반영한다. 피해 공식 자체를 바꾸지 않으며, 추가 자원이 수치 밸런스와 플레이 재미를 개선하는지는 사람 플레이로 확인해야 한다.
