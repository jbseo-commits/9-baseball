# 안티그래비티 작업 큐

> 규칙: [`docs/ANTIGRAVITY-LOOP.md`](../ANTIGRAVITY-LOOP.md). 한 바퀴에 **맨 위 `[ ]` 항목 하나만.**
> 상태 표시: `[ ]` 대기 · `[~]` PR 열림 (PR # · 프리뷰 URL) · `[x]` 머지됨 · `[!]` 막힘(이유 · 제안)
> 안티그래비티는 묻지 않고 위에서부터 계속 처리한다. 결과는 프리뷰 URL로 확인하고, 마음에 드는 PR만 머지하면 된다.
> 항목은 사용자가 적는다. 예외: 큐가 비었고 품질이 BAR_MET이 아니면 안티그래비티가 `[auto]` 항목을 만든다 (ANTIGRAVITY-LOOP §11.4).

## 항목 쓰는 법
```
- [ ] 제목 한 줄
  - 무엇: 바꿀 화면/동작
  - 완료 기준: 눈으로 확인할 수 있는 결과 (뷰포트 포함)
  - 건드려도 되는 곳: 파일/영역
  - 건드리면 안 되는 곳: (선택)
```

## 그림 에셋 항목 예시 (§10 흐름)
```
- [ ] A1 말풍선 적용
  - 무엇: 투수 대사 말풍선(.bp-voice, 보상 .bp-kovoice)을 A1 에셋으로
  - 완료 기준: asset-fix OK + 412×743/844×390/1440×900에서 대사가 가죽 말풍선으로 보이고 글자가 안 잘림
  - 건드려도 되는 곳: assets/ui-kit/, src/duel/ballpark.css 의 .bp-voice/.bp-kovoice, 관련 테스트
```
