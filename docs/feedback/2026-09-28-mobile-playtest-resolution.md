## 단정하지 않았던 항목의 결론

- **오른쪽 검은 원형 플로팅 아이콘** — Vercel 프리뷰 툴바다(배포본 직접 확인). 게임 UI가 아니며 프로덕션(GitHub Pages)에는 없다.
- **어두운 휘두른다 버튼** — 카드 미선택 시 정상 비활성. 버그 아님.
- **HP 72% / HP -10** — 계산 오류가 아니라 단위 혼동 → 문구로 분리(M04).
