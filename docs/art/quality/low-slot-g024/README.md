요청: “언더쓰로랑 사이드 투수들의 공 뿌리는 장면이 어색해”. 기존 G023의 프레임/로딩 검수가 야구 동작의 자연스러움을 보증하지 못했다. 세 투수 모두 공 손이 가슴 앞으로 돌아온 뒤 펴지는 chest-push 문제가 있었고, 실제 submarine 폼은 등록돼 있지 않았다.

## 구현

전체 캐릭터를 image_gen으로 다시 그렸다. 팔 잘라붙이기·뼈 회전·광학 보간을 하지 않았다. 원화6개 시트(투구3+회수3)의 채택 셀과 공통 배치 scale/translation, 원본 PNG 식별자/해시, 최종 픽셀 해시를 selection/manifest에 기록했다. 알파≤8/255 배경 잔상 제거만 별도 비창작 처리했다.

원본 키224개는 픽셀 그대로 보존하고16개를 명시적으로 교체했다. 기존 잘못된 릴리스 중간4개와 Violet의 부적합 복귀 중간1개는 제외하고, 새 회수 스텝6개를 추가했다. 최종 중간 원화는 전원 합계86개, 대상3명은 각각18개 그림이다. 나머지17명의 실제 WebP와 전체 등록 JSON은 이전 main3de6257과 동일하다.

새 긴 보폭에서 예전 짧은 보폭으로 바로 넘어가면 앞발이 순간 이동했다. 독립 검수에서 이를 발견한 뒤, 뒷발 지지→앞발 들기/회수→착지6개 원화를 추가했다. 세 투수만 릴리스 이후의 기존120tick 안에서 hold를 재분배해 각각의 새 스텝이 최소3 live ticks 보이도록 했다. 준비/디딤/릴리스/공 비행300ms/접촉 freeze/입력 해제 시각은 보존했다. 손·발 좌표를 새 그림에 맞추고 vNext와 legacy 좌표표를 함께 갱신했다. RNG·카드·피해·보상·세이브·전역 CSS는 변경하지 않았다.

## 근거와 한계

- [구현 전 영향도](IMPACT.md)
- [픽셀/좌표/17명 보존 검증](asset-validation.json) — `python scripts/validate-low-slot.py` (Pillow, baseline3de6257 Git 객체 필요). 릴리스는 실제 손 픽셀, 발 접점은 스파이크 돌기 사이를 고려한3px 이내만 허용한다.
- [독립 아트·코드 검토](independent-reviews.json) — 최초 발 순간 이동 blocker와 실제 녹화 재검토 후 해소 이력을 모두 남겼다.
- [실제0.5배속844×390](half-speed-play.json) / [실제1배속667×375](normal-speed-small-landscape.json) — 세 투수 모두18개 그림 관찰, 로딩/페이지 오류 없음, 실제 행동 결과가 엔진 결과와 일치.
- [참고 영상 관찰](reference-observations.json) — 실제 확인한 Cimber 영상은 센터필드 뒤 시점이다. 정확한 손·릴리스 순간이나 새로운 포수 정면 사이드암 영상은 검증하지 못했다. 이를 영상 기반 완벽한 생체역학으로 주장하지 않는다.

남은 미감상 한계는 유한한 키포즈 hold cadence와 신·구 그림 사이의 약간의 렌더링 차이다. 테스트/픽셀 수/독립 검토를 상업적 마스터피스의 증명으로 쓰지 않는다. G020/G021 HELD와 G022/G023의 과거 기록은 변경하지 않았다.
