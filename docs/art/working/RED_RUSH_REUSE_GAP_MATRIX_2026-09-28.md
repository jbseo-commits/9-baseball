## 결정

레드 러시는 현행 **여성형** 디자인을 고정한다. 목업 속 레드 러시의 성별 차이는 결함으로 기록하지 않는다. 기존 여성형 원형·키포즈·120프레임 투구 아틀라스를 재사용한다. 신규 마스터 시트와 READY/RELEASE 재생성은 중복이어서 채택하지 않았다.

현재 브랜치 `ag/20260928-red-rush-female-art`는 원본 체크아웃의 미커밋 변경과 분리한 작업 트리다. 런타임 파일은 바꾸지 않았다.

## 화면 비교에서 확인한 차이

- `battle-portrait.png`와 현재 `work/qa-v15-title-ending/phone-portrait-battle-decide.png`: 현행 투수는 목업보다 작고 화면 속 비중이 낮다. 인물 성별과 관계없이 **표시 크기, 카메라, 광원 통합**을 별도로 조정·검증해야 한다.
- `battle-landscape.png`는 목업에서 투수와 9존의 상대 크기가 크다. 현재 가로 실게임 캡처도 별도 비교가 필요하다.
- `knockout.png`와 현행 강판 아트는 인물 구도와 표정이 다르다. 여성형 정체성은 고정하고, 강판 감정 전달·분리 레이어·텍스트 안전 영역을 평가한다.
- `dex.png` 대비 여성형 초상 자체는 결함으로 보지 않는다. 카드 크롭에서 얼굴·모자·글러브의 100px 판독을 확인한다.

## 제작 방법과 프롬프트 요약

내장 `image_gen`을 사용했다. 기존 여성형 강판 장면을 참조해 **인물만 투명 알파로 분리하고 복장·포즈·해부학을 보존**하도록 지시했다. 첫 추출본은 신발이 캔버스 하단에 닿아 폐기하고, 네 방향 투명 여백을 요구해 재생성했다. 같은 원본에서 **인물만 제거해 경기장·흙·붉은 연무를 재구성**한 불투명 배경판을 만들었다. 앞서 생성한 신규 원형·READY·인비트윈 시안은 중복 또는 동작 차이 부족으로 저장소에 넣지 않았다.
