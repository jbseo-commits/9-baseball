# 20명 캐릭터 기준 원화 수정 · R4 최신 선택본

2026-10-31 사용자 요청: “네가 하나하나 보고 디테일하게 수정해”. 원본 20명과 큰 가이드를 직접 확인하고 캐릭터별 imagegen 편집을 수행했다. 첫 수정 20장 후 독립 검수 지적에 따라 6명을 추가 수정했다. 최종 선택은 **R4a 14명 + R4b 5명 + R4c 1명**이며, 단일 전신 기준 원화 20장이다.

## 열기

- `portable.html`: 수정 전후 이미지 40개가 내장된 약 8MB 비교 문서. 다른 파일 없이 열 수 있다.
- `index.html`: 같은 폴더 before / review-assets를 사용하는 비교 문서.
- `generation-records.json`의 `output` 20개: 캐릭터별 현재 선택 PNG. 파일 이름에 실제 수정 버전이 있다.
- `all20-r4-browser.jpg`: 최종 선택본 20명의 실제 브라우저 알파 합성 목록.

비교 문서는 캐릭터 필터, 어두운/밝은 체크무늬, 130px 축소 보기, 이미지 터치/Enter 확대를 제공한다. WebP는 같은 크기의 보기용 인코딩이며, PNG 원본은 그대로 보존했다. 130px 보기는 문서 안 정적 축소 점검이며 실제 게임 카메라 검증은 아니다.

## 추가 수정과 선택 판단

- Sky / Vulcan / Onyx / Tempest: 두꺼운 벡터형 외곽선과 매끈한 명암을 미세 픽셀 경계·명암 덩어리로 다시 그렸다.
- Jade: 피부의 긴 흰 반사 띠를 줄이고 면과 픽셀 명암으로 정리했다. 피부 재질의 세부 평가는 여전히 원화 검토 대상이다.
- Gale: 픽셀 재질 수정에 이어 R4c에서 발 간격을 좁히고 땋은 머리가 어깨 뒤로 내려오도록 고쳤다.
- Teal / Copper: 여백 확대 변형도 제작했으나 질감/광택 보존이 미흡해 선택하지 않았다. 기존 R4a를 유지한다. 이 두 원화는 상하 여백이 좁아 최종 스프라이트 패킹 전에 여백을 보완해야 한다. 여백 수정이 성공했다고 주장하지 않는다.
- 모든 초기·대체 후보는 작업 디렉터리에 보존했다. 선택용 ZIP에는 현재 선택한 PNG 20장과 비교·검수 자료 총 74파일을 담았다. 전체 대체안은 complete ZIP에 별도 보존한다.

## 실제 검증과 범위

- 총괄이 20명 원본·첫 수정·추가 수정안을 시각 확인했다. 일반 19명은 오른손 공/왼손 글러브, Onyx는 왼손 공/오른손 글러브와 보라 투구팔의 예외를 보존했다.
- 독립 검수는 첫 20명에서 손잡이 반전·중복 공·추가 팔다리 같은 심각한 새 결함을 발견하지 않았고 스타일·피부 재질·Gale 자세·여백 보완점을 지적했다. 그 근거를 위 추가 수정에 반영했다.
- 알파 모드·치수·바운드·SHA-256을 기록했고, 보기용 인코딩 뒤 PNG 원본 바이트가 바뀌지 않았음을 대조했다.
- 도구 미리보기의 알파 0 RGB가 갈색 번짐이나 흰 잔상으로 보이는 경우가 있었다. 실제 Chromium 체크무늬 합성은 정상 투명 영역이었다. 이 RGB 표시를 실제 결함으로 세지 않았다.
- 비교 화면의 40개 이미지, 필터, 확대 다이얼로그, 좌완 표시, 배경·130px 토글을 실제 브라우저에서 확인했다. 390×844, 844×390, 667×375, 1440×900에서 가로 넘침 0, JS 오류 0.
- 단일 HTML의 내장 이미지 40개 디코딩, 터치 확대와 외부 이미지 요청 0은 `portable-qa.json`으로 확인했다.
- 상태는 `concept_candidate`다. 정적 기준 원화 수정이며 기존 A/B 투구 시트의 모든 포즈, 5포즈 게임 카메라 적합성, 실제 사지 모션, 120프레임 아틀라스 완성을 의미하지 않는다.
- 추가 수정 6장도 독립 시각 재검수에서 후보 유지 GO를 받았다. Jade의 유광 느낌은 일부 남는다는 한계를 기록했다.
- 6명의 추가 수정으로 화풍 차이를 줄였다. 같은 픽셀 그리드·팔레트의 런타임 스프라이트 20명이 완성됐다고 주장하지 않는다. 실제 모션 제작 시 외곽선·픽셀 밀도·광원을 다시 맞춰야 한다.
- 모션 영상을 이번에 새로 시청·분석했다고 주장하지 않는다. 정적 원화의 `reference_mode`는 `not_needed_for_concept`다. 원화/모션 승인이나 게임 연결·main 통합을 기록하지 않는다.

## 근거 파일

- `independent-review.md`: 첫 20장 및 추가 6장 독립 시각 검수.

- `generation-records.json`: 현재 선택 20명, 실제 생성 파일, 사용 원본, 편집 지시, 해시·상태·이전 버전 추적.
- `generation-records-r4a.json`: 첫 20개 수정안 원본 기록.
- `additional-generations.json`: 재질/자세/여백 추가 편집 9개의 실제 출력·선택 여부.
- `character-review.json`: 캐릭터별 한국어 점검과 수정 내용.
- `alpha-inspection.json`, `alpha-check.png`: 초기 알파 측정과 실제 브라우저 합성.
- `review-encoding.json`: 현재 보기용 WebP와 원본 PNG 해시 연결.
- `browser-qa.json`, `portable-qa.json`: 실제 비교 문서 조작 검증.

기존 원화·게임 파일·모션은 덮어쓰지 않았다. main과 PR 68의 투수 기믹 구현에도 손대지 않았다.
