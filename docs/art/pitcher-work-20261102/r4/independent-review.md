# 독립 시각 검수 — 기준 원화 R4

검수 역할: motion_plan_review, 읽기 전용. 총괄의 생성 지시 외에 원본·결과 이미지와 실제 브라우저 합성 목록을 직접 확인했다.

## 첫 20장 검수

손잡이 반전·중복 공·추가 팔다리 같은 심각한 새 결함을 발견하지 못했다. Onyx의 좌완과 보라색 투구팔을 유지했다. Sky/Gale/Vulcan/Onyx/Tempest의 두꺼운 윤곽·벡터형 명암, Jade 피부 광택, Gale의 넓은 자세·공중 땋은 머리, Copper/Teal의 좁은 프레임 여백을 보완 우선순위로 지적했다.

## 추가 수정 6장 재검수

활성 기록의 새 6장과 최신 `all20-r4-browser.jpg`를 직접 확인했다. **concept_candidate 유지 GO**. 새 손잡이 반전이나 큰 신체 결함을 발견하지 못했다.

- Sky / Vulcan / Onyx / Tempest: 픽셀 경계와 분할 명암으로 바뀌어 R4a보다 개선됐다.
- Gale R4c: 발 간격이 실제 줄고 땋은 머리가 어깨 뒤로 내려와 자세와 무게 표현이 나아졌다.
- Jade: 연속된 긴 반사 띠는 줄었다. 어깨·허벅지의 유광 느낌은 일부 남지만 이번 후보 단계의 차단사항은 아니다.
- Onyx의 좌완·보라 투구팔, 나머지 5명의 우완 방향을 유지했다.

완전한 화풍 통일·게임 카메라·모션 적합성 승인 범위가 아니다. 알파 0 RGB의 도구 미리보기 잔상은 실제 결함으로 판정하지 않았다. 이 검수는 작가 또는 사용자의 원화 승인도 대신하지 않는다.
