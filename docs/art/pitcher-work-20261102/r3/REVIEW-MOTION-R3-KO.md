# 투수20명 모션 검수판 r3

사용자가 승인한 r2 캐릭터 방향으로 20명 전원의 투구 모션 후보를 제작했다. 좌완1명(Onyx), 우완19명이며 기존 명부의 투구폼을 유지한다. 원화의 10명은 문서상 확정 폼, 나머지10명은 제안된 기본 폼이다. 원래 명부에 없는 언더핸드를 새로 구현했다고 주장하지 않는다.

## 보기

`engine/review/traditional-gallery/portable.html`은 이미지가 포함된 단일 HTML이다. 투수를 고르고 경기장/인물 화면,130/400px,정상/½/¼속도,프레임 이동을 사용할 수 있다. 네트워크 이미지 로드가 필요 없다.

이번 결과는 관절을 잘라 변형하는 리깅 대신 전신 원화를 연결한 프레임 애니메이션이다.120개/60fps 타임라인 샘플은120장의 독립 원화가 아니다. 실제 제작/선택/파생 손/대기 재사용 수를 각 캐릭터 화면과 manifest에 구분했다.

## 수정한 문제

- 각자의 손·글러브·의상과 좌우완을 유지했다. 사이드암은 어깨 높이의 수평 릴리스로 구분한다.
- 투구75의 몸통을 유지한 채76의 빈손으로 바꾸고 공은 별도 장면 레이어로 날린다. 몸통 비교는 삭제 전 RGBA를 기준으로 한다. 이 검사는 해부학/미감을 자동 판정하지 않는다.
- Onyx는 공 뒤의 머리카락·소매가 함께 지워지던 부분을 새 국소 원화로 복구했다. 수정 영역 안의 몸통/머리카락은 의도적으로 바뀌었으므로 '몸통 전체 픽셀 동일'이라고 주장하지 않는다.
- 들린 발을 축발로 인식해 몸이 커지거나39도 기울던 정렬을 수정했다. 동일 시트 기준 크기와 제한된 회전으로 맞추며 필요한 이미지 여백 이동은 기준점도 함께 옮겨 경기장 위치를 보존한다.
- Amber64의 원본 신발 잘림은 해당 포즈를 선택하지 않는 방식으로 처리했다.50/84에 섞인 다른 셀의 클리트/머리카락은 추출 마스크를 정리했다.
- Tide70/73의 조기 빈손·잘못된 준비 포즈를 제외하고68의 쥔 손→75의 쥔 손→76릴리스로 연결했다.

## 검증과 한계

Chromium에서20명 선택과478개 포함 이미지 로딩을 확인했고,75/76/113을130·400px에서120회 이동했다. 정상 속도와¼속도는 약1.05초 동안64프레임/15프레임 진행했다. 최종 Amber50/84 수정 후에는 해당 구간과 전체 포함 이미지 로드를 추가 확인했다.

별도 시각 검수는20명의 릴리스/포즈 시트와 주요130px 경기장 구간을 대상으로 한다. 모든120프레임을 개별 관찰하거나 실사 영상으로 생체역학을 검증했다는 뜻은 아니다. Red20의 원본 머리카락 끝 잘림 등 원본 경계 플래그는 유지했다. 모션 후보의 사용자 확인과 본게임 적용은 별도 단계다. 이번 턴에서 게임/GitHub/main은 변경하지 않았다.

## 산출물

- `traditional/characters/ID/sequence-release-matched.json`: 각 투수의 선택 이미지와 기준점·공·타임라인.
- `traditional/source/`: 새 연결 원화40장과 Onyx 국소 수정 원화. Teal의 추가 전신 수정3장은 별도 파일.
- `source/`: 기존 승인 방향의 원화·마스터. `source-rigs/`: 각 캐릭터 고유의 바인드/손 원본.
- `traditional/motion-audit.json`: 파일·타임라인·알파 경계·균등 변환 검사. 시각 합격 판정과 구분한다.
- `engine/review/traditional-gallery/browser-qa-report.json`: 실제 브라우저 검사 결과.

배포 ZIP에는 선택된256px PNG와 타임라인,단일 미리보기,검사 결과를 담는다. 전체 해상도 제작 원화와 실패한 프로토타입은 이 작업 공간에 보존하며,실패한24부위 리그를 새 완료 자산으로 섞지 않는다.
