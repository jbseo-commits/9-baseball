## 범위와 판정 방식

이 문서는 `docs/art/benchmark/target/`의 **10개 목업을 완성하는 데 필요한 화면 아트 전체**를 다룬다. 저장소의 과거·미사용 파일 482개를 전부 신규 제작 목록으로 취급하지 않는다. 조사 기준은 GitHub 브랜치 `ag/20260928-red-rush-female-art`, 목업 원본 10장, `assets/`의 현존 파일, `src/duel/`의 import/CSS 참조, `work/qa-v15-title-ending/`의 실제 캡처다. 마지막 캡처는 작업 폴더에만 있고 GitHub 추적 파일이 아니다.

**상태:** `사용 중` = 런타임 참조 확인, `기존 후보` = 파일은 있으나 실제 사용 또는 화면 QA 미확인, `없음` = 목표 표현에 필요한 독립 에셋을 찾지 못함, `검수 후` = 기존 것을 먼저 비교해야 제작 여부를 결정할 수 있음. **파일 존재, 자동 QA 27/27, P2 완료 표기는 목업 일치 판정이 아니다.**

레드 러시는 현행 **여성형**으로 고정한다. 성별 차이를 목업 결함으로 기록하지 않는다. UI 위치·글자·상태 연결은 제미나이 담당이지만, 여기에는 UI가 필요로 하는 그림 에셋도 빠짐없이 적었다.

## 캡처·통합 품질 게이트 (이미지 업로드 외 필수 작업)

1. **10화면 현재 캡처:** 기존 자동 QA는 전투·지도·보상 4종 화면만 남겼다. 타이틀·덱·도감·홈런·강판·엔딩 6종은 목업과 동일 상태의 `412×743`, `844×390`, `1440×900` 비교 캡처가 필요하다.
