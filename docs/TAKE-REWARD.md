# 지켜보기 보상 — 다음 공 에너지와 추가 카드

사용자는 지켜보기가 스트라이크와 삼진 위험을 감수하는 선택이므로 에너지 보상에 다음 실제 전이의 추가 드로우 1장을 더 요청했다. 기존 기본 드로우와 에너지 3 충전은 스윙에도 적용된다.

아래 검증 기록은 최초 에너지 보상 구현의 기록이다. 추가 드로우의 영향도 분석과 후속 검증은 [TAKE-DRAW.md](TAKE-DRAW.md)를 확인한다.

## 구현 계약

- V10 MAIN RUN에서 지켜본 볼과 삼진 전 루킹 스트라이크는 다음 실제 투구의 에너지를 3에서 4로 올린다. 볼넷이면 다음 타자의 첫 공에 전달한다.
- 연속 지켜보기는 에너지 +1과 추가 드로우 1장만 예약한다. 남은 에너지나 보너스를 누적하지 않는다. 이후 스윙하면 그 다음 공은 기본 3으로 돌아간다. 기본 공 드로우 또는 다음 타자 4장 보충 뒤 추가로 뽑으며, 지켜보기 보너스만 손패 6장까지 허용한다. 손패가 이미 6장이거나 뽑을 카드가 없으면 추가 드로우는 0장이고 기존 카드는 버리지 않는다.
- 삼진, 런 종료, 투수 HP 0에는 보상을 예약하지 않는다. 새로운 전투는 기본 3으로 시작한다.
- 결과 화면의 잔량은 즉시 늘리지 않는다. 준비·선택·이어하기는 충전이나 예약 소비를 하지 않는다. 실제 다음 공/타자 전이만 예약을 소비한다.
- 기본 충전 3과 최대 4를 구분한다. 현재 공의 충전 상한 3/4를 보존해 지출·재접속 뒤에도 같은 분모로 잔량을 보여준다. 기본 손패와 일반 드로우 상한은 5장, TAKE 추가 드로우는 6장이다. 준비 횟수·기믹의 스택 상한·확률·투수 피해 공식은 유지한다. 손패 수를 쓰는 카드 효과는 늘어난 손패에 따라 달라질 수 있다.
- 저장 키를 유지하고 현재 공 상한과 다음 공 보너스를 선택적 필드로 추가한다. 예전 저장은 상한 3/예약 0, 잔량 0은 그대로 보존한다. 정수·범위·현재 잔량과 상한의 관계를 검사한다. V9는 기존 규칙을 유지한다.

## 독립 계획 검토

별도 reviewer는 에너지 +1, 미누적, 볼넷의 다음 타자 전달, 삼진·강판·새 전투에서 보상 차단을 권고했다. 결과 잔량과 다음 공 예약을 구분하고 고정 ‘다음 공 3’ 안내와 가이드의 스택 장수 설명을 갱신한다.

- 최종 `pnpm build` 통과(1090 modules), `pnpm check:dist` 통과(49.4MB / 50MB). 기존 500KB 초과 chunk 경고는 유지됐다.
- 실제 Chromium: 375×667·412×743·390×844에서 볼·루킹 스트라이크 보상 예약, 결과 잔량 0 재접속, 다음 공 4/4, 볼넷의 다음 타자 전달, 삼진 보상 없음, 실제 비용 4 스택 실행, 지출 뒤 0/4 재접속, 이후 기본 3 복귀를 확인했다. 보상 검사는 15/15 체크 통과했다.
