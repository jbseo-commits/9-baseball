# 공방 실험 main 병합 및 버티기 개선 검증

설계·소비 계약·직접 플레이의 한계는 [결과 문서](../../design/DEFENSE-LAB-REFINEMENT-20261023.md)를 먼저 읽는다. 이전 `defense-lab-20261022` 기록은 덮어쓰지 않는다.

- `runs.json`: A 고정 소스3ed0651의 정상3전과 별도 위기1전, 이후 B 플레이를 분리한다. 위기 전투·기능 검사를 정상 덱 강약 표본에 더하지 않는다.
- `ui-log.json`: 루트 파일럿이 CUA로 본 공개 AX/DOM 원본. 선택·준비·투구 중 동결·결과를 함께 보존하며, 표본 선별이나 강제 pending/저장 주입을 하지 않았다. 일부 라벨의 구 번호보다 실제 카운트/종료 통계를 우선한다.
- `B-play-plan.json`: 후속 플레이 전에 정한 정상 버티기914 재연과 별도 위기20261024. 정상 재연은 이미 배운 공을 포함하며 독립 밸런스 표본이 아니다.
- `normal-regression/observed-summary.json`: 별도 검수자가 일반 게임 시작→전투→보상→라커룸→다음 경로→리로드 이어하기를 확인한 범위. 전체3막 완주가 아니다.
- `responsive/responsive-summary.json`: 브라우저 뷰포트4종 실측. 가로 모드는 세로 화면을 축소하는 기존 제한이 있고, 초기 빈 장면 캡처는 안정화 후 재현되지 않았다. 실기기 검사가 아니다.
- A/B 테스트 및 build 결과는 파일명/소스 단계를 구분한다. 자동 고정 공 검사와 일반 엔진 차분은 실제 UI 플레이·삼진 구제·재미의 증거로 사용하지 않는다.

최종 검증·review·main 병합·배포 기록은 완료 후 함께 보존한다. 스크린샷은 실제 관측한 상태를 보여주며 ‘보호 파울’ 표식만으로 원래 삼진이었음을 주장하지 않는다.
