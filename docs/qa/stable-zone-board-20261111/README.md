# 9존 찌그러짐 수정

사용자 보고: “왜 존이 찌그러지는거지”. 대상은 PR #121의 플레이 프리뷰, 기준 커밋은 `16da8bc`다.

확정 후 선택판을 물리 투구 평면(210×323.4375)에 맞춰 비균등 변환하고 포털로 옮기는 코드가 원인이었다. 844×390 브라우저에서 선택판은 151.42×151.42px에서 106×163.27px로 바뀌었고, DOM도 교체됐다.

포털과 비균등 변환을 제거했다. 같은 중앙 조작판의 위치·정사각 비율을 결과까지 유지하며 SCAN·확정·결과 표시는 같은 칸에서 갱신한다. 상태 문구는 흐름 밖에 두어 조작판을 밀지 않는다. 크기 고정은 가로에만 적용해 기존 세로 회전 안내·호환 경로를 보존한다.

공·배트·접촉 좌표, 원화, 모션 순서, 시계, 엔진, 저장 코드는 바이트 동일하다. 조작판은 논리적인 코스 선택 UI이며 물리 충돌 평면을 뜻하지 않는다. 이전 DOM90의 물리 T 일치 검사는 `16da8bc`의 역사로 보존한다. 현재 UI의 검증 기준은 동일 노드·단계별 크기 안정성이다.

- 실제 엔진 결과 동일, 페이지 오류 0.
- 실제 카드 2장·지켜보기로 얻은 에너지 3의 카드 3장, 회전·리로드, 중복 입력 방지, 로딩 실패·지연 fallback, reduced-motion 경계 5/5 통과. 본편 저장 접근 0.
- 기존 7개 뷰포트 회귀 검사 119/119, 전체 250파일·1,730테스트 통과. 기존 smoke와 바이트 동일, Pages 빌드 54.8/60MiB.

브라우저가 탭 전환 중에도 visible 상태여서 실제 hidden-tab 검증으로 표현하지 않는다. 실물 휴대폰·청취·진동·상업성 판정도 아니다.

M22 원화 3/3·시각 후보 6/6·과거 실패·점수는 그대로 보존한다. 새 원화·아트 후보나 IMPROVED/BAR_MET 인증을 주장하지 않는다. 이번 변경은 사용자 요청에 따른 조작판 기능 수정이며 PR은 Draft로 유지한다.
