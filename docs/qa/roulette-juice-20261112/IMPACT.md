6. 스크롤: 영향 없음. 전역 overflow/height 수정 없음. 내부 장식이 문서 폭을 늘리지 않는지 확인.
7. 기존 흐름: 확인 필요. query-off 회귀, 여러 카드, 이어하기/결과/다음 경로 검증.
8. 테스트: 영향 있음. 공개 정보 경계, 감속 경계/단일 후보, 한 번만 나는 소리, 음소거/백그라운드/배속/언마운트, 기존 전체 회귀 및 실제 브라우저 촬영.
9. 빌드/배포: 영향 있음. 가벼운 SVG와 기존 Web Audio만 추가. 전체 테스트·smoke·production build·예산·Pages 배포 후 실제 공개 프리뷰 검증.

설계 검토: 별도 reviewer가 사전 점검. 호스트 타이머에 tick을 여러 개 쌓는 대신 기존 렌더 시계의 최신 공개 scanIndex/lockAge 하나만 관찰해 효과음을 낸다. 같은 atlas 준비/기능 래치가 소리와 시각을 함께 제어. 지연·음소거·숨김 이벤트는 소비하며 재생하지 않는다. LOCK은 코스만 확정하며 타격 성공/득점 연출은 실제 impact 이후 기존 판정만 사용한다.
