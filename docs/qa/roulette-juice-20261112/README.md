# 룰렛 탐색 → 확정 연출 개선

2026-11-12 KST. 사용자 요청은 레퍼런스 7개 검색과 실제 게임쥬스 개선이다. 같은 Draft PR121의 보호된 실제 게임 프리뷰에 적용하며 main 기본 화면을 활성화하지 않는다.

## 바뀐 경험

- 일정 속도로 한 번 훑던 표식을 **빠른 탐색 → 점점 긴 머무름 → 실제 목적지 확정**으로 바꿨다. 공개 후보만 이용하며 미리 정답 쪽으로 이동하지 않는다. 긴 준비 구간은 공개 순열을 반복하고, 후보가 하나면 가짜 회전을 만들지 않는다.
- 현재 칸의 밝은 가장자리와 직전 칸의 짧은 잔광을 분리했다. 투구 중 조작판이 지나치게 흐려지던 상태를 opt-in 프리뷰 안에서만 보정했다.
- 확정 칸 내부에 모이는 네 모서리와 국소 광량 펄스·작은 광선을 넣었다. 최초 120 가상 ms 동안 정착하고, 최대 520 가상 ms 안에 사라진다. 정사각형 보드·카메라·배우 좌표는 움직이지 않는다.
- 짧은 탐색 클릭음과 낮은 확정음을 분리했다. 기존 장면 시계의 최신 공개 표본 하나만 관찰한다. 음소거·숨김·지연 이벤트는 나중에 몰아서 재생하지 않는다. 탭을 숨기면 재생 중인 짧은 꼬리도 취소한다.
- 존 밖은 기존 밴드에서 같은 방식으로 확정한다. LOCK은 **코스 확정**이며 타격 성공을 뜻하지 않는다. 타격·HP·점수 효과는 기존 실제 판정의 impact 이후에만 나온다.

감속·펄스의 수치는 우리 게임용 설계 값이다. 레퍼런스에서 측정한 수치라고 표현하지 않는다. 예시 투구의 기존 경계는 LOCK 690 / 손 릴리스 950 / impact 1250 가상 ms로 그대로다. 확률·난수·카드 비용·피해·저장·엔진 시각은 변경하지 않았다.

- 새 효과음의 Web Audio 발생 시점·중복·취소와 녹음 신호를 확인했다. 청취·음색·인지적 싱크 또는 실물 휴대폰 소리/진동 품질은 검증하지 않았다.

- 세로는 기존 상태별 배치를 유지한다. 412×743/375×667에서 존4와 존밖9의 같은 LOCK 프레임에서 SVG 표시/숨김 전후 셀·보드·밴드 크기 영향 0px, absolute/pointer-none를 확인했다. 새 가로 게임 디자인의 세로 완성을 뜻하지 않는다.
