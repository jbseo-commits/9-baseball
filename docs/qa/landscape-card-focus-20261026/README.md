# 가로 원화·선택 효과 검증

이전 프리뷰4c04bfc에서 이어지는 가로 전용 개선. 기본 URL/세로/엔진/저장 형식/카드 에셋 파일은 유지한다. 로컬51938에서 브라우저UI로 조작했으며 생성 fixture는 자연 런/밸런스 증거가 아니다.

## 실제 화면

- 모든 custom art는 img/object-fit:contain, 기본/구 아트는 원래2×2 시트의한 셀을 clipPath로 제한. 다른 패널이 letterbox에 비치지 않는다. 이름·비용·순서·커버 glyph는 원화 사각형 밖에 있다.
- 568×320(내부568×288),844×390(844×358),1280×720(1280×688). 최종 채택은 acceptance.json. `full-art-seven-844`, `effect-linked-844`는 패딩 수정 전40.65px 셀을 기록한 초기 자료로 제외하며, 최종 `effect-linked-final-844` 이후는44px 이상이다.
- 긴 몸쪽 파워/조건부 피해,2S번트,주자 없음,준비2비용,공방+유지효과,빈 손패를 확인. 효과/조건/경고의 실제 텍스트 사각형이 조준판과 실행을 침범하지 않는다.
- `art-comparison.json`: 동일 정타노림/7개 버튼/844px. 이전 그림 상자9,077.99px²→새 전체 그림10,280.15px², 약13.24% 증가. 이전 상자는 이름이 위를 덮었고 새 그림은 가리지 않는다. 카드/화면 전체의 증가율을 뜻하지 않는다.
- `support-armed-*`: 같은 전투 세로/가로를 오가도 지원 대기 유지. 지원은 범위 추가이며 인쇄된 메인 효과를 얻는다고 표시하지 않는다.
- 실제4장 스택 타격 HP60→51/다음 공. 실행 중 효과·예측 숨김. 준비 실제 사용 에너지2→1, 볼/스트라이크/아웃 유지, 준비 효과는 손패 위에 남는다.
- 생성HP1 상태에서 실제 강판→보상→지도 스크롤→훈련 강화→다음전투→새로고침/이어하기. map-scroll.json의 실제 문서 스크롤을 확인했다.
- 기본320×568: 신규 원화/패널 노드0, page320×568 (`portrait-default.json/png`). 비교 세로에서도 원래 카드 crop과요약으로 돌아간다.
