## 실제 동작

- 첫 새 런의 자동 안내만 목표·흐름·커버 **3장**. 아웃 이월/3아웃 패배, 준비 공 미소비, 빈 선택 지켜보기, 재탭 해제, 번트 예외를 남겼다. 설정의 전체 **9장**·원문 수치·기존 확인 키는 유지했다.
- compact 지원 예산 초과는 비용 옆의 **빗금 친 ＋ 표식**. 비용 숫자와 버튼의 전체 접근성 설명을 유지한다. 카드 자체의 사용 불가와 다르므로 비활성화/전체 흐림을 추가하지 않았다. 실제 조건·에너지 부족·2S 번트 위험 문구는 유지한다.
- 제한 표식이 있는 공격을 누르면 기존 규칙대로 메인 교체가 가능하고, 해결된 지원 경고는 선택 요약에 남지 않는다. 단일 실행 및 원화 크기는 그대로다.

## 실제 새 런과 테스트 상태

새 로컬 사용자 → 시작 팩 → 3장 완료 → 지도 → 실제 첫 전투에 진입했다. 커트 장인 선택 뒤 재탭 해제→빈 선택 실행으로 1S/E3, 호흡 고르기 준비로 E3→2/1S 유지까지 확인했다. 이 플레이는 UX 확인이며 완주·균형 평가가 아니다.

[fixtures.html](fixtures.html)은 로컬 origin에서만 테스트 저장을 교체하는 명시적 버튼이며 production dist에 포함되지 않는다. 일반/공방 지원 후보를 실제 메인으로 바꾸고 실행되는 것을 확인했다. 별도 HP1/고정 공의 흐름 상태에서 실제 타격 → 강판 → [보상](fixture-reward-320.png) → 지도 스크롤414px([기록](map-scroll.json)) → [훈련 강화](fixture-training-320.png) → 다음 지도 → [다음 전투·새로고침 이어하기](fixture-next-battle-resume-320.png)를 확인했다. 생성 상태를 원정 실력이나 밸런스 증거로 쓰지 않는다.
