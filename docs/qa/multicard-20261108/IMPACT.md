# 여러 카드 탭 배치 복구 — 구현 전 영향도

요청: “일단 카드 여러장써서 막는게 없어졌네”. 최신main b25c361 기준 엔진/드래그 스택은 남아 있지만 vNext 일반 카드 탭은 메인을 교체하며, 에너지 부족이면 겹치기와 추가 버튼을 모두 숨긴다. 독립검토와 기존25개 관련 테스트로 이 계약을 확인했다.
