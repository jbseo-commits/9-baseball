- 667×375,740×360,844×390,1024×768,1440×900,1920×1080의 실제 브라우저: 중앙 존과 투수 전신 분리, 배우 가림 없음, 44px 이상 존/실행, 에너지가 손패 위, 실행은 스크롤 외부.
- 실제 카드 교체/재탭/존 선택, 지원 겹치기, 부족 에너지 잠금, 스와이프 종료 오선택 방지, 정보창 복귀 시 세로 스크롤 복원.
- 실제 엔진의 첫 공 바깥 높게 적중 → HP60→48. 메모리 검수의 생산 저장값 불변.
- Web Animations API로 CSS 펼침0/90/180/380ms 프레임 고정. JS 가상 시계가 CSS를 진행한다고 가정하지 않음. keyed 카드 DOM/동일 fan CSSAnimation 객체 보존으로 재탭 시 등장 재생 없음 확인. reduced-motion에서 fan 없음.
- 정확 적중/한 칸 차이/홈런/강판16프레임 캡처, 런타임 오류0. 공/접촉광/강판 마운드는 새 등록 메타데이터에서 동일 좌표 사용.
- 본편 기본/vnext 폴백의 준비·지켜보기·다음 공·저장/이어하기, 회전 선택 유지. 같은 seed 저장 상태 일치. 경로·보상·시설과 다음 경로 회귀 확인, 문서 스크롤 유지.
- 독립 reviewer: 입력·엔진 차단 문제 없음. P2 숨김 카드 표시 오류는 안정된 offset 경계로 수정하고 단위/브라우저 회귀 통과.
