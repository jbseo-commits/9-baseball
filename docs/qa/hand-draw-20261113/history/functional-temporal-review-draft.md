# 자동 카드 공개 기능·시간축 검토 — 초안

자동 열림과 순차 낙하라는 기능 목표는 제공된 6개 실행 사례에서 충족된다. 다만 모든 카드를 읽을 수 있다는 목표는 844×390의 세 카드 사례에서 충족되지 않는다. 정지 화면의 시각 품질 향상을 주장할 근거는 없다. 봉인 후 전달받은 결과인 `NOT_IMPROVED`, 평균 차이 `-0.0625`, 개선 축 2개를 그대로 유지하며 재채점하지 않았다.

## 확인 범위

- `live/report.json`의 실제 실행 표본·오디오 이벤트와 `three-844-0.5.webm`, `three-1280-1.webm`에서 추출한 시간 순서 프레임을 확인했다.
- 568×320 한 장 추가 사례는 실행 표본과 `take-568-1-settled.png`도 확인했다.
- 제품 파일은 읽거나 수정하지 않았다. 영상에 오디오 스트림이 없으므로 실제 청감, 음질, 오디오 파형의 클리핑은 판단하지 않았다.

## 기능 결과

| 사례 | 자동 열림 | 순차 낙하 | 새 카드의 착지 후 가시성 | 착지음 이벤트 |
|---|---|---|---|---|
| 844×390, 0.5×, 3장 | 확인 | 위에서 1→2→3 | 100% / 100% / 약 30.5% | 2회 |
| 844×390, 1×, 3장 | 확인 | 위에서 1→2→3 | 100% / 100% / 약 30.5% | 2회 |
| 844×390, 2×, 3장 | 확인 | 위에서 1→2→3 | 100% / 100% / 약 30.5% | 2회 |
| 568×320, 1×, 1장 추가 | 확인 | 위에서 진입 | 새 카드 100% | 1회 |
| 1280×720, 1×, 3장 | 확인 | 위에서 1→2→3 | 약 90.6% / 100% / 100% | 3회 |
| 844×390, 동작 줄이기, 3장 | 확인 | 생략, 즉시 표시 | 100% / 100% / 약 30.5% | 0회 |

실행 기록의 `autoOpened`는 6건 모두 true이며 별도의 패널 열기 클릭이 필요 없다는 결과와 일치한다. 모든 사례에서 오류 배열은 비어 있고, 기록의 `exactEngine`과 `productionPreserved`도 true다. 이 두 항목은 실행 보고서의 결과를 인용한 것이며 별도 코드 감사 결과는 아니다.

0.5× 사례의 새 카드 첫 비영(非零) 불투명도 표본은 약 4,388 / 4,603 / 4,820ms로 약 0.22초씩 벌어진다. 1×는 약 0.10~0.12초, 2×는 약 0.05초 간격이다. 첫 새 카드 생성부터 마지막 카드의 정지 표본까지는 각각 약 1.14 / 0.57 / 0.29초다. 프레임에서도 위쪽 진입, 카드별 시간차, 착지 후 정지가 확인된다. 동작 줄이기에서는 처음부터 불투명도 1, 이동 없음, 재생 중 애니메이션 없음으로 기록된다.

## 읽기와 잘림

844×390에서는 첫 두 카드의 제목과 효과가 안정된 상태에서 읽힌다. 세 번째 카드는 위쪽에서 내려오는 도중 잠깐 더 드러나지만 착지하면 본문의 대부분이 패널 하단에 가려진다. 도중 노출을 안정적인 읽기 상태로 볼 수 없다. 동작 줄이기 역시 같은 최종 잘림을 갖는다.

1280×720에서는 새 세 카드의 제목과 효과가 읽힌다. 첫 카드의 상단 일부는 에너지 패널 근처에서 잘리지만 주요 문자 정보는 보인다. 568×320 한 장 추가 사례에서도 새 카드의 제목과 효과는 보이며 제목이 두 줄로 나뉜다. 이것이 568에서 세 장 전체도 읽힌다는 증거는 아니다.

새 카드를 자동으로 펼쳐 주므로 새 정보가 생겼음을 알아차리기 쉬워진다. 반대로 우측 카드 묶음이 경기장 공간을 점유하고, 작은 높이에서는 세 번째 정보를 숨긴다. 읽기 목표를 완전히 충족하려면 작은 높이에서 세 카드의 제목·효과가 안정된 상태로 보이는지 추가 대응이 필요하다.

## 잘린 카드와 착지음

일반 모드 844×390 세 사례 모두 `1480Hz`·`2220Hz`의 짝을 이룬 착지 이벤트가 2회이며, 세 번째 카드용 세 번째 이벤트는 없다. 이는 최종 가시성이 약 30.5%인 카드에 착지음을 추가하지 않는 결과와 일치한다. 1280에서는 3회, 한 장 추가에서는 1회, 동작 줄이기에서는 0회다. 착지음 생성 여부는 확인되지만 실제 소리의 크기·거슬림·음질은 이 자료로 평가하지 않았다.

## 판정

초안으로서 기능 목표의 달성과 화면 제약을 분리해 보고할 수 있다. 자동 열림·속도별 순차 진입·동작 줄이기·잘린 카드의 추가 착지음 억제는 확인된다. 작은 높이에서 세 장 모두의 정보가 읽히는 목표는 남아 있다. 이 기능 확인을 화풍·구도·마감의 개선으로 바꾸어 해석하지 않으며, 기존 블라인드 시각 판정은 유지한다.
