# 추가 제작 결과 — 원본 보존·정정

기존28개 파일은 당시 원본 그대로 보존했습니다. 과거 보고서의 빨강/노랑 테두리 판정은 alpha1–2 RGB를 불투명 테두리로 해석한 문제가 있어, [별도 정정](extension/FRINGE-AND-REFERENCE-CONTROL.md)을 먼저 읽어야 합니다.

새 [접촉·연결 원화와 검수 기록](extension/README.md)은 정지 원화 검사까지 통과했습니다. 실제 게임 연결 후보는 독립 블라인드 비교에서 NOT_IMPROVED로 보류했습니다. 원화 수치 합격과 본편 적용 승인은 구분합니다. 기존 게임 화면을 교체하지 않습니다.

접촉은 사용자 허용 연장 후6/6, 연결은 별도 허용 연장 후5/5 제작을 사용했습니다. 원본 PNG·프롬프트·입력 가이드·검증 수치·시간 순서 재생·게임 연결 검토용 텍스트·6개 공개 비교 시트를 보존합니다. 상세 실행 기록은 `loop/autodev/runs/contact-sequence-20261111-kst0852.md`에 있습니다.
