## 실제 브라우저

공개 UI만 사용했다. 숨은 상태·localStorage 주입/변경, 난수 탐색, 결과 되감기는 하지 않았다. 브라우저 크기 지정은 실기기 터치/회전 검증이 아니다.

- 로컬 새 게임 → 한 방 승부 → 도움말 건너뛰기 → 로즈 페인트 전투 진입. 에너지2/2.
- 솔로포 각2, 바깥 낮게 계획: 공개 적중14–28%, 안타 시18~36 표시. 힘 모으기1의 사용 뒤 같은 공격을 낼 수 없다는 안내 확인. 이 시점 준비·공격은 실행하지 않았다.
- 타이밍 맞추기0을 실제 준비. 이어서 솔로포 각을 실제 1회 실행. 자동 다음 공 뒤 HP60→59, 0B1S0O, 집중+1 유지, 에너지2/2 확인. 짧은 판정 배너를 캡처하지 못했으므로 파울/헛스윙을 추정해 기록하지 않는다.
- 다음 공 정타 노림1 선택: [412px 화면](actual-plan-412.png), [AX](actual-plan-412.txt). 적중14–28%, 안타 시18~45. 추가 투구 없이 화면 검수.
