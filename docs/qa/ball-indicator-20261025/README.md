# 공개 화면의 볼 표시 겹침 보완

PR #58을 배포한 main `56a3a29`의 실제 저장을 320×568에서 열었을 때, 기세 배지가 볼 위치 표시를 가렸다. [수정 전 경계](before.json)와 [공개 화면](before.png)에 남겼다. 볼 표시와 기세의 교차가 `true`였다.

compact 전투의 기세만 우측 상단 60px 배지로 옮겼다. 불꽃과 실제 피해 배율을 남기고 중복된 다섯 칸·팝 애니메이션을 없앴다. 접근성 설명은 기세 수치와 배율을 모두 유지한다. 입력, 엔진, 저장, 전역 overflow 변경은 없다.

## 실측

[measurements.json](measurements.json)의 다섯 상태에서 기세와 볼 표시·투수·HP·의도 아이콘의 교차가 모두 `false`다.

| 상태 | 증거 |
| --- | --- |
| 일반 320×568, 기세 1 | [화면](after-320.png) |
| 일반 375×667, 기세 1 | [화면](after-375.png) |
| 보스 320×568, 기세 5 | [화면](max-boss-320.png) |
| 공방 320×568, 기세 5 | [화면](max-defense-320.png) |
| 가로 844×390, 내부 360×640 프레임 | [화면](landscape-844.png) |

320에서 배지는 x252~312, 투수의 오른쪽은 x249.328로 2.67px 떨어진다. 최대 배율 `×1.5`의 client/scroll 폭은 각각 30px로 잘리지 않는다. 배지 확대 애니메이션도 제거했다. 전투 문서는 세로 viewport와 같은 크기를 유지한다. 가로 캡처는 기존 세로 프레임의 축소 표시이며 실기기 터치 크기 측정은 아니다.

최대 기세·보스·공방 상태는 [로컬 전용 fixture](fixtures.html)로 생성했다. 프로덕션 origin에서 실행되지 않으며 실제 원정이나 밸런스 검증으로 간주하지 않는다.
