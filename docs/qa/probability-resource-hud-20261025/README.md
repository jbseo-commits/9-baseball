기준 main `d35ac74`. [구현 전 영향도](../../design/PROBABILITY-RESOURCE-HUD-20261025.md). 엔진·비용·확률·3아웃·저장 스키마·원화·전투 행 높이는 변경하지 않았다.

## 정보와 표시

- 확률의 색은 `courseHeat(publicFace)`에서만 결정한다. 드묾/가끔/자주, 공개 구간, 반올림된 정수%를 5단계로 옮긴다. 낱말·공 표식·숫자와 접근성 설명을 유지해 색만으로 읽지 않는다.
- `0~5%`는 옅은 청색, `0%`는 빗금 없는 별도 바탕, 미투구는 빗금, 단서 밖은 중립, 확정은 별도 톤이다. 0%를 불가능으로 취급하지 않는다. 기존 비compact 스타일의 raw share도 공개 face 기반 값으로 바꿨다.
- 결정 중에만 색을 표시하고 실행 후에는 새 색을 그리지 않는다. 숨은 실제 공/roll/반올림 전 수치를 읽지 않는다. 공개 읽기 상승이 결과 전에 색으로 새어 나가지 않는다.
- 메인 커버는 금색 외곽·번호, 지원은 점선·번호. 배경의 확률색은 선택 전후 같고, compact의 별도 커버 위험색은 숨겨 서로 다른 의미의 색이 겹치지 않게 했다.
- 헤더44px 안에서 B/S는 두 줄, **남은 아웃23px**, **현재 에너지22px**로 표시한다. 남은 아웃은 `3-shownCount.outs`이며 기존 착탄 전 동결을 따른다. 에너지는 기존 입력 시 지출 동작과 최대치·소비 표식을 유지한다.
