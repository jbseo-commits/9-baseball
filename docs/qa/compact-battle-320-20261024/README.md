## 실제 수동 원정 (127.0.0.1, 테스트 저장 주입 없음)

새 연결 야구 시작 → 지도 스크롤 → 아이보리 에이스60HP 진입. 손패 수평 넘김으로 작전 확인 선택·실행: 에너지2→1, 카드 한 장 보충, 카운트0/0 유지. 테이블 세터를7존으로 실행해60→45HP/1루. 히트 앤드 런으로45→29HP/1·3루. 테이블 세터+정타 노림 지원을 서로 다른 코스에 연결해29→13HP. 이후 파울/삼진 카운트 진행, 히트앤드런 사인 준비 유지 표시 확인. 마지막 주자 연결로 강판·승리까지 진행했다(총 1아웃, 실제 RNG 결과).

보상 참을성 선택·수령(덱9→10) → 지도 스크롤 → 줄자 이벤트 → 다음 전투 타격+8 → 지도 → 타격 훈련 → 주자 연결+ 강화 → 다음 지도. 새로고침·이어하기 뒤 같은 진행을 확인했다. 이 한 전투는 UX/흐름 회귀 확인이며 덱 밸런스 평가가 아니다.
