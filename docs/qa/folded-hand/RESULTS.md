# 오른쪽 접힘·펼침과 존 장착

검수일: 2026-10-29. 중앙 존과 전면 구장 유지, 오른쪽 접힘 → 부채꼴 손패 → 실제 커버 블록 장착을 검수했다. 게임 규칙·저장·실제 로스터 승인 목록은 변경하지 않는다. 이 경로는 명시적 샘플 배우 프리뷰다.

## 확인한 조작

- 667×375, 740×360, 844×390, 1024×768, 1440×900, 1920×1080: 구장/존의 접힘 전후 좌표 동일, 존 최소 44px, 가로 넘침 없음.
- 카드 탭 → 존 탭과 Chromium 실제 터치 입력으로 카드 끌어 넣기. 배치만으로는 투구하지 않음. 실제 3칸 카드의 2·5·8존과 장착 효과 좌표 일치.
- 삽입 효과는 root 좌표계를 사용. 새 카드 선택·해제·투구·회전 시 이전 효과 취소. 준비·비용 부족에서는 가짜 범위와 자동 접힘 없음.
- 실제 투구 결과 해설과 HP 60→48, 지원 카드의 별도 노림, Inspector 손패 스크롤 복원, 생산 저장 격리.
- 터치 드롭 직후 손패 다시 펼침 → 기본 스윙 첫 탭. 브라우저가 click을 생략하는 경우에도 손잡이 touch release로 즉시 열며, 뒤늦은 호환 click은 한 번만 무시.
- 빠른 실행은 실제 커버를 80ms에 고정하고 기존 투구 시계를 유지. reduced-motion은 이동 효과 없음. 세로 회전 시 기존 흐름의 손패가 inert에 갇히지 않음.

## 기존 흐름

기본 본편과 vnext fallback에서 준비·지켜보기·자동 다음 공·Inspector 일시정지·저장/이어하기를 같은 seed로 비교해 저장 결과가 같았다. 경로/보상/시설은 844×390, 390×844, 320×568의 9회 검수에서 스크롤과 다음 경로 이동이 유지됐다.

실제 Pages base production build와 60MiB 배포 예산, CSS 리소스 350개(폰트329·이미지21) 경로를 확인했다. 원화 품질을 낮추는 대신 동일한 가변 폰트 바이너리의 중복 선언을 빌드에서만 합쳤다. 정적 폰트와 개발용 원본 선언은 유지한다.

실행: `node scripts/qa-folded-hand.cjs`. `QA_BASE`와 `QA_OUT`으로 공개 프리뷰와 증거 디렉터리를 지정할 수 있다. 전체 테스트·smoke 보고서 결과는 validation.json에, 실제 화면 좌표/조작 기록은 browser.json에 보관한다. 테스트 수와 화면 검증은 재미·상업적 완성도의 증명이 아니다.

## 공개 프리뷰 확인

커밋 `dc9d259`, Pages 실행 `40871070112` 배포 성공 후 같은 6개 가로 크기에서 실제 터치 드래그·세로 스와이프·첫 헤더 탭·장착 좌표·HP 변화·저장 격리를 재검증했다. 공개 결과는 public-browser.json에 보관했다. 실제 JS는 `index-Be21Gfpg.js`로 로컬 빌드와 같으며, 한글 400/500/600/700/800/900 굵기가 모두 로드되고 이미지·CSS·폰트 요청 오류는 0건이었다(public-resources.json).

브라우저 포인터 캡처의 검증에는 가짜 pointerId를 발행하는 DOM 이벤트 대신 실제 CDP touch 입력을 쓴다. QA와 문서의 후속 커밋은 런타임 화면/게임 코드를 바꾸지 않는다.
