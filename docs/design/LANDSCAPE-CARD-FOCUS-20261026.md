# 가로 카드 원화와 선택 효과 연결

## 구현 전 결정

기존 PR62/가로 비교 프리뷰에서 이어 작업한다. main/기본 세로는 유지한다. 가로 손패는 원화 전체를 contain으로 표시하고 이름·코스트·순서·커버 표식을 그림 밖에 둔다. 기본 스윙/구 원화는 2×2 아틀라스의 한 셀만 보여준다. 844×390 이상에서 실제 그림 면적을 확대하고, 최소568×320/최대7개 버튼에서는 전체 원화와44px 조준·실행을 우선한다. 이미지별 원본 비율을 보존한다.

조준판 아래 선택 영역은 카드 이름→메인 효과/준비 효과/지원 범위→공개 예측/실행 불가 사유→단일 실행으로 이어진다. 지원 대기 카드는 인쇄된 효과가 발동한다고 표시하지 않는다. 기존 cardFaceOf·forecastFor·준비 피드백의 공개 모델만 사용하며 새 확률 계산/게임 룰/드로우 규칙을 만들지 않는다. 실행 중·착탄 후는 기존 정보 공개 게이트를 따른다.

## 검증

전체195파일/1,235테스트와smoke4종 통과, build58.7MB/60MB. 독립 검토에서 준비 카드 비용0표시 결함을 발견해 실제 cardCost로 수정하고 연결 회귀를 추가했다. 최소 화면의 '적중 시'와 긴 효과/조건/경고의 경계를 실제 측정했다. 844×390 동일 정타노림·최대7개 비교에서 전체 원화 표시 면적이 이전 그림 상자 대비13.24% 증가했고, 이름·비용은 원화 밖에 있다. 모든 카드/화면의 증가율이라고 일반화하지 않는다.

실제 조작: 지원 대기 A/B→4장 배치/실행(HP60→51)→다음 공, 준비(에너지2→1/카운트불변)→유지표시, 생성한HP1 전투→보상→스크롤 가능한 지도→훈련 강화→다음 전투→재개, PC1280×720, 원래320×568. `docs/qa/landscape-card-focus-20261026/README.md`와최종 acceptance.json 참조. 실기기 주소창/safe area/롱프레스는 별도 미검증이다.
