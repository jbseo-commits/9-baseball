## 구현 전 독립 검토 반영

- `cardText`의 모든 문구를 그대로 요약하지 않는다. 강화 watch의 레거시 손패 9장 문구와 단타 강화 예외가 MAIN RUN과 다르므로 새 요약은 정의의 효과/조건을 기준으로 작성한다.
- 한 줄 효과와 별개로 사용 불가·합산 비용 초과 사유를 시각적으로 남긴다. 번트 아웃 지불과 2스트라이크 파울 삼진도 남긴다.
- 확대 전후 카드 외곽의 위치·크기를 고정한다. 현재 높이 138px은 후보값이며 최종 미술규격으로 확정한 것은 아니다. 여러 지원 카드를 모두 키우지 않고 main/armed와 명시적 focus/hover를 중심으로 내부 아트를 확대한다.
- 기세/흔들림 idle 판정은 이미 계산된 표시 값(momentum/shaken)을 사용한다. 착탄 전에 엔진의 다음 결과를 누설하지 않는다.
- 기믹의 위험 요약은 항상 보인다. 카드 ⓘ는 카드 상세 전용으로 유지한다.
