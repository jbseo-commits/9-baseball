생성: 2026-10-13 · 근거: `src/duel/cards.js` + `src/duel/cards-v16.js` 정의와 `cardPower()` 엔진 계산을 `src/duel/card-face.js` 요약과 대조.

- `기본 요약` = 미강화 앞면 한 줄, `강화 요약` = + 앞면 한 줄. `조건` = 기본 조건 / 2S 포함 강화 조건.
- `대가·불가` = 코스트 + bunt/singles + requires. `근거` = 정의 gives 원문.
- 원칙: 조건부 파워(몸쪽/바깥/높은/낮은/한가운데/간파/흔들림/투스트라이크/초구/주자/겹침)는 조건과 함께 보존, singles/bunt 강화에 파워 +18을 날조하지 않음, watch 손패 9장 레거시 미복제, lure 지속(다음 스윙/타석 내)과 범위 확대 장타 손실은 상세에서 확인.
- 앞면 한 줄에 다 못 담는 고유 효과(드로우·흔들림·CONNECT 등)는 gives 원문을 살려 요약에 합쳤다. 전체 수동 상세의 기존 오문구는 엔진 근거 표시 문구만 좁게 고침.
