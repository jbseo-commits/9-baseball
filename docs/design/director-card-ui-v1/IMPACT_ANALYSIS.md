## 게시 전 UX 보완 영향도 — 2026-10-15

사용자의 추가 개선 요청에 따라 구현 전에 범위를 확장했다.

- UI: 손패 그림 안에 실제 역할(한 칸/세로 3/준비)을 표시하고 조준판 대비를 높인다. 결과에 작은 9존 기록을 추가하되 경기장과 다음 공 버튼을 가리지 않는다.
- 입력: 카드와 `+ 지원`을 위로 끌어 조준판에 배치하는 선택 동작을 추가한다. 탭은 유지한다. 수평 움직임은 손패 스크롤에 남기며 세로 방향이 확정되기 전에는 상태를 변경하지 않는다. 바깥 드롭·취소·포인터 손실은 계획/자원 무변경, 유효한 드롭도 실행은 하지 않는다.
- 규칙: 엔진 변경 없음. 지원 중복/주 카드/기본 타격/최대 3장 계약을 동일하게 적용한다. 결과 기록의 커버는 실행 전 복사, 착탄은 실행 후 공개된 `revealed.zone`만 사용한다. 범위 안을 안타로 단정하지 않는다.
- 저장/기존 흐름: 본편 데이터와 화면은 계속 비접촉이다. 드래그 상태는 메모리의 일시 상태다.
- 모바일/스크롤: 320/375px, 6장 수평 넘김, 작은 가로 높이, 버튼 접근을 재검증한다. 아래 여백은 `safe-area-inset-bottom`을 수용한다. 실제 휴대폰 터치 검증 여부를 별도 기록한다.
- 테스트: 드래그 취소·배치·합성 클릭 억제·수평 의도·지원 제한과 공개 전 착탄 비노출을 독립 문서 회귀 검사에 추가한다. 기본 탭/준비/결과/다음 공을 브라우저에서 확인한다.
- 빌드/배포: 같은 단일 HTML 경로를 유지한다. 갱신 파일의 문법/자체 포함 검사, build/dist 60MiB 예산, 게시 URL 검증을 반복한다. 본편 코드가 동일한 경우 전체 테스트는 이미 통과한 실행 근거를 유지한다.

## 격리 및 되돌리기

- 추가 범위: `public/ui-lab/director-card/index.html`, 이 문서 디렉터리.
- 다른 세션의 작업 폴더/브랜치/미추적 문서는 포함하지 않는다.
- 외부 CDN, 호스트 API, 로컬 절대 경로 없이 HTML 파일 하나로 실행한다.
- 되돌리기는 이 추가 커밋 단위이며 본편 규칙/저장 마이그레이션이 없다.
- 검증 결과는 `README.md`에 실제 실행 후 기록한다. 미실행 항목을 통과로 표시하지 않는다.
