# 9 Baseball 플레이 프리뷰 v6 — 심판캠 타자

기존 측면/정면 타자를 심판캠의 후면·오른쪽 뒤 어깨 구도로 새로 그렸습니다. 카드 안의 기존 그림과 v5 투수의 착지·수비 대기·다음 투구 준비는 유지합니다.

## 실제 변경

- 준비, 로딩, 앞발 착지, 골반 회전, 타격 직전, 접촉, 팔로스루, 마무리, 복귀 중간, 재그립, 번트: 새 투명 원화 11종.
- 타자의 등과 헬멧 뒤가 주로 보이고, 눈과 정면 얼굴은 보이지 않습니다. 양발은 타자석 안에서 마운드 방향으로 깊이를 갖습니다.
- 원화에서 관찰한 20개 관절·배트 좌표와 실제 신발 밑창을 등록합니다. 배트와 공의 접촉은 1340ms이며 판정은 그 전 공개하지 않습니다.
- 헬멧·등판·신발의 피부 변형 영역을 분리해, 배트나 반대편 다리가 해당 표면을 끌어당기지 않게 했습니다.
- 낮고 넓은 화면에서 구장과 인물의 비율이 달라졌던 문제를 동일한 카메라 축척으로 수정했습니다. 남는 공간은 어두운 구장 여백으로 처리합니다.
- 정면 타자 아틀라스는 실행·대체 경로에서 제거합니다. 새 그림이 없으면 명확한 오류가 발생합니다.

## 로컬 작업본 검토 자료

- `ballpark-play.html`: 이미지·스크립트를 포함하는 단일 실제 플레이 파일.
- `motion-review.html`: 실제 렌더러의 투구·지켜보기·헛스윙·파울·번트·다음 공 준비 검사. 결과는 검사용 합성 판정입니다.
- `batter-art-v6.js`: 수동 원화 등록과 표면 영역. 원본 1024×1536, 등록 평면 512×768.
- `generated-batter-v6.json`: built-in image_gen 제작 프롬프트 기록. 원본은 `assets/inbetweens/batter-*-v6.png`이며 contact-draft는 폐기 후보입니다.
- `motion-reference-v6.json`: 실제 MLB 영상에서 관찰한 시점과 해석, 한계.

실행되는 원화는 11개이며, 그 사이를 관절 기반으로 연결합니다. 수작업으로 모든 60fps 프레임을 그린 애니메이션이라는 뜻은 아닙니다. 카드의 규칙·비용·확률·저장 스키마를 변경하지 않습니다.

별도 시각 검수에서 마무리→복귀 사이의 목/등 변형과 배트의 끊김을 발견하여, 1940ms 복귀 원화를 추가하고 양팔 등록을 바로잡았습니다. 원화에 가려져 있던 배트 부분을 억지로 변형하는 방식 대신 완전한 독립 배트 PNG를 새로 그렸습니다. 몸 그림의 옛 배트는 실행 시 캔버스에서 마스킹하며 PNG 원본은 보존합니다. 새 배트는 몸 뒤에서 손·배트 끝을 따르는 하나의 연속된 변환으로 움직입니다. 배럴·손잡이도 소스 전환에 따른 좌표 튐이 사라졌습니다.

몸 캔버스에서는 마스킹 후 알파가 128 미만인 옅은 외곽 잔상을 제거합니다. 생성 PNG 원본과 내장 WebP의 알파는 보존하며, 이 정리는 실행 시에만 적용합니다. `generated-batter-unwind-v6.json`과 `generated-bat-v6.json`에도 추가 제작 프롬프트를 보존했습니다. 제작 도구는 built-in image_gen입니다.

## 게시 범위

프리뷰: https://jbseo-commits.github.io/9-baseball/previews/codex-ballpark-motion-v6-preview/

원본 새 PNG12개(타자11+독립배트1)는 preview-artifacts/ballpark-motion-v6/source-assets에, 검토 가능한 변경 소스는 이 문서의 source 폴더에 보존합니다. 단일 HTML 자체에도 실행 소스·48개 WebP가 내장됩니다. 실제 main 게임 파일은 변경하지 않습니다.

이번 Pages 실행은 검증된 v5 커밋을 별도 체크아웃해 이전 v5 프리뷰도 함께 보존합니다. 향후 main이나 다른 브랜치의 기존 배포가 이 보존 단계를 포함하지 않으면 프리뷰 경로가 사라질 수 있으므로 장기 호스팅 보장은 아닙니다.
