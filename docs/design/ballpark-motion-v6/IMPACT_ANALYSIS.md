# 변경 전 영향도 분석 — v6 심판캠 타자 프리뷰

작성 시점: 저장소 게시 변경 전, 2026-10-17. 대상은 별도 프리뷰이며 main 구현을 수정하지 않는다.

| 축 | 판단 | 대응 |
|---|---|---|
| UI / 레이아웃 | 프리뷰에 영향 | 기존 카드/입력 배치를 유지하고 경기장 카메라·타자 원화만 변경. 낮은 높이에서 구장·배우 공통 축척과 여백 사용. |
| 입력 / 제스처 | 프리뷰에 영향 | 버튼·탭·조준·재생 동작 보존. 실제 카드 선택→휘두르기→다음 공 및 리플레이 검증. |
| 게임 로직 / 밸런스 | 규칙 영향 없음, 표현 연결 확인 필요 | frozen engine hash 유지. 1340ms 단일 판정, 투구·타격 일치, 9존·파울·헛스윙·번트·지켜보기 회귀. |

신규 투수 제작 요청이 아닌 기존 남성 타자 카메라 수정이다. 신규 투수용 채팅 원화 승인/120프레임 제작 트리거를 소급 적용하지 않는다. 사용자는 새 에셋 제작과 실제 동작 수정을 요청했고 앞서 프리뷰 게시를 요청했다. main merge는 포함하지 않는다.

예상 회귀: 뒤로 돌아오는 정면 타자 fallback, 접촉 전 결과 노출, 번트 접촉 불일치, planted shoe 뒤틀림, 낮은 높이에서 구장/배우 투영 불일치, packed HTML newline hash 변경. 모두 프리뷰 단위로 격리하고 독립 검수 및 동적 화면으로 확인한다.
