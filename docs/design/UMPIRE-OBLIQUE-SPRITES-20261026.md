# 심판캠 사선 전투 — 구현 전 영향도

사용자가 sprite-gen 및 GPT 원화/GPT 이미지 스프라이트 경로를 선택했다. PR62 가로 프리뷰만 개선한다. 기존 카드/세로/엔진/저장 유지. 실제 MLB NLDS2024 심판캠을 재생·탐색했다. 준비에서는 옆가슴/어깨가 보이고 스윙 후 등이 돌아오는 관계를 새 타자에 반영한다. 좌타자 참고를 우타자로 단순 반전하지 않는다. 관측 영상은 신발/완전 복귀가 잘려 있어 발/복귀 검증 완료 근거로 쓰지 않는다.

## 9축

| 축 | 영향 및 대응 |
|---|---|
| UI/레이아웃 | 영향 있음: yaw를 가진 하나의 카메라로 plate/box/rubber/feet/contact 표시. 가로 전용 배우/배경 교체. 카드/세로 유지 |
| 입력 | 영향 없음: 기존 handlers/드래그/9존 조작 유지, 장면은 입력 미수신 |
| 게임/밸런스 | 영향 없음: 판정/확률/비용/HP/아웃/박자 불변. 추가 포즈는 시각 연결만 |
| 저장 | 영향 없음: schema/RNG/키/이어하기 유지 |
| 모바일 | 영향 있음: 568×320/844×390/PC에서 전신·배트·투수·타격접점 검증. 전경/후경 간격은 동일 투영에서 계산 |
| 스크롤 | 영향 없음: 전역 CSS 수정 없음. 전투 무스크롤/지도 스크롤 회귀 |
| 사용자 플로우 | 확인 필요: 전투→결과→보상→지도/시설→재개. A/B 시 선택/지원/조준 보존 |
| 테스트 | 영향 있음: yaw/가림/발/같은 접점, DOM/Pixi 릴리스, 프레임 rect/anchors/전체 타임라인 회귀 |
| 빌드/배포 | 영향 있음: canonical sprite-gen 추출/curated export만 반입. 기존 가로 runtime import 교체, 60MB 예산. 프리뷰만 배포 |

## 제작 및 카메라 계약

새 base 한 장을 기준으로 anticipation/swing/recovery 각4프레임을 GPT rows로 만든다. sprite-gen의 prepare/gen-set/extract/compose/curated export 및 동작 검수를 사용한다. raw를 등분 잘라 스프라이트로 대신하지 않는다. 실제 선택 rect·포즈별 baseline은 런타임 descriptor에 기록한다. 새 준비/로딩에 기존 리그를 사용하지 않는다.

세계 좌표는 +z 투수, +x 플레이트를 가로지르는 방향. 우타자는 왼쪽 box, 앞발 왼발/뒷발 오른발, 배트 손잡이는 왼손 아래/오른손 위. 가슴은 플레이트 쪽, 머리는 투수 쪽. 카메라는 yaw -20도 후보, 거리10m/높이2m, focal=min(3.6H,1.7W), plate y=.9H. optical centre는 배우 최대 범위를 잘라내지 않도록 모든 world 좌표에 공통 적용한다. DOM과 Pixi의 릴리스는 같은 atlas stance/release 값을 사용한다.

계획 독립 검토에서 손잡이 혼동, yaw만 바꾸고 원화를 유지하는 오류, 신발/복귀 영상 근거 한계, PC/작은 화면의 배우/조준 겹침과 전송 예산을 지적해 반영했다. 생성/추출/배포의 실제 결과는 후속 QA에 기록한다.
