## 남는 저해상도 잔차

PC에서는 정상 스윙 zone6/7의 impact−1ms에서 어두운 외곽이 각각6native px 겹칩니다. 흰 중심 공유는 없습니다.360×640에서는 정상 스윙 impact−4..−1ms의12개 zone/time 사례가 겹칩니다. 그중 zone6/−1ms 한 사례에서는 흰 중심도3native px 공유합니다. 나머지는 어두운 외곽입니다. 모두 precontact 원화7이며, 접촉 이후 결과별 궤도로 이를 숨기지 않았습니다.

브라우저 canvas의 가장자리 샘플링은 약1native px 차이를 보일 수 있습니다. 모든 경우1px 여유가 있다는 뜻이 아닙니다. 각4x PNG는 실제 원화와 helper 좌표로 만든 확대 진단 합성이며, 브라우저 전체 화면 캡처가 아닙니다.

## 원화 수와 복귀 한계

설치된 실제 helper21,408샘플에서 재생되는 고유 원화는30개이며, 보관 원화는36개입니다. 미재생 index는15/20/21/24/27/32입니다. 타격 전 hit/whiff 포즈 차이는0입니다. 상태표 합집합으로 부풀려 집계하지 않았습니다.

복귀19→33의 손 이동은 앞발 기준 약43storage px로 가장 큽니다. 픽셀 충돌 검사나 원화 수는 사람에게 자연스럽게 보인다는 판정이 아닙니다. 최종 플레이 영상에 대한 사람의 시각 평가가 별도로 필요합니다.

`summary.json`은 세 규격의 정확한 공유 사례·공 크기·간격·source SHA를 담습니다. 각 상세 보고서와 실제 sampler 보고서도 함께 보존했습니다. `installed-packet-data-diff.json`은 불변 원본 packet과 최종 wrapper의 접촉점/시간표 차이를 분리해 기록합니다. 이전390단독 묶음은 역사적 checkpoint이며, 현재 source SHA의 반응형 검사는 이 묶음입니다.
