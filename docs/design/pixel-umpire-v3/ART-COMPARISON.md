# V3 아트·동작 비교 근거

`803d248` 시점의 역사적 비교다. 최신 복귀·조명과 검증 한계는 [V4 기록](../pixel-umpire-v4/README.md)을 참조한다.

카드 일러스트와 원래 카드/9존 입력을 유지하면서, 타자 원화와 필드의 배치·모션만 검토한 개선 작업이다. 상업 완성도 판정은 별도다.

## 실제 참고 화면

- [Dimraeth Steam 공식 게임 화면](https://store.steampowered.com/app/2402680/Dimraeth/): 작은 배우보다 환경의 큰 명암과 빛을 먼저 읽게 하는 구성이 기준이다. 원화의 색 수나 확대 배율로 동급을 주장하지 않는다.
- [Holstin 공식 Steam 화면](https://store.steampowered.com/app/2235430/Holstin/): 후면 배우의 실루엣, 바닥의 국소 조명과 재질이 함께 읽히는 점을 비교했다. 장르·카메라는 그대로 복제하지 않는다.
- [MLB 실제 심판캠](https://www.mlb.com/video/best-of-ump-cam-from-dodgers-vs-mets): 실제 재생 3초/30초/45초 부근을 관찰했다. 포수 쪽 가까운 타자와 멀리 작은 투수, 플레이트/박스 축을 참고한 고정 후면 시점이다. 클립 전체를 분석했다고 주장하지 않는다.
- [MLB 구장 기초](https://www.mlb.com/official-information/basics/field), [공식 규칙 도면](https://img.mlbstatic.com/mlb-images/image/upload/mlb/ub08blsefk8wkkd2oemz.pdf): 17인치 홈플레이트, 6인치 간격, 4×6피트 타격 박스의 관계를 확인했다. 인용 PDF는 2019판이므로 현재 변경된 베이스 크기 등의 근거로 사용하지 않았다.

제3자 화면은 관찰 자료로만 사용했고 저장소의 에셋에 포함하지 않았다.

## 새 원화의 판단

V2의 큰 손/배럴 점프를 줄이기 위해, 실제 원근에 따라 배트가 짧게 보이는 중간 자세와 follow-through의 감속을 새로 그렸다. 머리와 옷·팔·다리 비례를 유지한 뒤 정확한 준비 자세 0으로 복귀한다. 허리까지 내렸다 올리는 복귀 후보는 제외하고 헬멧 위를 통과하는 한 번의 regrip arc를 선별했다. 포즈의 수를 맞추기 위해 중복·기각 그림을 재생하지 않는다.

독립 정지 이미지 검수에서는 후방 축, 몸통 회전, 배트 호, 신체 크기가 V2보다 안정적으로 읽혔고 즉시 기각할 인체 연결 오류는 발견되지 않았다. 다만 정지 PNG만으로 접지/필드 광원/복귀 리듬을 통과시키지는 않았다. 실제 축소 합성·원래 게임 재생으로 별도 확인한다.

## 원본과 런타임의 경계

built-in image_gen 생성 원본은 고해상도 raster이며, 손으로 만든 native pixel grid가 아니다. 원본을 보존한 채 공식 sprite-gen component extraction, 96색 공유 palette, hard alpha, 128 logical/256 storage의 2배 격자와 가역 row curation을 적용했다. 이 후처리는 손실 변환이다.

타자 source 36셀 중 authored timeline에서 선택되는 source는 30개다. source15/20/21/24/27/32는 원본으로 보존하고 재생하지 않는다. 접촉점은 실제 최종 그림의 목재를 다시 측정했다. 최종 runtime은 정상8 (191,78), 번트26 (197,82)를 양쪽 판정에 공통으로 사용한다. 투구 경로를 결과별로 밀어내지 않았다. 불변 수입 packet의 원래 접촉점과 최종 runtime 보정은 provenance에서 구별한다.

## 남아 있는 품질 한계

- 복귀에서 followB19→resetLift33의 앞발 기준 손 이동은 약43 storage px다. 더 작아진 한 번의 전환이지만 완전한 연속 원화와 같은 수준이라고 일반화하지 않는다.
- 셔츠의 가는 대각선 음영이 작은 크기에서 고른 질감으로 뭉칠 수 있다. 환경과 재질을 함께 다듬는 수작업 아트 패스는 별개다.
- 정상 헛스윙의 검은 공 외곽은 일부 샘플에서 목재 모서리와 접한다. 390×844 native 검사에서 공유 픽셀은 0이다. 짧은 PC에서는 impact−1ms 두 사례, 360×640에서는 impact−4..−1ms 열두 사례가 남고, 휴대폰 한 사례의 흰 중심도3native px 공유한다. 모든 배율 무충돌·1px 여유를 보장하지 않는다.
