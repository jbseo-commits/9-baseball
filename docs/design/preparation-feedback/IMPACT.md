# 준비 카드 피드백 영향도 분석 (구현 전, 2026-10-20)

범위: 원래 게임의 준비 카드 실제 뽑기 예고와 유효한 준비 효과 유지 표시. 카드 원화, 게임 규칙, 손패 한도, 저장 형식은 변경하지 않는다. 사용자는 팝업 없이 기존 화면 안에서 읽기를 요청했다.

## 표시 계약

- 뽑기 예고는 실제 받을 수 있는 수를 먼저 표시한다. 한도로 줄어들면 손패 한도 또는 뽑을 카드 부족을 설명한다. scout/calm/V16의 다른 효과·조건·사용 불가 원인은 유지한다.
- 준비 효과는 활성 상태만 표시한다. 집중·진루·생존·파워/HP 보정은 타석, 범위 일반은 다음 스윙, 강화 범위는 타석, 관찰은 이번 공에 맞춰 만료한다. 즉시 뽑기/스트라이크 취소/흔들림을 지속 효과로 표현하지 않는다.
- 미래 공의 실제 코스/결과나 더미 순서는 읽거나 노출하지 않는다. 타격 전 연출 동안 결과 만료를 미리 드러내지 않도록 기존 공개 정보 경계를 따른다.
- 효과가 없을 때 별도 빈 패널을 추가하지 않는다. 안내 및 사용 불가 경고를 효과 표시로 바꾸지 않는다.

## 구현 중 확정한 공간 배분

사전의 64px 고정안은 복합 효과가 숨는 위험이 있어 수정했다. 효과가 없으면 기존 64px, 있으면 최소 64px에서 실제 내용 높이만큼 요약 행이 커지고 같은 화면의 구장 1fr 영역이 그만큼 양보한다. 카드 176px와 행동 버튼 76px, 전체 화면 높이는 유지한다. 360×640의 합법적인 복합 4효과는 요약 76px/세로 초과 0px로 확인했다. 자세한 실제 결과는 QA.md에 기록한다.
