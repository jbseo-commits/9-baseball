# Ballpark motion v5 — 독립 플레이 프리뷰

[프리뷰 열기](https://jbseo-commits.github.io/9-baseball/previews/codex-ballpark-motion-v5-preview/)

카드 그림을 유지한 첫 상대 독립 전투입니다. 오른발 착지 후 무릎·골반으로 무게를 받고 수비 자세를 유지합니다. 다음 공이나 다시 보기에서는 별도의 두 걸음 복귀 뒤 투구합니다. 본편의 경로·보상·시설·진행 저장까지 통합한 버전은 아닙니다.

## 게시 구조

- 실행 파일: `preview-artifacts/ballpark-motion-v5/index.html`.
- 원본 로컬 검증본과 동일한 9,531,610 bytes, SHA-256 `3fc2506eccb9be40f67263d35d57e41ff2bbcb828f687c26d4a0740743b86b4b`.
- 해당 생성 HTML에만 Git 줄바꿈 변환을 끕니다. 커밋과 Linux 배포에서도 원본 바이트와 해시가 유지됩니다.
- 스타일·스크립트·실행용 그림이 파일 안에 들어 있어 별도 에셋 주소가 필요 없습니다.
- `preview-artifacts/`는 Vite/public 밖입니다. Pages가 이 브랜치의 프리뷰 루트에 index.html 한 파일만 복사하므로 본편 dist 예산을 올리지 않습니다.
- production root는 기존 방식대로 최신 main을 별도 체크아웃하여 테스트/빌드합니다. 일반 브랜치의 프리뷰 빌드 분기도 유지합니다.
- Pages의 현재 방식은 단일 활성 브랜치 프리뷰입니다. 다른 main/브랜치 배포가 이 프리뷰를 대체할 수 있습니다.

## 확인 범위

게시 전 로컬 v5 검사: adapter 39, UI 30, renderer 37, 합계 106/106 통과. 착지 지지/골반 압축, 발 그림자, 종료 후 수비 자세 유지, 다음 투구·리플레이의 두 단계 복귀와 자원 보존을 확인했습니다. 화면은 390×844 세로와 568×320 가로에서 스크롤 없이 표시됐습니다.

게시 파일은 다음 명령으로 해시·inline JS 문법·내장 이미지·외부 의존성·개인 경로를 다시 검사합니다.

```sh
node scripts/check-ballpark-preview.mjs
```

106건은 원래 구현 폴더에서 수행한 검사입니다. 이 PR은 같은 실행 파일의 게시와 배포 격리만 다루며 검사 수로 미감이나 자연스러움을 증명하지 않습니다. 실제 게시 상태와 라이브 확인은 `publication.json`에 기록합니다.

## 원화와 동작 참고

누적 새 원화 13장(투수 10·타자 3) 중 v5는 오른발 앞꿈치 착지와 양발 수비 자세 2장을 추가했습니다. 내장 image_gen으로 제작했으며 실행용 WebP는 원본 크기와 알파를 보존합니다. 원화·개발 소스·생성 기록·검사 캡처는 로컬 작업물에 보존되어 있으며, 이 공개 최소셋에는 개인 절대경로나 도구의 원시 결과를 포함하지 않습니다.

[MLB Paul Skenes 슬로모션](https://www.mlb.com/video/field-view-paul-skenes-pitching-in-slow-mo)의 약 20–22초에서 릴리스 후 오른발이 앞으로 돌아와 앞발 옆으로 내려오는 동작을 관찰했습니다. 한 투수의 관찰을 일반 생체역학 수치로 취급하지 않습니다.

모든 프레임을 새로 그린 애니메이션은 아니며 기존·새 그림의 선과 명암 차이는 남습니다. 실기기 성능, 실기기 회전·입력, Canvas 대체 경로의 기기별 화질은 별도 검증 범위입니다.
