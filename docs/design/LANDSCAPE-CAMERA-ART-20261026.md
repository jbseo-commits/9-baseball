# 가로 전투 카메라·타석 정합

범위: PR #62의 비교 프리뷰. 세로·본게임 기본값·카드 원화·엔진·저장은 유지한다. 기존 배경을 가로로 눌러 타석/홈플레이트가 납작해지고 타자 카메라와 맞지 않는 문제를 고친다. 새 후면 타자 전체 포즈와 배경을 별도 버전으로 제작하고 실제 런타임에 연결한다.

## 구현 전 9축 영향도

| 축 | 판단 | 대응 |
|---|---|---|
| UI/레이아웃 | 영향 있음 | 가로 비교 전용 필드/배우/카메라만 교체. 손패/조준판/실행은 보존 |
| 입력 | 영향 없음 | 타석/배경은 pointer-events:none. 기존 카드·조준 입력 유지 |
| 게임/밸런스 | 영향 없음 | 기존 결과/타임라인 그대로. 투영은 표시 좌표만 계산 |
| 저장 | 영향 없음 | 스키마/이어하기/RNG 변경 없음 |
| 모바일 | 영향 있음 | 568×320·844×390·PC 실제 축소, 포즈별 발·배트 잘림 확인 |
| 스크롤 | 영향 없음 | 전역 overflow 수정 없음. 전투 무스크롤 및 경로 스크롤 회귀 확인 |
| 플로우 | 확인 필요 | 비교 전환/전투 결과·보상·경로·시설 회귀 |
| 테스트 | 영향 있음 | 투영/포즈 매핑·DOM/Pixi 공통 접점·세로 격리 회귀, 전체+smoke |
| 빌드/배포 | 영향 있음 | 신규 PNG 원본 보존·런타임 최적화, 60MB 예산, 같은 PR 프리뷰만 배포 |

## 카메라 계약

배경의 종횡비를 보존한다. 홈플레이트/양쪽 타석/마운드/투수판/양발/타격 접점은 하나의 가로 전용 투영 모델로 정의한다. 새 타자는 후면 3/4 시점이며 준비·로딩·스트라이드·접촉·팔로스루·감속·복귀를 동일 시트에서 공급한다. 가로에서 구형 리그는 사용하지 않는다. DOM 대체도 같은 시트를 사용한다. Pixi 공착탄/임팩트/그림자/먼지 원점도 같은 타격/지면 좌표를 읽는다.

## 독립 계획 검토 반영

기존 배우 높이 비율로 계산한 공 접점/아크/VFX를 함께 고쳐야 한다는 지적을 수용한다. 구형 idle/load 리그와 DOM 대체의 옛 원화 복귀도 차단한다. 새 투수 제작·엔진/박자 변경은 범위에서 제외한다. 아트/모션 검증을 테스트 숫자로 대체하지 않는다.

## 제작 기록

내장 imagegen으로 투명 4×2 타자 포즈 시트와 인물/초크 없는 구장 배경을 생성했다. `assets/landscape-ballpark-v2/README.md`에 실제 프롬프트/원본/런타임 경로를 기록했다. 지면 초크와 마운드는 투영 SVG, 원화는 비율을 보존하는 별도 배경이다. 결과는 `docs/qa/landscape-camera-art-20261026/README.md`에 기록한다. 전체196파일1243개·smoke4·build59.5MB 통과. 독립 검토의 PC 배율/세로 그림자 지적을 반영하고 실제 PC Pixi 접촉을 재확인했다. main 병합은 하지 않는다.
