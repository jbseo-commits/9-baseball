# 같은 전투의 세로 / 가로 비교

## 구현 전 결정

기본 URL, 기존 세로 화면과 저장은 유지한다. `?battleLayout=compare`에서만 가로 전투 비교를 제공한다. 비교 호스트는 하나의 iframe을 계속 유지하고 논리 뷰포트만 바꾼다. 두 App/전투/자동 다음 공 타이머를 실행하지 않는다. 준비, 지원 대기, 조준, RNG와 저장은 하나다. 기존 화면을 검토한 뒤 최상위 회전 재로드 우회, 최대 7개 카드 버튼, 투구 도중 전환 잠금, 실제 뷰포트 측정을 독립 검토자와 확인했다.

가로에서는 왼쪽 경기장 / 오른쪽 9존 / 아래 손패 전체 / 오른쪽 아래 요약과 단일 실행을 사용한다. 기존 카드 아트와 배우를 재사용한다. 공은 조작 패널이 아니라 경기장 홈플레이트로 간다. 작은 가로 기준은 외부 568×320, 비교 도구 막대 32px를 뺀 실제 전투 568×288이다. 9존과 실행은 최소 44px, 최대 손패 6장 + 맨손 스윙 1개가 겹침·스크롤 없이 들어가야 한다.

## 9축 영향도 분석

|---|---|---|
| UI / 레이아웃 | 영향 있음 | 비교 내부의 가로 미디어에만 새 CSS, 원래 세로 DOM/스타일 유지. 실제 568×320·844×390·PC·320×568 비교 |
| 입력 / 제스처 | 영향 있음 | 기존 카드/조준/단일 실행 핸들러 재사용. 가로 손패는 전부 노출. 전환은 자식 확인 후 크기 변경, commit/FX/locked에는 차단 |
| 로직 / 밸런스 | 영향 없음 | 엔진·확률·비용·자동 진행 변경 없음. 공개 정보 표시와 착탄 게이트 유지 |
| 저장 / 불러오기 | 확인 필요 | 키/스키마/마이그레이션 없음. iframe src·key·전투 노드 동일, 비교 전후 선택/지원/카운트/저장 불변 검증 |
| 모바일 뷰포트 | 영향 있음 | 비교 모드에서만 기존 세로 고정 및 회전 재로드 우회. 기본 URL의 회전 안내 유지. 논리 크기와 실제 축소 크기를 구분 |
| 스크롤 / 오버플로 | 영향 있음 | 비교 호스트 잠금은 전용 wrapper에 한정. 전투만 no-scroll, 비전투는 동일 iframe의 세로 문서로 복귀해 지도/보상/시설 스크롤 유지 |
| 사용자 플로우 | 확인 필요 | 타이틀→경로→전투→보상→시설→다음 경로, 재개. 화면 전환으로 새 런/투구/저장 변경 금지 |
| 테스트 / 회귀 | 영향 있음 | 먼저 비교 라우팅/메시지/프레임 계산/기존 portrait 불변 실패 테스트. 전투 입력·기본/지원/준비·정보 경계와 실제 화면 QA |
| 빌드 / 배포 | 영향 있음 | 새 bitmap 없음. 전체 tests, smoke 4종, build/budget, 브랜치 프리뷰에서 동일 전투 A/B 확인. 기본 main은 변경 승인 전 유지 |

## 검증 기록

전체 194파일/1,227테스트, 최종 관련4파일/29테스트, smoke4종, build58.6MB 통과. 실제 브라우저에서 최대7개 카드와 44px 조준/실행, 동일 전투 선택/지원 대기 보존, 일반/공방 및 보상→지도 스크롤→시설→다음 전투/재개 확인. 최종 채택 측정은 `docs/qa/landscape-battle-compare-20261026/acceptance.json`, 상세 한계는 같은 폴더 README. 실기기 주소창/safe area/롱프레스는 브라우저 뷰포트 검증과 구분한다.
