# 수비 실험 — 규칙 검수와 사람 플레이를 분리한다

2026-10-14 · DESIGN_SPEC.md의 후보 A/B/C에 대한 **실행 전 검수 계획**이다. 아래 성공 조건/상황은 이미 관측된 결과가 아니다.

## 1. 세 비교용 덱

공통 6장: `place ×2, strike, setup, watch, scout`. 현재 시작 팩의 공통 토대를 이용하되 아래 추가 3장은 **실험용 비교 재료**다. 본편 START_PACKS를 수정하지 않는다.

| 비교용 덱 | 추가 3장 | 확인할 선택 |
|---|---|---|
| P 정타 중심 | place, slug, finisher | 확률 높은 현재 정타 vs 다음 장타를 위한 수비 조정 |
| L 연결 중심 | tableSetter, rally, finisher | 주자 보존/추가 진루 vs 수비 조성/회수 |
| S 희생 후보 | tableSetter, bunt, slug | 안전한 출루/진루 vs 아웃을 지불한 즉시 수비 급변 |

L에도 장타 작전을 넣는다. 진루 카드만 주고 자기 전진 페널티에 갇힌 모습을 ‘덱 정체성’으로 판정하지 않는다. S는 완성된 희생 덱으로 승인된 구성이 아니다.

진단용 첫 손패는 추가 3장+공통 place 1장+watch 1장으로 고정할 수 있다. ID는 전부 실제 9장 덱의 고유 ID여야 한다. 나머지 4장은 정상 draw에 둔다. 별도 squeeze/flow 사례는 전체 12종 whitelist 안에서 합법적인 진단 덱을 따로 구성한다.

고정 손패는 ‘할 수 있는가’를 검사한다. 자연 셔플은 기존 합법 셔플 방식을 사용하되 **실험 P/L/S 각각의 추가 3장 풀에서 최소 1장**을 첫 손패에 제공해 ‘실제로 자주 경험하는가’를 확인한다. 본편 START_PACKS power/link/hold의 원래 보장 풀을 잘못 호출하지 않는다. 제공 카드는 지정 9장 덱의 실제 ID를 사용한다. 두 결과를 섞지 않는다.

## 2. 비교 방법

- 같은 상황에서는 공개 투구 정보, 수비, 주자, 아웃, 카운트, HP, 에너지, 손패를 맞춘 A OFF/ON을 비교한다.
- 현재 투구의 hidden pending은 플레이어에게 보이지 않는다. 규칙 단위 검수에서만 강제 결과 fixture를 사용하고 영상/리포트에 fixture임을 표시한다.
- 같은 시드라도 선택이 달라지면 이후 카운트/드로우/공이 달라질 수 있다. 자동으로 ‘모든 이후 공이 같다’고 주장하지 않는다. 조건을 복제한 개별 판단 비교와 자연 경기 비교를 나눈다.
- 드로우 순서는 플레이어에게 공개하지 않는다. 테스트 작성자가 진단 순서를 통제하는 것과 실제 플레이어의 정보는 구분한다.
- 시작 덱 차이를 볼 때는 같은 수비/주자 상황을 사용한다. 시작 상황 C를 볼 때는 같은 덱으로 6개 조건을 본다.
- B는 같은 A 규칙·후보값에서 아웃 이월만 다르게 비교한다. 후보 숫자를 동시에 바꾸지 않는다.

## 3. 핵심 진단 사례

시드/생성된 상대/판정값은 구현자가 실제 실행 결과와 함께 기록한다. 아래는 상태 명세다. HP 숫자는 기능을 드러내는 **진단 fixture**이며 본편 밸런스값이 아니다.

| ID | 공개 상황과 손패 | 실제로 확인할 갈림/반례 |
|---|---|---|
| D1 정타 조정 | 후퇴 수비, 0아웃, 주자 없음, place/slug/scout, 에너지 3. 높은 행이 더 유력하고 낮은 행도 합법 코스 | 지금 유력한 높은 공을 노릴지, 다음 장타 페널티를 줄이기 위해 낮은 행을 노릴지. 항상 높은 행을 고르면 정타 조정 가설의 실패도 기록 |
| D2 세로 커버 | 후퇴 수비, strike가 높은/중간/낮은 행을 모두 커버 | 같은 열의 anchor만 바꿔도 커버는 같음. 전이가 anchor가 아닌 실제 적중 행에 따라 달라짐. 미리보기는 한 결과로 확정하지 않음 |
| D3 주자 회수 | 후퇴 수비, 1루 주자 1명, 0아웃, tableSetter/rally/finisher | tableSetter 단타는 기존 주자 1→2루에 공간 +1루, rally는 원래 1→3루에 공간 +1루로 홈인 가능. 새 타자는 +1루 대상 아님. 다음 수비는 한 단계 전진 |

| D5 희생 급변 | **후퇴 수비**, 1루 주자, 0아웃/0S, bunt/slug/place/watch. slug는 아직 미사용 | 성공 희생은 2→0과 주자 진루/아웃+1. 일반 진루의 2→1보다 빨리 수비를 바꿈. 다음 타자에게 실제 slug가 남아 있는지 확인. 이 사례로 자연 시작 빈도를 주장하지 않음 |
| D6 희생 포기 | D5와 같지만 2아웃 또는 2S, 또는 상대 HP가 지금 직접 안타로 강판 가능한 상태 | 아웃/파울 삼진 위험이나 즉시 승리 때문에 희생을 포기할 수 있어야 함. 희생이 무조건 정답인 설계는 실패 |

### 첫 세 공의 가설 사례 — 보장되는 시나리오가 아님

P: 간파로 공개 높이를 읽음 → 현재 정타의 적중 가치와 다음 수비 변화 중 선택 → 다음 타자가 그 상태에서 slug/finisher 또는 다시 정타를 선택.

L: 주자가 있는 후퇴 상황에서 tableSetter/rally로 추가 진루 → 기본 수비가 됨 → finisher로 피해와 다음 후퇴를 만들거나 주자를 보존하며 다른 선택.

S: 주자가 있는 후퇴 진단 상태에서 번트 성공을 선택 → 전진과 아웃을 확인 → 미사용 slug로 후속 공격. 번트 파울/미스/드로우 부재면 계획을 포기.

‘공’과 ‘타석’을 혼동하지 않는다. 간파/준비는 투구를 진행하지 않고, 파울이면 같은 타자다. 실제 기록에는 준비 액션·실제 투구·타석 종료를 나눠 적는다.

기본 수비/빈 베이스의 자연 시작에서는 S의 고유 급변이 첫 세 공에 나타나지 않을 수 있다. tableSetter가 먼저 수비를 전진시킨 뒤 번트를 쓰면 차별점이 없을 수도 있다. 이 경우를 숨기지 않고 시작 팩의 실제 체험 빈도 문제로 기록한다.

## 4. 기능 회귀와 경계값

1. depth 0/1/2에서 모든 지원 성향의 전이를 확인한다. 경계값에서 −1/3 같은 불법 상태가 생기지 않는다.
2. 높은/중간/낮은 실제 공, 광역/세로 커버, 관찰로 공개된 행/볼을 각각 확인한다. 확정 코스 누설 없음.
3. 성공 직접 안타, assistOnly, 홈런, sacrifice, 빈 베이스 번트, 3아웃 번트, 2S 번트 파울, 미스/파울/볼넷을 전수 확인한다.
4. BASIC/미지원 카드/준비는 공간 효과/이동 없음. 지원 여러 장이어도 전이는 1회. 강화도 중복 이동 없음.
5. HP +8/−4는 기존 최종 피해 이후·HP0/국면 판정 이전이다. 최소 1과 같은 pitchId 중복 적용 방지를 검수한다.
6. 추가 진루는 투구 전 기존 주자만. 이미 홈인한 주자, 새 타자, 만루/3루 주자, flow 준비, 원래 추가 진루 카드와의 조합에서 중복 득점 없음.
7. 추가 득점이 흔들림/통계/로그에 1회 반영되고 기존 runnersBefore 피해 압박 계산이 바뀌지 않는다.
8. 다음 수비는 다음 타자에서만 적용. 같은 타석 다음 공/재렌더/검사/회전/복원으로 중복 적용하지 않는다.
9. HP0/3아웃 동시 발생의 현행 우선순위 유지. 특히 희생의 제3아웃에서 진루/유인/실험B T가 발생하지 않는다.
10. B의 T는 유효한 성공 희생만, 기존 시작 아웃/일반 아웃/번트 삼진은 제외. 강판에 성공했을 때만 이월 조정.
11. C의 시드 hash는 기존 공/드로우 RNG를 소비하지 않는다. 1루 주자 ID와 현재 타자/라인업 중복 없음.
12. 착탄 전 HUD·선택 요약·정보 보기·aria·VFX에서 nextDepth/추가 진루/최종 피해/KO가 새지 않는다.
13. 실험 flag OFF에서 기존 정상 상태/행동 결과가 바뀌지 않는다. 실제 본편 저장 키를 읽어 이행/덮어쓰기 하지 않는다.
14. 375×667, 390×844, 360×640, PC 세로 iframe에서 원래 배우 접지/플레이트/9존 hitbox/카드/실행 접근성을 확인한다. 실기기 회전·브라우저 바·롱프레스는 별도로 미확인 표시 가능.
15. 본편 타이틀→경로 실제 스크롤→전투→보상→시설→다음 경로→이어하기, 관련/전체 테스트·smoke·build·dist는 변경 영향에 맞춰 실행한다. 실행 안 한 항목을 통과로 쓰지 않는다.

## 5. 사람 플레이 평가표

기존 플레이어와 처음 보는 플레이어의 결과를 구분한다. 인원 수·세션 길이·기기·경험을 실제 기록한다. 아래 항목은 합격률을 이미 측정한 표가 아니다.

| 관찰 | 기록 방법 | 실패 신호 |
|---|---|---|
| 수비 상태를 읽음 | 선택 전에 현재 수비와 유효 효과를 설명하게 함 | 이동이 장식으로 보이거나 안타가 아웃될 것이라 오해 |
| 현재/미래 가치 교환 | 어떤 선택을 포기했고 다음 타자에게 무엇을 남겼는지 질문 | 이유 없이 최고 확률/최대 즉시 피해만 반복 |
| 정타의 위치 선택 | 노림 위치·성공 확률 정보·다음 수비를 함께 기록 | 높은/낮은 행의 미래 차이가 행동에 영향 없음 |
| 연결의 주자 판단 | 주자가 없을 때/1루에 있을 때 같은 카드 비교 | 주자 유무가 선택에 영향 없음 |
| 희생의 가치/포기 | 유인과 아웃을 알고 선택/포기했는지 기록 | 항상 금지 카드 또는 항상 필수 카드 |
| 덱별 차이 | 같은 공개 상황을 P/L/S로 비교 | 덱마다 같은 성향 2장 자동 교대만 수행 |
| 조작 부담 | 실행까지 탭·오탭·상세 진입·설명 요청 기록 | 추가 확인/팝업/스크롤 때문에 원래 플레이가 느려짐 |
| 결과 인과 | 피해/진루/다음 수비 변화 이유를 설명하게 함 | 피해 버그/공 재추첨으로 이해 |

최소 검토 묶음은 각 덱×현재 수비 3종×주자 없음/1루 2종이다. 진단 가능한 사례와 자연 셔플 사례를 따로 두며, 강제 조건을 쓴 성공 영상만 제출하지 않는다.

## 7. 진행 판정

A에서 현재/미래 가치 때문에 서로 다른 선택과 포기 사례가 관찰되고, 규칙을 설명할 수 있고, 기존 조작 부담이 유지되면 다음 단계 후보로 남긴다.

희생 가치만 부족하면 B를 분리 비교한다. 시작 체험 빈도만 부족하면 C를 분리 비교한다. 수비 상태 자체가 행동을 바꾸지 않으면 규칙 추가/보상을 누적하지 말고 A를 재설계하거나 폐기한다.
