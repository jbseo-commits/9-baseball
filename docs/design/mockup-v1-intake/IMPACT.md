# A01 에셋 준비 — 구현 전 영향도

기준: PR #63 / bb409c0. Claude Code는 전체 구현 계획을 전달받았으므로 이 작업은 독립된 intake 경로만 소유한다.

| 축 | 판정 | 대응 |
|---|---|---|
| UI/레이아웃 | 영향 있음(검토 도구만) | 비교 페이지의 구장·배우를 동일 좌표로 표시. 실제 앱은 연결하지 않음 |
| 입력/제스처 | 영향 있음(검토 도구만) | 포맷 비교 버튼·키보드 확인. 게임 입력은 변경하지 않음 |
| 로직/밸런스 | 영향 없음 | 엔진/카드/확률 파일 미수정 |
| 저장/불러오기 | 영향 없음 | localStorage와 앱 상태를 사용하지 않음 |
| 모바일 뷰포트 | 영향 있음(검토 도구만) | 320px 세로와 360px 높이 가로에서 비교·원근 검수 |
| 스크롤/오버플로 | 영향 있음(검토 도구만) | 독립 HTML에만 스타일, 본편 전역 CSS 미수정 |
| 기존 사용자 플로우 | 영향 없음 | 새 asset은 아직 게임에서 import하지 않음 |
| 테스트/회귀 | 영향 있음 | 원본/결과 해시·해상도·alpha 검사, 실제 브라우저 비교, 본편 필수 검사 기록 |
| 빌드/배포 | 확인 필요 | 직접 import할 WebP 후보를 만들되 shared optimizer/manifest를 건드리지 않음. 본편 빌드 크기 확인 |

독점 파일: `tools/art/mockup-v1-intake/`, `assets/production-art/mockup-v1-intake/`, `docs/design/mockup-v1-intake/`, `docs/qa/mockup-v1-intake/`.

Claude의 C01–C08, `src/`, 전역 설정, 기존 최적화 manifest, 계획 패키지의 WORKLOG/manifest는 수정하지 않는다. 검토용 원화 매핑과 실제 로스터 승인·모션·본편 성능 측정을 구분한다.
