# 확률 색 농도와 자원 HUD — 구현 전 영향도

기준 main `d35ac74`. 사용자 요청은 9존 확률을 색 농도로 읽고 에너지와 남은 아웃을 한눈에 확인하는 것. 카드 원화, 단일 실행, 팝업 없는 320×568 전투를 보존한다.

## 정보·표시 원칙

- 공개된 face 문자열만 색 함수에 전달한다. 낮은 읽기의 낱말, 확률 구간, 반올림된 정수%를 단계별로 표시한다. 실제 소수 확률·pending 코스/roll·전체 분포의 순위를 색 강도로 노출하지 않는다.
- `0~5%`는 가능한 구간, `0%`는 반올림된 숫자, `안 던짐/안 씀`은 닫힌 코스, `단서 밖`은 미공개, `확정`은 공개 단서다. 서로 다른 의미를 구별하고 0%를 빗금/불가능으로 만들지 않는다.
- 공개 확률은 청색/청록 농도, 메인 커버는 금색 외곽과 순서, 지원은 점선과 번호. 색만으로 읽지 않도록 기존 공 표식·공개 숫자·접근성 설명을 유지한다. 실행 이후에는 새 확률색을 그리지 않는다.
- 현재 에너지의 즉시 차감은 기존 비용 지불 동작이다. 이를 바꾸거나 엔진 스냅샷을 추가하지 않는다. 남은 아웃은 `3 - shownCount.outs`로 계산해 착탄 전의 기존 카운트 동결을 따른다.
- 헤더44px 안에서 B/S를 두 줄로, 에너지와 남은 아웃을 큰 숫자로 표시한다. 에너지 최대치와 기존 소비 연출 표식을 유지한다. 새 버튼·팝업·고정 행을 추가하지 않는다.
