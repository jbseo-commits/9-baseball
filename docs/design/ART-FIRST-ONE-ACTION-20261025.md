# 큰 카드 원화와 단일 실행

사용자 요청: 320×568 한 화면, 원화 확대, 아이콘과 중복된 문구 제거, 팝업/세로 스크롤 없음. 추가 명시: 휘두르기/지켜보기를 버튼으로 나누지 않고 빈 선택 제출은 지켜보기. 이전 본게임 반영 권한을 이어 검증 후 main에 반영한다. 기준658f1ce.

## 정보 원칙

카드 일반 설명은 모든 손패에 반복하지 않고 선택하면 고정 요약에서 읽는다. 비용·커버·주자/카운트 조건·번트2S 삼진·현재 비용 경고는 남긴다. 요약은 실제 메인 효과를 보여주며 지원카드의 일반효과를 발동하는 것처럼 설명하지 않는다. 공방 현재 제약/다음 예고와 보호·반격 상태도 보존한다. 실행 문구는 `실행` 하나, 현재 동작은 같은 요약에서 미리 확인한다. 무선택인2S 지켜보기는 스트라이크면 삼진이고 보호되지 않음을 명시한다.

구현 중 실측으로 카드 원화가 빈 영역 없이 펼쳐지도록 96×148px 영역에 이름·조건을 겹쳤다(이전84×56px 대비 약3배 면적). 작은 구장에서는 동일 카메라 단위로 구장/양 배우를 함께 아래로 이동해 머리 잘림을 피한다. 9존과 볼 표시는 구장 안에서 별도로 배치한다. 포커스로 hidden 구장이19px 내부 스크롤되는 문제는 전투 장면에만 overflow:clip을 적용해 차단했다. [검증 기록](../qa/art-first-one-action-20261025/README.md).
