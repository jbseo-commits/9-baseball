# 2에너지의 선택

기준 main: `8bbeb93`. 사용자의 기본 에너지 2, 일반 3칸 비용 2,
시그니처의 자원 효율 또는 넓은 커버 요청을 반영한다.

| 선택 | 비용 / 기회비용 |
| --- | --- |
| 일반 가로·세로 3칸 공격 | 2. 기본 공에는 한 장에 예산을 투자 |
| 정타 노림 + 정타 노림 | 1+1. 좁은 칸을 연결하고 지원으로 보완 |
| 유료 준비 + 정타 노림 | 1+1. 범위 대신 정보·타구 질에 투자 |
| 유료 준비 + 일반 3칸 | 1+2라 기본 공에 불가. 준비 효과를 유지하며 지켜본 다음 공을 노릴 수 있음 |
| 라인드라이브 / 끝장 승부 | 시그니처 비용 1. 기존 세로 3칸 / 1칸 강타 효과를 유지하며 지원 여유 확보 |
| 존 봉쇄 / 천둥 스윙 | 시그니처 비용 2. 기존 십자 최대 5칸과 각자의 효과 유지 |

일반 5~9칸 카드도 비용 2로 올려 1비용 광역 공격이 기본 선택이 되는 빈틈을 막는다.
기존 범위·파울·단타·강타 효과는 유지한다. 희생 번트는 안타 보장이 아닌 아웃과
진루를 교환하는 작전이므로 1비용 예외다. 강화·지원 여부는 비용을 할인하지 않는다.
`setup`·기본 스윙·지켜보기는 0비용이다. 새 카드나 희귀도 변경은 없다.

지켜보기의 생존 보상은 다음 실제 공에만 3에너지를 준다. 연속 지켜봐도 누적하지
않으며 삼진·투수 강판에는 지급하지 않는다. 추가 드로우와 타석별 준비 한도는 같다.

기존 저장은 현재 공의 3/4 상한·잔량·보상 예약을 보존한다. 불러오기 자체로 충전하거나
차감하지 않는다. 실제 다음 공·타자부터 2/3, 새 전투는 2로 시작한다. 누락 필드는
잔량과 상한을 함께 정규화하고 0을 보존한다. 저장 키와 버전은 바꾸지 않는다.
수비 실험은 기존 3/4 예산을 유지하고, 공통 카드 비용 조정은 함께 적용한다.
V9는 에너지 지출이 없고 V11의 스윙 한도 6은 유지한다.

## 구현 전 영향도

| 축 | 판단 / 대응 |
| --- | --- |
| UI·레이아웃 | 영향 있음. 같은 비용/에너지 함수로 손패·도감·미리보기·가이드 수치 동기화. CSS 변경 없음 |
| 입력·제스처 | 영향 있음. 비용 초과 표시와 실행 거부, 취소·재선택·무료 행동 접근 보존 |
| 로직·밸런스 | 영향 있음. 에너지와 비용만 변경; RNG·커버·피해·희귀도 보존. 정상 지켜보기 전이로 조합 검증 |
| 저장·불러오기 | 영향 있음. 현재 공 보존, 0·누락 필드·구형 3/4·다음 전이 왕복 검사 |
| 모바일 | 확인 필요. 작은 폰·PC 세로 iframe의 숫자와 행동 가능 상태, 회전 검사 |
| 스크롤 | 의도한 영향 없음. 전역 CSS·이벤트 변경 없이 손패/지도 스크롤 재검증 |
| 기존 흐름 | 영향 있음. 세 스타터의 실제 준비→대기→공격, 보상·시설·이어하기 검사 |
| 회귀 검사 | 영향 있음. 과거 3/4 기대값을 갱신하되 새 예산에서 가능한 조합으로 입력·효과 검증 유지 |
| 빌드·배포 | 확인 필요. 전체 테스트·smoke·production build·용량·CI·공개 파일 검증 |

## 검증

스타터 3종 × 100개 시드의 첫 손패 모두 실행 가능한 공격이 최소 2장 있었다.
이는 선택 가능성 검사이며 전략성·난이도·재미의 인간 플레이 검증을 대신하지 않는다.
최종 자동 검사·브라우저 검사·배포 근거는 PR에 기록한다.
