# 3아웃 공방 실험 전투

사용자 승인(2026-10-22): 3아웃을 유지하고 타석 보호·특수행동 봉쇄를 별도 실험 전투로 구현한다. 연결·버티기·한 방이 같은 적에 서로 다른 행동을 고르게 하고, 실제 UI 플레이 결과를 보고 수정한다. 본게임의 밸런스나 저장 형식을 확정하는 작업은 아니다.

## 근거와 성공 조건

- 이전 6런은 전부 패배했지만 파일럿·경로·보상이 달라 덱의 승률이나 강약 순위를 입증하지 않는다. 원자료는 `full-run-audit-20261021/review-summary.json`에 있다.
- 기존 커트·스트라이크 제거·흔들림·투수 기믹을 새로운 기능으로 주장하지 않는다. 새 실험은 공개된 적 행동에 개입하고 서로 다른 조건으로 위험을 다루는 관계를 검증한다.
- 같은 파일럿, 적, 초기 시드, 공개 의도 순환으로 비교한다. 덱 구성과 행동이 난수 소비에 영향을 주므로 모든 이후 공까지 동일하다고 주장하지 않는다.
- 정상 시작과 위기 연습(명시적 2아웃 2스트라이크)은 별도 기록한다. 회귀 테스트의 숨은 공 주입은 UI 플레이 근거로 사용하지 않는다.
- 보호 발동/제외/만료, 봉쇄의 실제 다음 공 이득, 덱별 다른 선택, 실패 후 복구, 생산 저장 보존을 확인한다. 재미와 상업적 성공은 이번 검사로 입증하지 않는다.

## 실험 계약

- 진입: 명시적인 `?experiment=defense`. 기존 전투 화면과 카드·선수·구장 에셋을 재사용한다. 메인 런 저장과 독립된 실험 저장 키를 쓴다.
- 적: 같은 레드 러시, HP 88(기존 2막 일반전 수치), 별도 보스 기믹 중첩 없음. 현재 공의 위치는 기존 공개 정보 규칙을 따른다.
- 의도: 실제 공 종료 때만 순환한다. 준비·카드 선택·렌더·새로고침으로 변경하지 않는다. 봉쇄해도 정상 투구와 의도 순환은 진행한다.

| 현재 공개 예고 | 봉쇄하지 못한 결과 | 적용 기간 |
| --- | --- | --- |
| 스택 견제 | 다음 실제 공에서 최대 스택 2장 | 다음 공 1회, 다음 타자여도 적용 |
| 압박 | 다음 실제 공 시작 에너지 -1, 기존 상한 유지 | 다음 공 1회 |
| 숨 고르기 | 추가 제약 없음 | 준비·회복 기회 |

- 이미 적용 중인 제약과 이번 공에 막을 수 있는 예고를 구별한다. 봉쇄가 현재 쓴 준비·카드의 비용이나 제한을 소급 취소하지 않는다.
- 덱: 기존 9장 시작 구성 + 공통 `defend`(커트 스윙) 1장. 기존 역할 페어와 공통 대응 카드의 첫 손패 보장을 설명한다. 정상 런의 덱/보상 풀은 바꾸지 않는다.
- 타석 보호: 2스트라이크에서 대응 가능한 메인 카드 사용 시 타석당 1회 활성. 존 안 커버 밖 스윙을 보호 파울로 처리한다. 존 밖 스윙·루킹·번트·지원만 적중은 제외. 그 공이 끝나면 소모되고, 파울로 보호를 재생하지 않는다.
- 연결: 실제 기존 주자 한 명이 최소 2베이스 이동하면 예고를 봉쇄하고 다음 타자에게 보호 1회를 전달한다. 여러 주자의 1베이스 이동을 합산하지 않으며, 홈인 이동량도 출발 베이스부터 센다. 비축 불가, 해당 다음 타자 종료 시 만료.
- 버티기: 공통 대응 카드 외에 커트 장인·파울팁·걷어내기도 보호 가능. 보호 파울 성공 시 예고를 봉쇄하고 해당 타석 다음 안타에 반격 +8을 준다. 한 번만 지급, 타석 종료 시 만료, 보호 재생/무한 드로우 없음.
- 한 방: 힘 모으기·거포 본능·예고 홈런의 실제 준비 투자 후, 기본 커버가 최대 2존이고 파워가 2 이상인 메인 카드가 직접 적중하면 예고 봉쇄. 공통 관찰/수급 준비와 지원만 적중은 조건을 충족하지 않는다.
- 보호 파울의 기존 파울 피해는 기존 연속 파울 감쇠를 따른다. 반격은 다음 안타에만 적용한다. 새 효과의 전후 변화와 만료를 결과 기록에 남긴다.

## 검증 기록

추가 영향도(짧은 PC 가로 창): 844×390에서 실험 전투의 고정 행 합계가 416px이 되어 실행 버튼이 잘린다. 실험 쿼리가 있는 PortraitFrame만 최소 논리 화면 320×568을 창 높이에 맞춰 축소한다. 본게임 프레임, 휴대폰 회전 안내, 저장 키는 변경하지 않는다. 리사이즈 복귀·정상 프레임 격리를 테스트하고 같은 크기로 다시 실측한다.

계획 검토: 독립 reviewer가 봉쇄 시점, 타석당 준비 횟수, 실제 진루, 힘 투자 조건, 보호 반복 발동, 실험 저장 격리를 검토했다. 현재 공의 판정 후 다음 실제 공의 특수 제약을 취소하는 계약으로 반영했다.

구현: `?experiment=defense` 진입, `9zone-defense-lab-v1` 저장, 동일 레드 러시/10장 덱/정상·위기 선택을 연결했다. 팝업을 추가하지 않고 기존 카드 이미지에 역할 표식을 붙이고 플랜 안에서 현재 제약·다음 예고·보호 소진·반격·힘 투자를 구분한다. 준비/선택은 예고 순환을 진행하지 않는다. 종료 시에는 다음 공의 봉쇄/전달 보상을 성공으로 세지 않는다.

### 수정과 회귀 결과

- 독립 검토에서 재현한 손상 저장의 hand/draw/discard/pending 누락, HP999, history `[null]`, preparations 누락을 거절한다. 실패하던 경계 검사를 먼저 고정했다. 잘못된 실험 저장은 실험 선택으로 복구하며 생산 키로 폴백하지 않는다.
