# 가로 한 전투 완성 — 구현 전 영향도 분석

사용자 요청: 가로 화면에서 전체 손패·기존 카드 원화를 유지하고, 팝업/스크롤 없이 선택·조준→투구→타격/실패→복귀가 이어지는 실제 전투를 구현한다. 세로는 유지하고 브랜치 프리뷰만 게시한다. 기준은 공개29e5108과 이전 미커밋 사선 카메라·14포즈 타자 후보이며, 후자를 덮어쓰거나 삭제하지 않는다.

## 계획 독립 검토 반영

2026-10-27 별도 reviewer가 최소 뷰포트의 툴바 차감, 임팩트 전 결과 누출, 동일한 임시 앵커, 회전·입력 상태 보존, 기존 팝업 진입 경로를 지적했다. 전체 손패 최대 상태와 긴 효과를 포함하고, 14포즈는 손발/배트 연속성을 실제 재생으로 판정한다. DOM/Pixi를 둘 다 확인하며 새 자산 형식 테스트만으로 자연스러움이나 상업 완성도를 주장하지 않는다.

## 첫 구현 범위

기존 실제 V10 전투와 같은 상태/handler를 사용한다. 가로 전용 선택 도크와 공간 배치, 공·포즈·반응 타이밍 및 복귀 앵커를 우선 정리한다. 새 카드/덱/적/밸런스 규칙은 추가하지 않는다. 구현과 검증 결과는 후속 QA 문서에 실제 결과만 기록한다.
