# V4 회복 동작·환경 조명 변경 전 영향 분석

기준: `803d248` / 기존 PR49 draft. 카드 일러스트·카드/9존 조작·엔진·저장을 유지한다. 신규 투수 캐릭터 제작이 아니라 기존 장면의 타자 복귀와 환경 통합을 개선한다. 기존 V2/V3 에셋은 덮어쓰지 않고 V4 후보를 별도 보존한다.

## 확인한 병목과 구현 방향

V3는 finish19→overhead33에서 손 위치가 크게 바뀌고, 후속 복귀가 앞발을 계속 고정한 채 손·배트의 작은 이동에 집중되어 있다. 손만 잇는 대신 감속→배트 내림→뒤꿈치 재접지→하체 정리→준비의 전신 중간 원화를 만든다. 지지발이 바뀌는 동안 위치가 끊기지 않게 한다. 이전 recovery가 다음 action의 지지발 정보를 읽는 위험도 함께 격리한다.

조명은 경기장 원화의 큰 명암과 광원을 다시 구성하고, 타자·기존 투수의 밝은 면/그늘과 바닥 그림자를 같은 우상단 주광·차가운 환경광 기준으로 맞춘다. 단순 전역 색 필터를 그래픽 완성으로 간주하지 않는다. 영상 관찰과 창작 동작 설계를 구별해 기록한다.

## 완료 게이트

인접 손·발·몸통과 마지막 READY 경계를 실제 runtime transform 뒤 비교한다. 사지를 늘이거나 opacity crossfade로 누락 원화를 숨기지 않는다. 접촉 전 궤도를 결과별로 바꾸지 않으며 기존3규격 충돌 잔차를 증가시키지 않는다. 새 포즈 수·테스트 수를 자연스러움이나 상업 완성도 판정으로 사용하지 않는다. 독립 사전 검토의 recovery context 위험을 반영한다.

## 최종 판단과 확인한 제약

새 원화12개와 구장 원화를 반입했다. 지지발을 일찍 rear로 바꾸는 후보는44→45에서 몸 전체가 약15native px 밀려 제외했고, 앞발을 READY까지 유지하는 배치가 더 안정적이었다. 이전 동작의 접지 context를 보존하는 코드와 접촉점 표시의 회귀 검사는 유지한다. 원래 계획의 지지발 전환 자체를 품질 목표로 고집하지 않았다.

전체174파일/1,073테스트·4smoke·build·dist59.1/60MB 통과. 실제390/360/PC,번트/지켜보기/기존 투수를 확인했다. 가로844×390에서는 기존 좁은 PortraitFrame/내부 스크롤을 확인해 제약으로 남겼다. 실기기 회전이나 수동 전체 경로 완주를 완료로 적지 않는다. 구체적인 좌표/영상/해석 한계는 [V4 검증 기록](pixel-umpire-v4/README.md)에 있다.
