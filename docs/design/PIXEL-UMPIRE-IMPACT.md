핵심 위험은 도트 크기 혼합, 프레임 전환에서 발/그립 튐, 공이 손·배트에서 분리되는 현상, 예전 아트의 이중 표시, 접촉 전 결과 노출, 다른 투수 정체성 손실이다. 이전 원본은 보존하고 후면 남성 타자·기존 레드 러시와 구장을 같은 도트 규격으로 제작한다. 새로운 투수 캐릭터/로스터 생성 요청이 아니므로 기존 캐릭터 정체성은 보존한다. 다른 투수의 기존 고유 원화를 공통 픽셀 표시에서 유지할 수 있는지 별도로 검증한다.

프레임 수와 자동 검사 점수는 상업적 완성도·재미를 입증하지 않는다. 생성 원본/추출 산출물/제작 프롬프트/표시 규격/검수 결과를 보존한다.
