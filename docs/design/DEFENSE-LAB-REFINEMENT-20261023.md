보호의 실제 UI 구제 표식을 확인하는 추가 기능 검사는 정상 비교와 분리했다. 시드914 위기에서 공개 최다 몸쪽3을 피하고 낮은 범위의 바깥쪽 높게2에 공통 커트 메인을 골랐다. 준비/지원 없이 최대3구로 제한했으며 숨은 공/roll/저장을 주입하지 않았다. 첫 공은 자연 파울 HP88→86으로 보호를 유지하고 스택 예고를 봉쇄했으며, 두 번째 커트 장인은 같은 낮은 범위에서도 안타 HP86→66을 만들어 반격을 소비했다. 타석이 끝나2S 검사 기회가 없어져2구에서 중단했다. 리로드 후에도 HP66·2아웃·반격 소비 상태가 유지됐다. 최초 설정 중 존 이름을 잘못 추정해 locator가 실패했고 공개 DOM 이름을 읽어 **투구 전** 검사 조준을 수정했으며 공/시드는 되감지 않았다.
