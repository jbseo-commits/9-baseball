## 3. 결정이 필요한 것 (목업과 현재 게임이 다른 곳)
- **D1 투수 성별·캐릭터**: 목업의 투수는 남성("불꽃의 강민호", 남성 레드 러시). 현재 로스터 12명은 여성 캐릭터(사용자 지시 "여캐 매력적"). **기본값: 여성 로스터 유지, 목업의 구조(칭호+이름, HP 게이지, 초상)만 적용.**
- **D2 타자 구도**: 목업은 대형 어깨 너머 타자. 현재 Pixi 측면 포즈 10장 + 스윙 타임라인. 바꾸면 타자 그림·애니메이션을 새로 만들어야 한다. **기본값: 측면 유지, 타자 크기만 키움(가능 범위).**
- **D3 카드 다이아 숫자**: 목업 카드 좌상단 1/2 숫자(코스트처럼 보임). 현재 게임엔 코스트가 없다. **기본값: 강화 단계(+) 또는 스택 순서 표시에 사용. 코스트 신설 없음.**
- **D4 코치 캐릭터**: 목업에 감독/코치 초상. 새 캐릭터 그림과 대사 톤 필요. **기본값: 도입(B2 생성 후).**
- **D5 보상 "추가 보상"(카드 제거/회복/강화/상점)**: 지금은 지도 시설. 보상 화면에 넣으면 런 구조가 바뀐다. **기본값: 넣지 않음.**

## 4. 로드맵
- **트랙 A — 코드만으로 (안티그래비티 큐 T1~T8)**: HUD, 9존 유리+연결선, HP 게이지, 카드 프레임, 동사 버튼, 보상 레어리티, 홈런/강판 스플래시, 코치 대사 판 틀. 각 항목은 품질 루프에서 목업 대비 IMPROVED여야 Ready.
- **트랙 B — 그림 (제미나이 지시서 B1~B6)**: 카드 일러스트 16장, 코치 초상, 지도 일러스트, 스플래시, (결정 후) 대형 타자. `asset-fix.mjs`의 **illustration 모드**로 정리(색 유지, 격자·배경·크기만 강제).
- 트랙 A가 틀을 먼저 만들고, B 그림이 들어오면 틀에 끼운다. 그림이 없는 동안 틀은 기존 글리프·텍스트로 동작한다 (저품질 임시 그림 금지, AGENTS §6).
