# 새 감사 문서 후속 적용

기준 main `40a0ee3`. 새 커밋은 화면 감사와 HUD 참고 문서만 추가했다. 감사의 화면 기준은 `71cafd1`이며 PR #58·#59 이전이다. 기존 단일 실행, 카드 원화 확대, compact 하단 예측·단계·범례 숨김, 지원이 없을 때의 스택 패널 정리를 다시 구현하지 않는다. 참고 문서의 외부 스크린샷은 원문 자체가 미확인이라고 명시하므로 세부 배치의 검증 근거로 쓰지 않는다.

## 이번 범위

1. compact 손패에 반복되는 `지원 비용 초과`만 비용 옆 표식으로 바꾼다. 비용 숫자와 전체 aria 사유는 유지한다. 이 카드는 메인으로 바꾸면 사용할 수 있으므로 비활성화하거나 실제 사용 불가 카드와 같은 흐림을 적용하지 않는다. 주자 조건, 2S 번트 삼진, 준비 횟수 소진, 실제 에너지 부족 경고는 유지한다.
2. 첫 새 런의 자동 안내는 목표·한 공의 흐름·커버 3장만 보여준다. 전체 9장 규칙은 기존 설정의 게임 방법에서 유지한다. 기존 확인 키를 바꾸거나 다시 안내를 강제하지 않는다. 새 전투 팝업·상황 팁 저장 키·고정 행을 만들지 않는다. 준비·선택 오류·지원 놓기·2S 위험은 기존 인라인 요약에서 계속 읽는다.

## 구현 전 9축 영향도

| 축 | 판단과 대응 |
| --- | --- |
| UI / 레이아웃 | 영향 있음. compact 지원 예산 표식과 첫 안내 페이지 수만 변경. 원화 영역과 조건 띠는 유지. |
| 입력 / 제스처 | 영향 있음. 초과 지원 후보를 눌렀을 때 기존 메인 교체를 유지. 안내의 이전/다음·키보드·스와이프·건너뛰기 유지. |
| 로직 / 밸런스 | 영향 없음. 실제 비용·피해·공수·지원 가능 여부 계산 및 엔진 불변. |
| 저장 / 불러오기 | 영향 없음. 런 스키마와 기존 WELCOME_SEEN_KEY 유지. 이미 본 사용자는 자동 안내가 다시 열리지 않음. |
| 모바일 viewport | 영향 있음. 320×568 및 390×844에서 비용 표식·이름·조건·실행과 안내 3장 실측. PC/가로 프레임도 확인. |
| 스크롤 / overflow | 영향 있음. 기존 compact 한 화면과 손패 가로 넘김을 보존. 안내만 짧아지고 지도/시설/보상 스크롤 불변. |
| 기존 흐름 | 영향 있음. 시작 팩→안내→지도→전투, 설정→전체 도움말, 이어하기와 선택 교체 확인. |
| 테스트 / 회귀 | 영향 있음. 첫 안내 3장·전체 9장·확인 기록, 지원 예산과 메인 불가 구분·메인 교체·실행 판정 회귀를 먼저 고정. |
| 빌드 / 배포 | 영향 있음. 의존성·원화·workflow 불변. 전체 테스트·smoke·build·독립 검토 후 PR와 공개 배포 확인. |

3장에도 HP 0 승리, 3아웃 런 종료, 상대 사이 아웃 이월, 빈 선택 실행=지켜보기, 준비의 공 미소비, 재탭 해제, 번트 예외를 남긴다. 고급 수치와 규칙은 전체 도움말에서 계속 확인할 수 있다. 첫 화면을 단순하게 보이는 것과 규칙을 바꾸는 것을 혼동하지 않는다.
