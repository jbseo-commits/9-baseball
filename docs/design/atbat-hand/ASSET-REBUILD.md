## 에셋 단위

1. 목업의 해·관중석·마운드·홈플레이트 기준점을 유지한 텍스트/배우 없는 구장.
2. 크림/네이비/골드 타자의 고해상도 준비 원화와 일관된 타격 동작. 개별 그림과 등록 좌표 보존.
3. 참고 목업의 샘플 투수 배우와 투구 동작. 실제 로스터 대체/승인으로 취급하지 않음.
4. 초기 손패와 주요 효과의 장면형 카드 원화. 이름/비용/범위/효과 문구를 원화에 굽지 않음.
5. HUD·카드·선택·실행의 별도 스킨 에셋과 같은 제작 규격.

미감 검수는 실제 완성 화면과 목업의 차이를 기준으로 한다. 테스트 통과를 목업 재현이나 상업적 완성의 증명으로 쓰지 않는다. 새 원화/실제 동작 수와 제한을 정확히 기록한다.

## 구현 시 추가 확인

- 목업처럼 타격/지켜보기 원형 버튼을 함께 표시한다. 기존 메인 실행 test ID와 엔진 콜백은 보존하고 두 버튼은 실행 latch를 공유해 혼합 연타를 한 번만 실행한다. 카드 비용 부족이어도 지켜보기는 가능하다. 메뉴·투구 중에는 실행하지 않는다.
- 고해상도 준비 이미지 아래 atlas를 계속 마운트해 첫 스윙의 늦은 디코딩 공백을 막는다. 샘플 투수의 deciding/flight는 coil 자세로 연결한다.
- 런타임 예산: 현재 어떤 카드도 사용하지 않는 family4개 eager glob만 제외한다. 현재 모든 카드의 기존 파일 매핑을 비교하는 회귀로 그래픽 변경 없는 절감을 검증한다. 원본 파일은 보존한다.
- QA 삽입 캡처는800ms 효과가 IPC/스크린샷 중 끝나는 경쟁을 막기 위해 테스트 시계만 멈춘다. 실제 투구 전에 재개하며 제품 타이밍은 늘리지 않는다.
