# 타석 중심 전투 화면 — 2026-10-29

승인 방향: 중앙 존·좌측 타자·중앙 투수, 우측 손패와 바로 위 에너지, 선택 카드→범위→실행의 단일 강조. 최신 채팅 목업을 구현하며 엔진 수치나 실제 상대 원화 승인 범위를 바꾸지 않는다.

## 구현 순서

1. 단일 공유 카메라의 안정된 타석 프레이밍, 존을 필드 위로 이동. 배우/그림자/공/VFX 동일 변환.
2. 오른쪽 손패 그리드 + 직접 선택 유지 + 스크롤 복원. 에너지와 실행은 고정.
3. 행동을 설명하는 신규 카드 원화 시트. 이름/비용/범위/선택/문구는 모두 live DOM. 나머지 카드 기존 원화 fallback.
4. 선택색 통일, 중복 요약은 작게, 결과 해설/차단 이유는 유지.
5. 실제 브라우저 가로 화면/입력/연출과 본편 플로우, 전체 테스트, build, 공개 프리뷰 검수.

## 사전 독립 검토

`atbat_plan_review` 읽기 전용 검토: 진행 가능. 작은 가로에서2열, 세로 스크롤 복원, 포즈 합집합 기반 카메라, 결과/부족 이유 유지, 모델 수치 그대로 사용을 반영한다. 메인만 편집한다.

## 채팅 중 구도 변경

후속 이미지3장에 따라 최종 손패는 그리드 대신 오른쪽 곡선을 따라 이어지는 가로 스트립이다. DOM 순서/선택은 그대로이며 장식 곡선은 입력을 받지 않는다. 전폭 field 카메라, 존만 hand rail 왼쪽으로 제한. 작은 가로에서는 회전을 빼고 세로 스크롤한다. 선택 카드 돌출을 위한 스크롤 영역 내부 여백을 확보한다. 새 구장/배우/공/접촉/강판 효과는 atbat-composition의 한 등록 정보와 카메라를 공유한다. 작은 가로 전폭 비율에서 모든 포즈를 보존하도록 worldHeight·발 위치를 재등록했으며 엔진과 로스터 승인 범위는 바꾸지 않는다.

## 펼침 동작

손패 최초 등장과 새 카드 DOM만240ms 부채 펼침, 카드별18ms stagger. 선택은120ms 전진과220ms 반사광, 존 노림은150ms 짧은 강조. 별도 펼치기 버튼/입력 잠금/엔진 대기 없음. 기존 keyed DOM을 유지해 재탭·정보창 복귀에 재분배 애니메이션을 반복하지 않는다. reduced-motion에서는 새 동작을 생략한다.

독립 완료 검토에서 fan 도중 변환된 경계로 읽은 숨김 카드 표시가 정착 후 남는 P2를 발견했다. 고정된 스크롤 레이아웃 offset으로 측정하도록 바꾸고, 첫 카드가 보이는 scrollTop0에서 위쪽 숨김 표시가 없는 회귀를 추가했다. 원본 배우·확률·저장·실제 로스터 승인 정책은 그대로다.

## 배포 경로 영향도 후속 확인

실제 Pages 긴 base의 URL 반복 때문에 로컬 `/` 빌드와 달리60MiB를 초과했다. 아트 품질을 더 낮추지 않고 Vite CSS 리소스만 `{relative:true}`로 출력한다. JS/HTML의 base와 public 경로 계산은 Vite 기본값 그대로다. 영향: CSS 이미지/public 폰트 URL, nested preview·본편 배포. 대응: 실제 Pages base 빌드, 모든 CSS 리소스의 실파일 경로 검사, 공개 브라우저의 이미지·font 로딩 확인. 엔진·입력·저장 영향 없음. 별도 reviewer가 설치된 Vite 구현의 CSS/public 상대 경로 계산을 확인했고 사전 검토했다.
