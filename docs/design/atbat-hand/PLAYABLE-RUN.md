## 연결 계약

- `battleUi=vnext` 본편에서는 실제 artId에 해당하는 기존 atlas를 사용한다. 샘플 배우 승인 목록을 몰래 채우지 않는다. atlas가 없는 상대는 기존 완전한 화면을 유지한다.
- 실제 투수는 기존 120셀/60fps 자료와 같은 host 가상 시계에 맞춘다. 공 출발은 기존 릴리스 시각을 사용한다. 새 타자/중앙 존/구장 좌표를 공유한다.
- `battlePlay=1`은 본편 Duel을 별도 저장소와 정상 시작 상태로 마운트하는 플레이 경로다. fixture/grant/import된 테스트 상태는 사용하지 않는다.
- 배속과 취소 가능한 판정음을 App 소유 시계에 연결한다. 새 화면에서는 이미 수행한 스택 확정 뒤 App의 두 번째 스택 연출과 고정 속도 홈런 영상을 겹치지 않는다. 기본 게임의 기존 경로는 보존한다.

## 독립 검토 반영

- 실제 선택된 atlas의 manifest를 사용한다. SD/Red Rush는79, PixelLab과 study/runtime은76프레임. PixelLab의 발·손은 원본 정규화 등록점, 나머지는 원화를 보고 등록한 근사 좌표로 JSON에 구별한다. 발 기준은 준비 자세에 한 번 고정하며 매 프레임 재중심화하지 않는다.
- renderer 적격성에 맞춰 배속/영상/스택 연출을 선택한다. defense·자동 시연·미지원 fallback은 기존 1배를 유지한다.
- localStorage getter 자체가 거부돼도 본편 오류 안내가 동작한다. 프리뷰의 backing 읽기만 가능하고 쓰기/삭제가 막힌 경우에는 최신 메모리 값과 삭제 tombstone을 우선한다.
- 플레이 경로의 오류 경계는 본편 저장 삭제 버튼이 없는 MemoryPreviewBoundary다. v10-relic-ui 전역 decorator의 본편 저장 읽기도 플레이 경로에서는 비활성화한다. BGM 선택·코치 완료 등 기존 UI 환경설정만 공유하며 게임 저장 키는 공유하지 않는다.
- 손패가 처리한 Esc를 App이 다시 처리하지 않는다. 실제 본편의 main/support/aim 유지 회귀를 추가한다.
