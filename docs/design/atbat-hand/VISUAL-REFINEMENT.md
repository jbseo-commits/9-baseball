# 목업 기준 시각 정리 — 구현 전 영향도

2026-10-29 사용자 피드백: 실제 게임도 목업처럼 정돈하고 AI 슬롭처럼 보이지 않게 한다. 구장·배우·중앙 존·오른쪽 접힘/펼침·장착 조작을 유지한다. 새 캐릭터나 장식 원화를 생성하지 않는다. 카드의 삽화/문구/범위 열, 글자 위계, 여백, 기호, 기본 배경을 일관되게 정리한다.

| 축 | 판정 | 대응 |
| --- | --- | --- |
| UI/레이아웃 | 영향 있음 | `.bv-refined` 한정 스타일. 카드 비용/삽화/문구/도식 겹침 제거, 패널 배경 축소, BSO/HP 위계, 단일 행동 강조. |
| 입력/제스처 | 확인 필요 | 기존 핸들/선택/드롭 콜백 유지. 새 카드 DOM에서도 드래그·상세·스크롤·키보드 검증. |
| 로직/밸런스 | 영향 없음 | 비용·범위·확률·피해를 모델에서 그대로 표시. |
| 저장/불러오기 | 영향 없음 | 표시만 변경. 기존 schema와 이어하기 유지. |
| 모바일 뷰포트 | 영향 있음 | 가로6크기, 44px 대상, 짧은 높이의 카드 조건·차단 이유 검사. |
| 스크롤/넘침 | 영향 있음 | 손패 내부 스크롤 유지. 전역 overflow 변경 없음. |
| 기존 플로우 | 확인 필요 | 본편 fallback과 경로/보상/시설/회전/이어하기 재확인. |
| 테스트/회귀 | 영향 있음 | 카드 표기·상세 접근·중복 문구 제거 회귀 및 실제 브라우저 6크기 검증. 이미지 decode/폰트 완료 후 캡처. |
| 빌드/배포 | 영향 있음 | Pages 실제 base, 리소스 경로/예산, 공개 프리뷰 확인. |

선택 강조와 실제 장착/투구 효과는 유지한다. 조용한 기본 UI가 연출의 대비를 만들도록 한다. 읽히지 않는 잔무늬·큰 배경판·반복 수치·서로 다른 이모지 장식을 추가하지 않는다. 실제 승인되지 않은 로스터 배우 매핑은 변경하지 않는다.
