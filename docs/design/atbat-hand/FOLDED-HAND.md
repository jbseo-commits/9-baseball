# 오른쪽 접힌 손패 → 펼침 → 존 장착

사용자가 2026-10-29에 지정한 기본 화면은 전면 구장·타자·중앙 9존이다. 오른쪽 손패는 접혀 있다가 손잡이로 펼친다. 이전의 하단 손패 해석은 이 지시로 대체한다. 펼친 손패는 기존 부채꼴 스트립을 사용한다. 카드 탭 후 존 탭, 또는 카드를 존으로 끌어 놓는 조작을 제공한다. 장착하면 실제 엔진 커버 칸이 카드에서 분리되어 맞물리고 손패가 접힌다. 투구는 기존 실행 버튼으로 확정한다.

## 구현 전 9축 영향도

| 축 | 판정 | 격리·검증 전략 |
| --- | --- | --- |
| UI / 레이아웃 | 영향 있음 | opt-in `.bv-atbat`만 변경. 구장 카메라 고정, 중앙 존과 실행 버튼은 접힘과 독립. |
| 입력 / 제스처 | 영향 있음 | 세로 손패 스크롤과 가로 드래그 구분. 탭→존 대체 입력, 취소·영역 밖 드롭은 실행하지 않음. |
| 로직 / 밸런스 | 영향 없음 | 기존 카드 선택·존 선택 콜백만 호출. 범위·비용·피해·투구 타이밍 수정 없음. |
| 저장 / 불러오기 | 영향 없음 | 접힘·이펙트는 컴포넌트 로컬 상태. 저장 스키마 수정 없음. |
| 모바일 뷰포트 | 영향 있음 | 667×375, 740×360, 844×390 포함. 손잡이·존 최소 44px, 회전 후 좌표 재측정. |
| 스크롤 / 오버플로 | 영향 있음 | 손패 내부 세로 스크롤 유지. 전역 overflow 변경 금지. |
| 기존 플로우 | 확인 필요 | 기본 본편 fallback 및 경로·보상·시설·이어하기 재검증. |
| 테스트 / 회귀 | 영향 있음 | 접힘 DOM 비활성, 선택·드롭·취소, 실제 범위·빠른 재입력·reduced motion 테스트. |
| 빌드 / 배포 | 영향 있음 | Pages 실제 base 빌드·60MiB 예산·CSS 경로·공개 프리뷰 확인. 가변 폰트 중복 선언만 정리하여 원화 품질 유지. |

연출은 판정기를 갖지 않는다. 선택한 커버만 사용하고 아직 공개되지 않은 실제 투구 코스는 읽지 않는다. 준비 카드·지켜보기는 범위 블록을 생성하지 않는다. 장착 이펙트가 진행 중이어도 실행 입력은 즉시 전달하며 별도 대기 시간을 추가하지 않는다. reduced-motion에서는 이동 대신 실제 칸의 정적인 테두리를 쓴다.
