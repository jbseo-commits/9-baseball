## 시간 계약

- 시작 시 playback/장착 효과에 배속을 고정한다. 투구 시계와 RAF는 가상 시간을 공유하고, 예약 시간은 남은 가상 ms/배속으로 계산한다. 지연된 소리를 버리는 허용 시간은 실제 시간 기준이다.
- 화면 내부 CSS animation/transition은 WAAPI playbackRate로 조절한다. class/childList와 실제 단계 속성만 관찰한다. 프레임마다 달라지는 SVG/style 속성은 관찰하지 않는다.
- 장착 수명·진동·스택 확정도 같은 배속을 사용한다. 소리는 시작 간격만 조절하고 음높이와 개별 타격음의 길이는 유지한다.
- body 카드 효과에는 프리뷰 전용 rate/signal/sound 옵션을 전달한다. 안전 삭제 시각도 배속에 맞추고, 완료·언마운트 시 잔여 효과를 취소한다. 기존 호출 기본값은 동일하다.
- 움직임 줄이기는 기존 60ms 정지 결과 경로를 유지한다. 배속이 이 설정을 해제하지 않는다.

## 독립 검토 반영

느린 배속에서는 판정음의 후속 음이 나중에 예약된다. 선택적 AbortSignal로 noise/crack/crowd/echo와 모든 oscillator를 추적한다. 음소거·숨김·fixture 재시작·새 연출·언마운트 시 미래 음원까지 중지한다. 기본 호출 일정은 유지한다.
