## 제약

범위는 카드 안 한 번만 표시하고 중앙 존에는 실제 드롭 후보만 얇게 표시한다. 정보가 이웃 카드 아래로 가려지지 않게 선택 카드의 면을 보호한다. 드래그 종료·취소·스크롤·메뉴·회전·투구 전환 때 후보 표시를 지운다. 장착 source는 바뀐 그림 방향과 실제 미리보기 rect를 그대로 사용한다. 접촉/착지/소리의 시간 계약은 바꾸지 않는다.

## 검수 반영

선택 정보 왼쪽에 겹치던 접기 핸들을 카드 바깥 위로 이동했다. 상세 아이콘의 보이지 않는 확장 영역이 그림 중앙을 가로채지 않게 하되 기존 상세 접근은 유지했다. 세로에서 손패를 펼치지 않았어도 Esc로 드래그를 취소한다. native implicit pointer capture가 자식 그림에서 손패로 넘어갈 때의 정상 lostpointercapture는 취소와 구별한다.
