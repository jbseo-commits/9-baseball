# 가로 전투 카드·코스 직접 선택 — 구현 전 영향도

2026-10-28 · 기준 f09f6ca · 사용자: 코스와 카드 선택이 번거로움. 코드상 원인: 두 번째 스윙 카드 탭이 비교/교체 대신 암묵적 지원 배치로 전환, 카드 미선택/준비 중에는 먼저 고른 코스의 표시가 사라짐.

방향: 가로 opt-in View의 기본 카드 탭은 메인 교체로 통일. 카드 겹치기만 명시적 선택 모드로 기존 지원 배치 재사용. 코스는 카드 선택과 무관하게 표시하고 카드 교체로 바꾸지 않음. 실행 확인은 기존 단일 버튼, 탭만으로 자동 타격하지 않음. 스와이프/드래그를 새로운 필수 입력으로 만들지 않음. 같은 메인 재탭은 유지하고 명시적 해제로 지켜보기 선택에 돌아간다. 해제는 실행 버튼 옆 고정44px칸에 두고 미선택/잠금 상태에는 비활성으로 남겨 연속 탭이 지켜보기 실행으로 바뀌지 않게 한다. Inspector·잠금·스택 제한을 보존한다.
