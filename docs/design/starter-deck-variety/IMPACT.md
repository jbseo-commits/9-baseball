# 시작 덱 다양성 — 선행 영향도 (2026-10-21)

사용자 승인 범위: 연결·버티기·한 방 승부가 실제로 다르게 플레이되도록 시작 덱 개선. main 2f4890d 기반. 새 런 선택 시에만 적용한다. 기존 저장의 덱·손패·성장, 카드 원화·효과·비용·피해/확률 규칙은 유지한다. 작업 브랜치/PR/프리뷰 게시까지 진행하며 이번 PR의 main 병합은 별도다.

## 원인과 설계

현행 9장 중 7장이 공통이다. 공통 2장(place/scout)과 방향 카드 7장으로 구성해 덱 간 카드 중복을 2~3장으로 줄인다. 같은 역할의 반복 주기를 위해 주력 한 종류는 두 장 넣는다. 7장이 모두 서로 독점이라는 뜻의 ‘전용’이라는 표현은 쓰지 않는다.

- 한 방: slug×2 / soloShot / gapHunter / loadPower / setup / watch. 좁은 강타, 빈 베이스 추가 피해, 준비 비용과 정보 선택.
- 연결: tableSetter×2 / rally / hitAndRun / flow / relayBat / watch. 출루 시 카드 회수, 주자가 생긴 뒤 추가 진루/지원 보상. 빈 베이스에서는 flow를 쓸 수 없다.
- 버티기: cutMaster×2 / foulTip / fightOff / wearDown / calm / benchCheer. 넓거나 좁은 단타 커버, 미적중 시 파울 생존/추가 피해. 일부러 헛치는 전략으로 설명하지 않는다.

첫 전투에는 역할쌍이 부족할 때만 최소 교환한다. 한 방: 강타(slug/soloShot)+힘 준비(loadPower/setup), 연결: 출루(tableSetter)+후속(rally/hitAndRun/relayBat), 버티기: 공격(cutMaster/foulTip/fightOff)+파울 압박(wearDown/benchCheer). 나머지는 seed 셔플을 유지한다. 기존 3-ID 시작 팩 기록은 옛 처리 그대로 두며 후속 전투/이어하기는 새로 보정하지 않는다.

## 평가 경계

기존 policy.planAction은 V16 준비·조건부 HP·지원 보상을 충분히 평가하지 않는다. 그 봇의 승률이나 기대 베이스를 세 덱 재미·밸런스 순위로 사용하지 않는다. 공개 정보에 근거한 선택, 실제 발동/포기한 대안, 카드 재등장을 구분해 기록한다. 첫 경기 검증을 후반 성장 다양성이나 상업적 완성도 입증으로 확대하지 않는다.

## 사전 독립 검토

동일 기능인 fullSwing/slug 중복, defend/cutMaster 상하위 관계, ‘전용’이라는 표현을 지적받아 위 후보로 수정했다. 팩별 역할쌍, 기존 3-ID save 분기, pile 보존과 pitchSeed 불변 검사 및 실제 플레이 검수를 반영한다. 아직 구현/검증 완료를 주장하지 않는다.
