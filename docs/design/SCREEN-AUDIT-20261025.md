## 다른 화면

- **타이틀**: 4개 버튼, 문제 없음.
- **시작 팩**: 3택 1 좋음. 설명이 길다 → 대표 카드 3장 + 한 줄.
- **첫 지도의 안내 9장**: 가장 큰 진입 장벽. 에너지·예약·추가 드로우·손패 6, 스택·CONNECT, 기세, 정확 적중, 주자 압박, 흔들림, 읽기 단계, 준비 2회, 아웃 공유가 한 번에 나온다 → **3장(목표 / 한 공의 흐름 / 덮으면 안타)** + 나머지는 처음 등장할 때 한 줄 팁.
- **지도**: 칸 종류·다음 상대 HP·"이 길 너머" 요약은 필요. 상단 BGM·주크박스는 설정으로.
- **결과**: `노림 → 실제 코스 → 결과` 한 줄과 강판 컷인은 유지. 자동 다음(1.1초)이라 읽을 틈이 짧다.
- **보상**: 카드 3장 + 넘기기, 투수 대사 — 유지.
- 상점·라커룸·사건 화면은 이번에 캡처하지 않았다(코드만 확인).
