# 가로 전투 연출 — 5단계 pilot 구현

기준 `96b6b85`, PR #66의 `codex/mockup-v1-c05-integration`. [구현 전 영향도](IMPACT.md) · [실행 검증·영상](../../qa/landscape-battle-cinema/RESULTS.md).

1. **타이밍/사운드** `presentation-clock.js`: 본편과 메모리 검수가 기존 presentation timeline과 cue를 사용한다. 하나의 취소 가능한 시계가 stage/impact/settle/complete를 소유한다. 지연·백그라운드 복귀에서는 오래된 소리/진동을 버린다. engine advance는 기존 controller에 남는다. RedRush/홈런 영상/강판 hold 정책을 보존한다.
2. **배우 동작** `motion-timeline.js`: 타자 14개의 직접 그린 포즈와 투수 5포즈(기존 coil 1개 포함). 준비→로드→체중 이동→배럴 진입→접촉→팔로스루→복귀. 발 anchor와 실제 배트/릴리스 event를 등록한 atlas 사용. 정지 그림 회전이나 120개의 독립 원화로 주장하지 않는다. [원본·등록 정보](../../../assets/production-art/landscape-cinema/README.md).
3. **공/접촉/실패** `scene-effects.js`: impact 전에는 결과와 무관한 공 접근만. 접촉은 그려진 배럴에 고정하고 결과 공개 뒤 실제 땅볼/파울/홈런 궤적으로 분기한다. 정확 적중은 국소 섬광·짧은 카메라 반응, 근접 실패는 통과 공·비접촉 잔상·기존 9존 경계 연결이다. 거리 계산은 실제 전체 coverage 기준 Chebyshev 1칸, 존 밖 볼은 제외한다.
4. **실제 카드→HP** `presentation-snapshot.js`: 실행이 수락된 직후 선택과 손패를 지우기 전에 사용 카드 기록. 실제 적중한 메인/지원과 실제 보너스만 확인한다. 접촉 이후 카드70ms/보너스145ms/HP210–230ms 순서. HP는 실제 전후 값과 잔상을 사용하고 오버킬은 실제 감소량으로 표시한다. 준비에는 준비 효과, 지켜보기에는 실제 결과만 표시한다.
5. **홈런/강판** `cinema-director.js`: 실제 홈런만 높은 타구 궤적·구장 빛·홈런 마무리. 실제 HP0만 settle 이후 마운드 초점·피로 포즈·강판 제목. HP 소진 전에 강판 제목이나 전용 소리를 재생하지 않는다. 연출이 게임의 보상/진행을 새로 결정하지 않는다.

## 확인 방법

프리뷰의 검수 선택에서 `연출 · 정확 적중`, `연출 · 한 칸 차이`, `연출 · 홈런`, `연출 · 강판 (HP 1 검수)`를 선택한다. 소리는 기본 꺼짐이며, 켠 뒤 `다시 시작`으로 반복한다. 소리 상태만 메모리에 유지한다. 홈런은 seed5의 실제 시작 팩/카드 행동이다. 강판은 명시적인 HP1 진단 상태에서 실제 공격으로 만든다. 일반 플레이의 HP/시작팩을 바꾸지 않는다.

## 인수 경계

가로 화면에서 선정 배우와 연출의 연결을 검수하는 pilot이다. `actor-coverage.json approvedArtIds=[]`는 유지한다. 실제 미승인 상대는 기존 완전한 화면으로 fallback하며 이 샘플 그림을 모든 상대에 배포하지 않는다. 전체 로스터 연결/G1·G2·G4, 실제 휴대폰 Safari의 소리·성능·손맛, 상업적 재미는 이번 테스트로 승인하지 않는다. 실기기와 사람 플레이 검수를 별도로 남긴다. 세로 화면은 재설계하지 않았다.
