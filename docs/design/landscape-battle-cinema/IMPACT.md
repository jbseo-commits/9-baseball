# 가로 전투 연출 — 구현 전 영향도 분석

2026-10-28 · 기준 96b6b85 · 사용자 요청: 조사한 전투 연출 원리를 아래 5단계로 순차 구현. 가로 휴대폰/PC 우선. 실제 판정·밸런스·저장 스키마 변경 없음.

## 순서와 인수

1. 본편과 검토 화면이 같은 presentation clock/timeline/cue 정책을 사용. 350/950ms 임의 프리뷰 제거. 취소·언마운트·background 복귀 중 중복 cue/진행 방지.
2. 선정 타자와 일치하는 새 그림의 준비/로드/스윙/접촉/팔로스루/복귀를 제작·연결. 타석 방향·그립·발 anchor를 검수. 정지 원화 회전만으로 완료 처리 금지.
3. generic 투구 접근 후 impact부터 실제 존/정확·근접 실패 공개. 국소 접촉과 공 통과/미트 반응을 구분. 실제 coverage 기준 한 칸 비교. UI에 두 번째 그리드/입력 단계 추가하지 않음.
4. 실제 발동 카드·공개된 피해만 짧게 순차 확인. HP 잔상/피해는 접촉 이후. 에너지·손패·단일 실행 위치 유지.
5. 실제 홈런·HP0 강판에서만 전용 타구/구장/종료 강조. 일반 결과를 홈런처럼 연출하지 않음. 무음/모션 감소에서도 결과 판독 가능.

새 원화/모션은 기존 명시적 메모리 검토 화면에서 한 타자와 샘플 투수를 사용한다. approvedArtIds=[]를 임의로 채우거나 샘플 투수를 실제 모든 상대에 연결하지 않는다. 사용자 이번 요청으로 가로 pilot 동작 제작·branch preview 연결을 진행한다. 과거 전체 로스터 G1/G2 완료와 혼동하지 않는다.

## 한계/증거 기준

상업적 재미·출시 품질을 테스트 개수로 입증하지 않는다. 실제 배우 동작과 소리 포함 영상, 느린 재생·접촉 프레임, 실제 공개 preview를 남긴다. 전체 투수 모션/로스터·실기기 Safari 검수는 실제 수행한 범위와 구분한다.
