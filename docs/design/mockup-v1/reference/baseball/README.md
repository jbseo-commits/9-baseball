# Actual batter's box references

Read and visually inspected on 2026-10-27. These references guided new original game artwork; the runtime uses the generated stadium/character PNGs, not the photographs.

## Official layout

MLB, 2026 Official Baseball Rules, Appendix 2, printed page 163 / PDF page 175:
https://mktg.mlbstatic.com/mlb/official-information/2026-official-baseball-rules.pdf

Observed: each batter's box is 4 ft across and 6 ft along the pitcher/catcher direction. Its inner edge is 6 in from the 17 in wide plate. The 3 ft + 3 ft division is at the plate's square/triangle junction. The plate's flat edge faces the pitcher; its point faces the catcher. The official rulebook and its rendered layout page are not bundled; consult the official URL above.

## Working perspective guide

`ground-layout.json` and `perspective-guide.svg/png` are a newly authored mathematical guide in feet. They project regulation ground dimensions into a provisional camera compatible with the old stadium. The final illustrated background approximates this guide and moves landmarks; runtime anchors were measured from the final art, not assumed to equal the guide. This is a visual reference correction, not a claim that every generated chalk pixel is regulation-exact.
