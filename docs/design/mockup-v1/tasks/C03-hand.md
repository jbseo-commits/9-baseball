# C03 — 손패와 에너지

담당: Claude Code. 선행 C01. 목표: 손패를 여는 단계 없이 카드·비용·차이를 한곳에서 판단한다.

**허용 파일**: `src/duel/battle-vnext/HandDock.jsx`, `BattleCard.jsx`, `hand.css`, `tests/battle-vnext-hand.test.jsx`. `cards.js`, card-art 전역 매핑, App/BallparkBattle 수정 금지.

## 구현

- 에너지를 손패 헤더에 한 번 표시한다. 실제 current/cap과 선택 비용·실행 후 잔여를 연결하며 결과에서도 위치를 유지한다.
- 카드 face는 비용, 그림, 범위 glyph, 이름, 짧은 효과, 필요한 조건/경고를 가진다. 효과는 기존 `cardFaceOf` 결과를 활용한다.
- 일반 효과를 전부 장문으로 펼치지 않는다. 조건/못 쓰는 이유는 잘라 숨기지 않으며 자세한 정보는 기존 detail callback으로 연결한다.
- 메인 주황/지원 청록에 더해 실선·점선·순서/문구를 사용한다. 색만으로 구별하지 않는다.
- 무료 기본 스윙 선택칩을 손패 헤더 근처에 유지한다. 별도 실행 버튼이 아니며 기존 기본 선택을 호출한다.
- 가로 스크롤에 남은 카드 힌트를 제공한다. 스와이프 후 click이 발생하지 않도록 기존 입력 정책과 연결한다. hover 없어도 선택·해제·상세가 가능하다.
- 입력 잠금과 비용 부족 이유를 구별한다. 정보창 복귀 후 부모가 선택/스크롤/포커스를 복원할 수 있게 ref/콜백 경계를 제공한다.

## 인수

- 손패 UI를 여는 탭이 없다. 에너지·손패 DOM은 각각 하나다.
- 카드 id/순서/선택 상태가 부모와 일치하고 스와이프가 무의식적으로 선택을 바꾸지 않는다.
- 긴 한글 이름·강화·조건부 카드·에너지0·조건부3의 fixture를 검사한다.
- 관련 입력 테스트 결과와 C05에서 검수할 667×375/320×568 위험 목록을 넘긴다. 카드 6개 원화만으로 전체 카드 그림 완성이라고 하지 않는다.

Claude 전달 문구: “C03만 구현해. 에너지를 손패 위에 붙이고 손패를 항상 보여줘. 기존 카드 데이터와 선택 콜백을 사용하며 새 자원/규칙을 만들지 마.”
