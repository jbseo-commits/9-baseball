# C04 — 9존·예측·단일 행동·결과

담당: Claude Code. 선행 C01. 목표: 지금 해야 할 일과 방금 일어난 일을 같은 영역에서 읽는다.

**허용 파일**: `src/duel/battle-vnext/DecisionPanel.jsx`, `BattleHud.jsx`, `ResultReadout.jsx`, `decision.css`, `tests/battle-vnext-decision.test.jsx`. 기존 SwingForecast 계산/엔진/공통 상태 수정 금지.

## 구현

- 9존에 공개 수준별 정보, 노림, 메인 커버, 지원 커버·순서를 표시한다. 결과 이후 실제 공은 같은 9존에서 강조한다.
- 9존 아래에 선택 이름/비용/공개 적중 예측/조건부 피해를 배치한다. `안타 시`와 `희생타 시`를 생략하지 않는다.
- 단일 주 행동은 `지켜보기 / 타격 / 준비 사용`. 무선택 설명, 선택 해제, 지원 대기, 비용 부족, 입력 잠금, 정보창 경합까지 CONTRACTS 표를 따른다.
- 기존 `data-testid="bp-swing"`, `data-action-kind`와 의미 있는 aria label을 유지하거나 통합자가 추적할 대체 매핑을 제공한다. 테스트 ID를 유지하기 위해 옛 전역 CSS class를 무조건 복제하지 않는다.
- HUD는 상대 HP/BSO/주자/읽기만 우선하고 에너지를 중복 표시하지 않는다. tell 한 줄과 당장 필요한 경고만 펼친다.
- 결과는 기존 resultExplanation과 실제 결과 snapshot을 사용한다. 최근 결과 한 줄의 표시 수명은 부모 계약으로 받고 독자적 다음 공 타이머를 만들지 않는다.

## 인수

- 세 행동 모두 화면 문구와 실제 콜백이 일치한다. 실행 버튼 수가 늘어나지 않는다.
- 낮은 읽기에서 정확 %/정답이 누출되지 않는다. 예상 HP를 확정 피해처럼 표현하지 않는다.
- 정확 적중/지원 적중/근접 실패/볼/루킹/희생타/강판의 실제 상태 fixture를 검사한다.
- 선택·결과·준비 요약이 겹치지 않으며 긴 결과 문구 처리 방식을 남긴다. 스텝 안내를 새 필수 클릭 단계로 만들지 않는다.

Claude 전달 문구: “C04만 구현해. 목업의 오른쪽 배치를 따르되 행동은 하나, 내용은 본편 공개 정보와 실제 결과로 보여줘. 숨은 정보·새 계산·자동진행 타이머를 추가하지 마.”
