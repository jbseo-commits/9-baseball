# C07 — 회귀·성능·테스터 인수

담당: Claude는 재현된 결함 수정, Codex는 독립 코드/화면 검수. 선행 C05; 정적 기능 검수는 먼저, 최종 G3는 C06 이후.

**허용 파일**: `tests/battle-vnext-*.test.*`, 제안 `scripts/qa/battle-vnext.mjs`, QA 증거/기록. 발견 결함의 구현 파일은 현재 소유자로부터 인계받은 것만 수정한다. 패키지 추가·공통 파일·예산 변경은 통합자가 결정한다.

## 수행

1. QA.md의 필수 행동과 7개 뷰포트를 검수한다. DOM 박스 측정과 실제 스크린샷을 함께 남긴다.
2. 관련 의미 있는 회귀를 추가한다. CSS 문자열 그대로 복사한 테스트보다 실제 입력/상태/겹침을 확인한다.
3. 전체 test, zone report10, production build, check:dist를 수행한다. 아트 파생본을 새로 만들었으면 재빌드 후 실제 WebP 사용을 확인한다.
4. production preview의 `/9-baseball/` 경로, 폰트/이미지, 캐시·콘솔 오류를 확인한다.
5. iPhone Safari와 Android Chrome 실제 기기에서 safe area·스크롤·회전·모션·음소거·로딩을 확인한다. 에뮬레이션과 실기기를 구별한다.
6. 기존 저장 이어하기와 실제 런 진행을 확인한다. 전체 런 QA는 샘플 첫 전투 성공으로 대체하지 않는다.
7. 새 테스터의 첫 30초 이해·행동 예측·결과 설명을 기록한다. 그림 호감과 조작 결과를 나누고 신구 UI의 순서 효과를 줄인다.

## 인수 G3

QA 표의 모든 항목은 실제 상태/근거/환경을 가진다. 필수 항목 BLOCKED면 출시 판정도 보류하며 가능한 다른 검증을 계속한다. 자동 테스트 통과는 시각/재미 통과가 아니다.

하나의 결함 목록에 재현/원인/수정 SHA/재검증을 남긴다. 같은 오류의 두 번째 시도 전 독립 reviewer/advisor에게 근거를 보낸다. 범위 밖 새 기능으로 결함을 우회하지 않는다.
