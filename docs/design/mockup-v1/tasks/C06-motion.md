# C06 — 실제 동작과 판정 동기화

담당: Claude 연결 구현, Codex/아트 제작·검수. 서로 교대하며 같은 파일을 동시에 수정하지 않는다. 선행 C05 G1 + A02 승인/검수된 동작 납품.

**허용 파일**: `battle-vnext/motion-timeline.js`, `motion.css`, `BattleScene.jsx`의 배우/공 연결 부분, `tests/battle-vnext-motion.test.js`. 기존 App FX 연결이 필요한 경우 통합자가 수정한다. 샷 판정·피해·카드 소비 변경 금지.

## 구현

- 기존 `playToken`, `fxStage`, `impactAt`, shot/presentation snapshot과 동작 timeline을 대응한다. 완료 콜백은 기존 controller가 받아 처리한다.
- 프레임별 pivot·발·릴리스/접촉 이벤트 metadata를 사용한다. 공이 손에서 나오기 전 결과가 뜨거나, 배트와 무관한 위치에서 타격되지 않게 한다.
- 일반 안타/정확 읽기/범위 적중/근접 실패/파울/볼/루킹/홈런/강판을 구별한다. 화면 흔들림·슬로모는 중요한 순간에만 쓴다.
- 사운드는 기존 음소거/사용자 입력 이후 재생 정책을 따른다. reduced-motion은 의미·타이밍을 유지하는 짧은 대체 표현으로 둔다.
- 탭 background/복귀·회전·배우 로딩 지연·중복 animation end에서 한 번의 판정이 유지되게 한다. UI 타이머는 엔진 상태를 독자적으로 진행하지 않는다.

## 인수 G2

- 대표 배우 한 쌍의 준비→투구→접촉/헛스윙→회복을 실제 게임에서 영상으로 남긴다.
- 코드 회귀: 토큰당 중복 callback 없음, 취소/언마운트 정리, 정보 공개/HP 갱신 시점 일치.
- 시각 회귀: 그립·좌우·발·배트 궤적·공·카메라·그림자와 UI 가림 없음.
- 필수 동작이 없으면 BLOCKED 또는 부분 프리뷰로 기록한다. 정지 그림을 회전시켜 완료 처리하지 않는다.

후속: C07 실기기·테스터, 이후 A03 전체 로스터. 첫 한 쌍이 통과하기 전 수십 개 모션을 복제하지 않는다.
