# 320×568 전투 한 화면

사용자 승인 범위: 카드 이미지를 유지하고 카드·조준판·실행을 세로 스크롤 없이 배치한다. 중복 아이콘/문구와 보조 버튼을 줄이고 팝업을 추가하지 않는다. 검증 후 main 병합·공개를 포함한다. 기준 main `aefcca9`.

## 구현 전 영향도

| 축 | 판단 | 대응 |
| --- | --- | --- |
| UI/레이아웃 | 영향 있음 | 전투 전용 compact 클래스와 마지막 CSS에서 628px 최소 높이를 없애고 실제 viewport 안에 다섯 행 배분. 기본 작은 화면 예산: 44 헤더/유동 경기장/148 손패/40 상태/48 행동. |
| 입력/제스처 | 영향 있음 | 손패·9존·실행 입력 그대로. 무료 기본 스윙 유지. 정보 진입점만 하나로 통합하고 인라인 검사기의 탭·Esc·포커스 복귀 검증. |
| 로직/밸런스 | 영향 없음 | 카드 비용·확률·피해·준비·공방 판정 불변. 2S 지켜보기/번트와 비용 경고는 유지. |
| 저장 | 영향 없음 | 키·스키마 불변, 기존 이어하기 확인. 메뉴/탭/화면 크기만으로 공을 진행하지 않음. |
| 모바일 | 영향 있음 | 320×568 및 큰 세로·PC iframe·가로 축소를 실제 측정. 9존과 실행/메뉴는 최소44px. safe-area는 화면 내부에 예약. |
| 스크롤 | 영향 있음 | 전역 overflow 금지. 전투만 화면 크기 제한. 손패는 기존 수평 넘김. 상세는 같은 경기장 안의 필요시 정보이며 외부 팝업 없음. 지도/보상/시설 스크롤 보존. |
| 사용자 흐름 | 영향 있음 | 정보 메뉴에서 카드/투수/읽기/더미/복기·음향/타이틀/공방 조건으로 접근. 본편 새 런·전투·결과·보상·시설·다음 길·이어하기 확인. |
| 테스트 | 영향 있음 | 새 보조 버튼 수/인라인 정보/기본 스윙/상태 보존 회귀 + 전체/실제 화면 검사. 기존 진입점 검사는 통합 메뉴에 맞춰 행동을 보존하며 갱신. |
| 빌드/배포 | 영향 있음 | 기존 패키지·아트·workflow 그대로. build/60MB/CI·공개 저장/최신 화면 확인 후 완료. |

## 선택한 방향

- 평상시 보조 진입점은 상단 정보 메뉴 하나. 공격·지켜보기 두 행동은 뜻이 다른 핵심 선택이므로 합치지 않는다.
- 무료 기본 스윙은 남긴다. 지워도 세로 공간은 줄지 않고 에너지0에서의 탈출 행동을 감추게 된다.
- 셀의 반복 확률 낱말·카드 역할 태그·단계 설명·반복 행동 캡션을 줄인다. 공 개수/빗금은 짧은 공통 범례, 수치는 접근성 설명과 정보 화면에서 확인.
- 카드 이름/비용/효과/사용 조건·경고, B/S/O, 활성 준비, 공방의 현재 제약·다음 예고·보호/반격은 판단 정보라 보존한다.
- 작은 화면 카드 아트는 최소56px로 원본을 유지한다. 전투 장면은 동일 카메라/배우, 지도 등 다른 화면의 전역 크기·스크롤을 바꾸지 않는다.
