## 발견한 결함

- 번트의 커버를 안타 확정으로 간주한다. 실제는 희생타/파울이며 안타 피해가 아니다.
- moonshot/gapHunter/sinkerBuster 예측 reveal에 결과 이름이 없어 실제 장타 추가 피해가 빠진다.
- 준비 미리보기가 이미 획득한 정찰 단서를 지운다. 반대로 미사용 흔들기 준비로 읽기 단계가 올라가면 정보를 무료로 공개한다.
- 속임수 투수의 정찰 확정 코스를 다시 이동시켜 100% 도착을 40%로 표시할 수 있다.
- 낮은 읽기에서 동일한 공개 확률 구간을 가진 두 상태가 다른 의도 아이콘을 표시한다. 흐린 투명도는 정보 경계를 보장하지 않는다.

예측 숫자는 공개 정보에서 보장되는 구간을 사용한다. 정찰 후 속임수의 부분 단서에서 정확한 조건부 구간을 공개 정보만으로 복원할 수 없으면 넓은 안전 구간을 표시한다. 상태·RNG를 미리 소비하지 않는다. 검증 결과는 실제 완료 후 기록한다.

## 완료한 보완과 검증

- 판정은 그대로 두고 예측에서 실제 `swingOdds`와 결과 이름/베이스를 전달한다. 번트는 희생타 확률·희생타 피해로 표시한다.
- 공개 정보만으로 보장되는 의도를 표시하고, 불확실하면 `읽기 힘듦`으로 남긴다. 낮은 읽기의 피해 끝점·HP 예상선도 공개 가능한 코스 전체를 사용한다.
- 준비 전후 표시의 정보 정밀도는 사용 전에 획득한 공개 뷰로 제한한다. 실제 피해 보너스와 기존 정찰은 보존하고, 아직 얻지 않은 정찰 결과는 숨긴다. 임시 준비 예측 상태는 저장/실행하지 않는다.
- 준비 후 실행 불가능한 조합은 기존 예측 영역에서 안내한다. `안타 시` 피해임을 밝히며 희생타에 안타 전용 주자 피해 배율을 표시하지 않는다.
- 원래 테스트 25개는 통과했지만 신규 버그 재현 7개는 수정 전에 모두 실패했다. 최종 전체 **189파일/1,187테스트** 통과. 독립 검토자는 합법적 공격 결과 **3,303건**을 실제 판정과 대조해 HP 불일치 0건을 보고했다.
- production build·60MB 예산 **58.6MB** 통과. smoke zone10/v9-30/growth2/deck1 모두 종료0. pnpm 자동 설치의 로컬 심볼릭 링크 오류는 기존 설치의 Node/Vitest/Vite 진입점을 직접 실행해 해결했다. 잘못 지정한 smoke 파일명도 실제 `deck-report.js`로 바로잡아 실행했다.
